## Short version: purpose

`r2.spec` is a spec file for the script `go.sh` of the window test: 8 lines, each with the arguments of one call of `robsize`. Each call measures one filler kind in steps of 1 over a short range of N, with 9 repetitions. The ranges lie around the step positions that an earlier run with the coarse default lists had printed.

## Words used here

- **CRB**: the Arm reference server under test. It has 128 CPUs.
- **Kernel**: the inner loop of a benchmark that reads, writes or copies memory. On this page "kernel" means this loop. The operating system kernel is always written "Linux kernel".
- **`robsize`**: the window test program of this folder. Each pass of its loop does two independent loads that miss the caches, and N filler units after each load. It prints the time per loop pass in ns for each N.
- **Window**: the out-of-order window of a core: the instructions that the core holds between fetch and retirement.
- **Filler**: an instruction between the two loads that does not depend on them.
- **Kind**: one sort of filler of `robsize`, chosen with the option `--kind`.
- **N**: the number of filler units after each of the two loads. While the fillers fit in the window, the two misses run at the same time. At the N where they no longer fit, the time per pass steps up from about one miss time to about two.
- **Pointer chain**: a buffer of pointers that form one random cycle. Each load of a pointer gives the address of the next load, and each such load misses the caches. `robsize` builds two chains, one for each of its two loads.
- **Spec file**: here a text file `TAG.spec` that the script `go.sh` reads. Each line holds the arguments of one call of `robsize`. It has no tag column, unlike the spec files of `rx.sh`.
- **Step position**: the N at which the time per loop pass steps up. `robsize` prints it in a comment line that starts with `# step`.

## Main flow

1. Read one line as one call of `robsize`. The script `go.sh` runs `./robsize --cpu 2` and then the words of the line, with a time limit and on the CPUs 0 to 119 (line 1).
2. `--kind` gives the filler kinds to measure, as one name or as a list with commas. `robsize` measures them one after the other, in the order of its own table of kinds, not in the order of the list.
3. `--nmin`, `--nmax` and `--nstep` replace the default list of N of the kind: the first N, the last N and the distance between two N.
4. `--reps` gives the number of repetitions per N. The result of an N is the median of the repetitions.
5. Options that a line does not name keep the defaults of `robsize.c`: 200000 loop passes per repetition (`--iters`), pointer chains of 1024 MiB (`--mb`) with one pointer every 64 B (`--stride`).

## Behavior a reader must know

- The file holds no command. The script `go.sh TAG` reads the file `TAG.spec` of its folder, so `go.sh r2` reads this file.
- All calls of one spec file share one budget of 570 s in `go.sh`. A line that finds 5 s or less of the budget left is skipped.
- `--cpu 2` is not written in this file. `go.sh` adds it.
- Each call is a new process. It builds its two pointer chains again before it measures.
- The default step of the kinds `nop` and `iadd` is 10, that of `vadd` and `ldrq` is 5, that of `ldpq` is 2. This file measures the same kinds in steps of 1.
- The result file `rob-r2-20261115T193953Z.csv` holds 8 lines `# call:` with the 8 lines of this file, and the line `# exit_code=0` [Ref1].
- Each range of this file holds the step position that the earlier result file `rob-r1-20261115T191146Z.csv` gives for the same kind in its line `# step` of the series `median_ns`: 683.6 for `nop`, 157.0 for `vadd` and `vadd_nd`, 193.9 for `iadd`, 193.0 for `iadd_nd`, 159.3 for `ldrq`, 79.9 for `ldpq`, 9.5 for `iter256` [Ref2].

## Short version: purpose

`k3.spec` is a spec file for the script `go.sh` of the window test: one line with the arguments of one call of `robsize`. The call measures 6 kernel-body kinds, one for each sparse read kernel from `read_sparse` (9 `nop`) to `read_sp56`. The result tells how many loop bodies of each kernel fit in the out-of-order window of a core.

## Words used here

- **CRB**: the Arm reference server under test. It has 128 CPUs.
- **Kernel**: the inner loop of a benchmark that reads, writes or copies memory. On this page "kernel" means this loop. The operating system kernel is always written "Linux kernel".
- **`robsize`**: the window test program of this folder. Each pass of its loop does two independent loads that miss the caches, and N filler units after each load. It prints the time per loop pass in ns for each N.
- **Window**: the out-of-order window of a core: the instructions that the core holds between fetch and retirement.
- **Filler**: an instruction between the two loads that does not depend on them.
- **Kind**: one sort of filler of `robsize`, chosen with the option `--kind`.
- **N**: the number of filler units after each of the two loads. While the fillers fit in the window, the two misses run at the same time. At the N where they no longer fit, the time per pass steps up from about one miss time to about two.
- **Spec file**: here a text file `TAG.spec` that the script `go.sh` reads. Each line holds the arguments of one call of `robsize`. It has no tag column, unlike the spec files of `rx.sh`.
- **Kernel-body kind**: a kind whose name starts with `k_`. One unit of N is one loop body of a benchmark kernel of `bwx12.c`, in the instruction order of that kernel. Its loads read a small buffer that stays in the cache, and its loop branch is never taken.
- **`ldp q`**: the Arm instruction that loads two 16-byte vector registers.
- **`nop`**: an instruction that does nothing.

## Main flow

1. Read one line as one call of `robsize`. The script `go.sh` runs `./robsize --cpu 2` and then the words of the line, with a time limit and on the CPUs 0 to 119 (line 1).
2. `--kind` gives the filler kinds to measure, as one name or as a list with commas. `robsize` measures them one after the other, in the order of its own table of kinds, not in the order of the list.
3. The line has no `--nmin`, `--nmax` and `--nstep`. So each kind uses the list of N that the table of kinds in `robsize.c` gives it.
4. The line has no `--reps` and no `--iters`. So each N is measured with 5 repetitions of 200000 loop passes, and the result is the median time per pass.

## Behavior a reader must know

- The file holds no command. The script `go.sh TAG` reads the file `TAG.spec` of its folder, so `go.sh k3` reads this file.
- All calls of one spec file share one budget of 570 s in `go.sh`. A line that finds 5 s or less of the budget left is skipped.
- `--cpu 2` is not written in this file. `go.sh` adds it.
- The result file `rob-k3-20261115T204653Z.csv` holds one line `# call:` with the text of this file, and the line `# exit_code=0` [Ref1].

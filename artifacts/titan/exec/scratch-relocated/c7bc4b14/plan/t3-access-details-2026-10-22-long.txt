Access to phoenix-crb (192.168.2.45) while I am away, 22 Oct to about Thu 29 Oct:

1. SSH: ssh arm@192.168.2.45. The arm account is the shared admin account and has sudo. Most of you already
   have a key on it. If yours is missing, send your public key (the one-line .pub file, never the private
   key, with your name in the comment) to <<Jibin: a colleague who has arm access>>. The colleague, logged in
   as arm, runs:
     echo 'ssh-ed25519 AAAA... yourname@yourhost' >> ~/.ssh/authorized_keys
   Use >> (append). A single > deletes every key and locks everyone out. Keys only for people on the
   phoenix-crb project. My own account (jhan) is not for shared use.
2. BMC (the board's management controller: remote console and power control): <<Jibin: address or URL>>,
   reachable from <<Jibin: network or VPN>>, user <<Jibin: BMC user>>. The password is in <<Jibin: password
   manager entry>>, and <<Jibin: one named colleague>> also has it. It is not posted here.
3. When to use the BMC: only if the host does not answer on SSH for 10 minutes. Post here before you touch
   it, and ask whether anyone else can still log in. Open the console first and read what is on the screen;
   do not log in there. Power-cycle only if you cannot fix the problem from the console. During Jeremy's
   hours (weekdays 13:00-21:00 UTC) wait for his OK here first. Afterwards post here what you did and when.
4. If the host reboots for any reason: it comes back by itself on the vendor kernel 7.1.3-arm-agi with all
   the settings (isolated cores, governor, paused timers), which are stored in the boot configuration. If
   the console shows a boot menu, press nothing: after 10 s it boots the right kernel by itself. Never pick
   6.8.0-147-generic, which has never booted on this board. After any reboot, post the time here: a run in
   progress at that moment is lost.
5. Jeremy's positron-perf account is his: do not enter it, and no other key goes on it unless he asks here.
   If a run looks stuck, post here; Jeremy's side stops it and removes the RUNNING file.

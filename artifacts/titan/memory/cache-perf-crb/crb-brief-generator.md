`crb/crb-memory-hierarchy-brief.html` (the two-page A4 brief for Bill) is the output of `crb/make-brief.py`. The script takes the root-run result folder as its only argument and has no default. The folder that reproduces the brief is `crb/results/sudo-20261102T054936Z` (checked on 2026-11-12: output identical to the existing brief apart from the "Brief generated" date).

How to change the brief: edit the HTML template inside `make-brief.py`, then run `python3 crb/make-brief.py crb/results/sudo-20261102T054936Z`. The script overwrites the brief in place and stamps today's UTC date. To test first, run a copy of the script whose last `open(...).write(html)` points to a scratch file, and diff.

Do not run `python3 -m py_compile` on it in place: that leaves a `__pycache__` folder in `crb/`.

The brief has an explicit page break (class `pb`) and must print on two A4 pages. Check the print layout with the local headless browser ([[headless-chrome-offline-render]]). A shorter label in the first table once made the column narrower and broke other labels at a hyphen, so print after any label change.

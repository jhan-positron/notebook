Access details for phoenix-crb, in case you need them while I am away (22 Oct to about Thu 29 Oct):

- Addresses: the host is 192.168.2.45 (<<Jibin: what it was before, if this is the changed address>>; thanks
  Mark for the change). The BMC (the board's management controller, for remote console and power control)
  is https://192.168.1.119.
- SSH: ssh arm@192.168.2.45. The arm account is the shared admin account and has sudo. Its password is in
  1Password (<<Jibin: entry name>>). For key login, append your public key to the arm account's key file,
  as arm: echo 'ssh-ed25519 AAAA... you@host' >> ~/.ssh/authorized_keys. Use >> (append); a single > wipes
  every key and locks everyone out.
- BMC: log in at https://192.168.1.119 (credentials in 1Password, <<Jibin: entry name>>) and click
  "SOL console" for the serial console. Use it only if the host does not answer on SSH. Post here before
  you touch it, and power-cycle only if the console does not help. A reboot keeps all the settings
  (isolated cores, governor, paused timers) but kills a run in progress, so post the time here afterwards.
- Kernels: the running kernel 7.1.3-arm-agi is Arm's build for this board (installed 28 Sep). The other
  installed kernel, 6.8.0-147-generic, has never booted on this board: never pick it. After a reboot, GRUB
  (the boot menu) starts 7.1.3-arm-agi by itself. If you see the menu, press nothing.

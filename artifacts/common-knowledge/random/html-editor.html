Editing a file

  1. Use Open file to choose an existing HTML document.
  2. Click its text and type. Pasted content is inserted as plain text.
  3. Click a table cell, then choose a row or column button. New cells start empty.
  4. Use Save to update the opened file. Use Save as to keep the original and work in a copy.
  • Paragraph: adds text below the current block. Inside a table, it adds a paragraph after the table.
  • Table keys: Tab moves to the next cell. Shift + Tab moves back. Enter adds a line inside a cell.
  • Undo: Ctrl + Z. Redo: Ctrl + Shift + Z. Use ⌘ on a Mac.
  • Preview: shows the page without editing outlines. Document links stay inactive.
Supported files and saving

Designed for static, UTF-8 HTML files with styles included in the file, such as your action plan. Linked styles, images, fonts, and scripts do not run or load in the editor. Their references are kept in the saved HTML.

Merged cells, nested tables, and uneven rows can be edited as text. Row and column insertion is disabled for those tables. Undo and redo keep up to 100 recent editing steps.

Saving preserves the document’s styles and links. The browser may normalize HTML spacing and attribute quotes. Scripts are preserved but remain paused in both editing and preview.

Chrome may ask for permission to save. If direct file access is unavailable, saving downloads an HTML copy. Check your Downloads folder. Reloading or closing this editor discards unsaved edits.

Words used here

/scratch
An NFS share from filer.positron.internal (23 TB, 87 % used). The same files are visible from delphi-3bda and the other hosts that mount it.
.pftrace
A Perfetto trace file: a recording of scheduler and application events captured during one benchmark draw. Large, and only useful while the draw is under analysis.
kvwait.bin
A binary dump of per-matmul timing stamps written by the instrumented runtron during the August deep-dive campaigns, one file per draw.
notebook
The git repository ~/workspace/notebook (jhan-positron/notebook on GitHub) that holds handoffs and mirrored artifacts.
mirror, canonical
A mirror is a copy in the notebook. The canonical file is the original on the machine where the work ran.
on-disk size
The space the filer reports for a file (du). Content size is the number of bytes in the file; here it is larger than the on-disk size.
tron, runtron
tron is the inference program under test. runtron is its command-line tool. A build of it is about 400 MiB.
worktree, checkout
A copy of the tron source at one git commit. A build tree is the compiler output next to it.
PR 3244, PR 3070, PR 2906
Pull requests of positron-ai/tron that the July and June tests compared against their base commits.
CI lease
The file the nightly System CI writes on delphi-3bda while it owns the machine. Only light work is allowed while it exists.
PDJN, deep-dive, pfgate, 5cat, ab kits, g2 and gate campaigns
Names of the July and August decode-performance investigation rounds. Each has a handoff in the notebook.

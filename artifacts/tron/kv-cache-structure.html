02 / BLOCK

Same bytes. Different read pattern.

K remains token-major for Q·Kᵀ. On AVX-512, V folds adjacent tokens into one row so a dual-bf16 dot-product can accumulate both weighted values in one instruction.

Odd-partner zeroing is a correctness invariant. When the final live token is even, its paired odd slot is outside offset_bound. TRON zeros that partner before the rounded-up V loop can read it, preventing stale or NaN data from contaminating the sum.

04 / FACTS

The invariants worth keeping.

The compact mental model, plus the source locations that define the current branch.

ownership book → slab
page → view

The stable page vector is metadata. Only the book owns the K/V DMA allocation.

flat order (L · H + h) · P + p

Page is the fastest-changing dimension; one page is a cross-section, not a contiguous payload.

lifetime allocated ⊇ valid ⊇ live

tok_ct is a gapless valid prefix; offset_bound is per-pass liveness.

GAL → GOF all layers → one layer
all heads

A GAL groups four positions; each layer owns one 16 KiB pair. Runtime Hᵢ maps to fixed slot Sᵢ.

causality lo, not page × 64

lo is the page’s first global ID in the current pre-order flattened forward pass.

cache tiers book ≠ GOF staging

The host book is authoritative. Hardware staging is disposable and reconstructed on demand.

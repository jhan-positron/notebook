# C++ language claims about the compound requirement

L1. `requires(size_t n_pages, size_t storage_slot_count, bool support_eagle, bool amx_mirror_eligible) { ... }` is a requires-expression; its parameters are never evaluated or created at runtime; they exist only to give the expressions inside argument types (they are lvalues of those types).
L2. `{ expr } -> std::same_as<std::shared_ptr<T>>;` is a compound requirement: (a) expr must be well-formed (unevaluated operand); (b) `std::same_as<decltype((expr)), std::shared_ptr<T>>` must be satisfied - the type of expr is inserted as the FIRST template argument of the type-constraint.
L3. std::same_as is exact: std::shared_ptr<T>& , std::shared_ptr<U> for U != T, or any type merely convertible to std::shared_ptr<T> fails. std::convertible_to<std::shared_ptr<T>> would be the looser alternative.
L4. This form does not check noexcept; the form `{ expr } noexcept -> ...` would. book's try_create is noexcept but a non-noexcept 4-arg factory would still satisfy amx_mirror_aware_cache.
L5. "Callable with (size_t, size_t, bool, bool)" is decided by ordinary overload resolution, so implicit conversions are allowed: a try_create whose 4th parameter is `int` (or any type bool converts to) would also satisfy the concept. The concept checks a signature shape, not the meaning of the 4th argument; a cache whose 4th bool means something else would be handed the mirror flag silently.
L6. For book, try_create has two overloads (3-arg with defaults, 4-arg); the 4-argument call selects the 4-arg overload unambiguously. For three_argument_sequence_cache, the 4-argument call has no viable overload -> the expression is ill-formed -> the concept is false (not a hard error).
L7. The leading `sequence_cache<T> &&` makes amx_mirror_aware_cache subsume sequence_cache (relevant for constrained-overload ordering); in create_sequence_cache it is used only via `if constexpr`, where subsumption does not matter, but it guarantees the fallback 3-arg call exists for any T for which the concept is even asked.

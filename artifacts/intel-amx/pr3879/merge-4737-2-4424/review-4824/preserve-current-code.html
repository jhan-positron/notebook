A larger reduction to evaluate separately

Optional design proposal · benchmark before adoption · h/tron/models/model.hpp:3380

Preserve-current-code: Consider reusing tron::barrier before maintaining a second shared-save protocol.

The existing barrier already provides main-thread phase setup, per-helper phase tracking, and completion waits (threading.hpp:895–936). A dedicated instance reset for the main helpers could replace opened, finished, helper_windows, and the custom wait loops while retaining the work-unit table and shared block stores. The existing greedy_range can also supply dynamic claims.

Treat this as a prototype requiring measurement. The existing latch diagnostics do not match the new aborting watchdog, and equivalent TPS/TTFT has not been established. Keep the current synchronization until those differences are resolved and the reduced version is benchmarked.

Existing implementation: h/tron/threading.hpp:895 · h/tron/threading.hpp:1027.

Narrowing packed storage to only AMX-eligible queries is also a redesign. The storage gate currently knows the key-head size. AMX eligibility additionally depends on query type and query-head grouping. Moving that policy through storage interfaces is not an established small deletion. h/tron/tensor/k_vnni.hpp:118 · h/tron/models/self_attention.hpp:1904.

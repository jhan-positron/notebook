PR4424 · h/tron/models/kv_cache.hpp

KV cache: typed K storage, per-block layout state, and layout-aware copies

Short version

  • PR4424 gives each eligible K plane a typed packed owner while retaining row-major storage inside unfinished 16-token blocks.
  • The page now tracks saved rows separately from converted blocks. Stores, readers, invalidation, and page copies use that state.
  • The diagrams separate token offsets, physical slots, KV heads, and EAGLE metadata so each transition can be checked against the cited code.

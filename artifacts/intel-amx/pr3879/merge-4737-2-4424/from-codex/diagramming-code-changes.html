Short version

PR4424 gives eligible K planes a typed owner that can hold row-major and packed blocks.

Cache state records which layout each block uses.

The model shares writes with helpers, then completes token bookkeeping and any deferred conversion.

Words used here

Tron
The inference program under test.
K / Q / V
Keys, queries and values in attention. A query scores stored keys to choose how much each value contributes.
KV page
A 64-token cache page. Each storage slot has the key and value data for its own head geometry.
bf16 / fp32
16-bit brain floating-point values / 32-bit floating-point values.
VNNI
Vector Neural Network Instructions. Here the name identifies the paired layout used by the matrix and vector instructions.
AMX / AVX-512
Intel Advanced Matrix Extensions / Advanced Vector Extensions with 512-bit vectors. These are CPU instruction sets.
FPGA / DMA
Field-programmable gate array, the accelerator card / direct memory access, used to move staging buffers to the card.
GOF
Group of four consecutive tokens. The gof staging code prepares their K and V data for the accelerator.
row-major
All dimensions for one token are contiguous. A short write can keep this form inside a block of the typed K owner.
layout_on<head_size>
The compile-time storage gate. TRON_K_VNNI enables it only for 128-dimension heads.
slot
A key/value storage position associated with an attention operation and a head geometry.
pending_k_block
A saved page pointer, physical storage reference and block number awaiting conversion.
EAGLE_STORAGE_SLOTS_1
One extra layout-state entry beyond the logical slots, reserved for EAGLE storage.

// Why not add the fourth argument to sequence_cache itself? Because only a
// cache with a K mirror arena (book) can use it, and a cache that meets the
// public contract alone must still build with the scheduler. Today every
// production cache is a book, so the no-bool path is compiled but not run; it
// exists for caches that know nothing about AMX. Without the bool there is no
// mirror arena, and every mirror consumer null-checks (Note [K mirror parallel
// arena]).
Lineage note: “mirror” names the formulation S = Q·KT read from a second, VNNI-interleaved copy of K, which originates from Bill’s PR #2934; the arena, the flag and the concept discussed here are our implementation of that idea in PR #3879.

The picture

In one line: create_sequence_cache lets the scheduler hand its AMX bool to book without forcing that bool on every cache type that meets the published sequence_cache checklist; a cache that does not take the bool simply gets no K mirror, and all mirror code already tolerates "no mirror".

Sentence by sentence

the comment saysin plain words
"Optional extension of the factory contract, not part of sequence_cache:" sequence_cache (kv_cache.hpp:1431) is the checklist a KV-cache type must pass to work with the scheduler. One item on it (kv_cache.hpp:1411-1413) is a factory: a static function T::try_create(n_pages, storage_slot_count, support_eagle) whose result is std::shared_ptr<T> (nullptr when the DMA allocation fails). "Factory contract" is not a defined term anywhere else in the tree (only this comment and the title of commit 840106b44a); it means that one checklist item. The concept defined directly below, amx_mirror_aware_cache, is a second, separate check that a cache may pass or fail. Failing it does not make a cache any less of a sequence_cache.
"a cache that can allocate the AMX K mirror arena (book) also accepts the scheduler's amx_mirror_eligible flag." Today one cache type owns a K mirror arena: book (member mirror_arena_, kv_cache.hpp:1093; maybe_allocate_mirror_arena, 1101). book has a second try_create with a fourth parameter, bool amx_mirror_eligible (kv_cache.hpp:1036-1039). Precision: the concept cannot see whether a type has an arena. It checks only that T::try_create can be called with a fourth bool argument and that the result type is exactly std::shared_ptr<T>. "The scheduler's flag" is a bool the scheduler computes once per token tree (full.hpp:1456-1459) and stores in every tree node (full.hpp:312); it is true when the model's activations are bf16 and at least one attention kernel has head_size 128 with 4 query heads per KV head (amx_attn_iface.hpp:136-138, 147-148).
"create_sequence_cache passes the flag to such a cache" create_sequence_cache<T>(...) (kv_cache.hpp:1449-1461) is the one function the scheduler calls to make a book (full.hpp:834). Inside is if constexpr (amx_mirror_aware_cache<T>): a switch the compiler decides once per cache type, not at run time. For a type that passes the check it calls the 4-argument try_create and hands the bool through. In production every cache_t is a book (h/tron/plugins/llama.hpp:188, h/tron/plugins/mock.hpp:110, heterogeneous_kv_cache.hpp:28-39, and the 15 ingest-generated plugins), so this is the branch that runs.
"and calls the three-argument factory that sequence_cache requires for every other conforming cache," "Conforming" = passes the sequence_cache checklist. For a cache type that has no 4-argument try_create, the compiler takes the other branch: the 3-argument call that every sequence_cache must support, and the bool is dropped. No such cache exists in production; the only one in the tree is three_argument_sequence_cache (t/t_llama_unit.cpp:460-491), written to prove that this branch compiles. Why the branch exists: before commit 840106b44a the scheduler called the 4-argument book::try_create directly at full.hpp:834, so any future or out-of-tree cache that met the published checklist but lacked the fourth argument would not have compiled with the scheduler. Codex's review of PR #3879 (finding P2) pointed this out; it was an inference from the code, no build had failed.
"which then simply has no mirror arena" A cache made through the 3-argument call has no K mirror. For a non-book cache that is true by construction: it never had one. (book also has a 3-argument try_create, kv_cache.hpp:1025-1030, which hard-codes the bool to false; tests use it, the scheduler does not.) The converse does not hold: a book made through the 4-argument call with the bool true can still end up without an arena - when AMX is not usable on the host (amx_attn::available() false, which includes TRON_AMX_DISABLE=1), when the nothrow new returns null (kv_cache.hpp:1106-1115), or in the default build, where the CMake option TRON_AMX_K_MIRROR is OFF (src/tron/CMakeLists.txt:181) and the arena members do not exist at all (kv_cache.hpp:1085-1121; the bool is then [[maybe_unused]], 1066).
"(every mirror consumer null-checks; see Note [K mirror parallel arena])." Nothing breaks when the arena is missing. mirror_at_storage returns nullptr when mirror_arena_ is null (kv_cache.hpp:1291); the two accessors mirror() (1321) and page::k_mirror_data() (1618) pass that nullptr on unchanged; and every place that would read or write through the pointer tests it first: fill_storage_slot (1368), page::set_k_mirror (1632), page::copy_storage_slot (1969), and the QK read in self_attention.hpp:1574, which then runs the AVX dotter loop (1595) instead of the AMX mirror kernel. save_k (model.hpp:2796-2800) does not test the pointer itself; it relies on set_k_mirror's test. The Note (kv_cache.hpp:555-591) lists the four reasons the arena may be absent and calls the fallback "fail-soft, never fatal", with one caveat it states itself (577-580): the nothrow allocation is not fail-soft under Linux overcommit - the pages are committed at the first write, so a host that enables the mirror must keep pool/2 of ordinary RAM free.

the code saysin plain words
template <typename T> concept amx_mirror_aware_cache = ...; Defines a named yes/no question about a type T, answered by the compiler. Using it later as amx_mirror_aware_cache<book> yields a compile-time bool.
sequence_cache<T> && T must first pass the sequence_cache checklist. Because of &&, when it does not, the rest is not even tried and the answer is "no" ([temp.constr.op]/2). Two consequences: (1) any type that passes this concept also has the 3-argument factory; (2) this concept is "more constrained than" sequence_cache, which matters only if both were used to constrain two overloads of one function - the more constrained one wins (probe which(), returns 4 for the book-like type, 3 for the 3-argument type). if constexpr does not care about that ordering; it only asks true or false.
requires(size_t n_pages, size_t storage_slot_count, bool support_eagle, bool amx_mirror_eligible) { ... } A requires-expression. The four names are not variables: they have no storage and no lifetime, are never evaluated and never exist at run time ([expr.prim.req]/4). They exist only to give the expression inside a set of argument types. They behave as lvalues of those types, so a factory whose fourth parameter is bool&& would not match while bool& would (probes X1, X2). The names are the same as book::try_create's parameter names for the reader's benefit only; the compiler never compares names.
{ T::try_create(n_pages, storage_slot_count, support_eagle, amx_mirror_eligible) } First half of a compound requirement: this call must compile. "Compile" means ordinary overload resolution ([over.match.viable]): T must have a static try_create callable with four arguments of types (size_t, size_t, bool, bool). Implicit conversions are allowed - a fourth parameter of type int or double also passes (probes C_int4, X6); std::string does not (G_string4). If no overload fits, the whole requires-expression is simply false ([expr.prim.req]/6) - not a compile error; that is what lets if constexpr take the other branch. For book the 4-argument call picks the 4-parameter overload and nothing else: a 3-parameter function is not viable for 4 arguments ([over.match.viable]/2). The expression is an unevaluated operand, so try_create needs no definition to be checked - which is why the test type can be declaration-only.
-> std::same_as<std::shared_ptr<T>>; Second half: the type of the call expression, decltype((T::try_create(...))), is inserted as the first template argument of std::same_as, so the real check is std::same_as<decltype((call)), std::shared_ptr<T>> ([expr.prim.req.compound]/1.3, [temp.param]/4). same_as is exact ([concept.same] = is_same_v both ways): a factory returning std::shared_ptr<Derived> fails, std::shared_ptr<T>& fails, const std::shared_ptr<T> fails, std::unique_ptr<T> fails - although every one of them converts to std::shared_ptr<T> (probes D_base, E_ref, H_const_ret, X3). The looser spelling would be -> std::convertible_to<std::shared_ptr<T>>. Checking stops at the first failing part ([expr.prim.req]/6): if the call does not compile, the type test is never reached.
(what is not written) noexcept is not checked. The form { expr } noexcept -> ... would check it; this one does not, so a throwing 4-argument factory passes (probe F_not_noexcept). create_sequence_cache is itself noexcept (kv_cache.hpp:1454), so such a factory throwing would end in std::terminate. Both of book's factories are noexcept (1027, 1039). Meaning is not checked. Any fourth argument a bool converts to counts as "accepts the mirror flag"; the probe type with an int fourth parameter instantiates the 4-argument branch of create_sequence_cache with no warning under -Wall -Wextra.
// maintenance trap static std::shared_ptr<book> try_create( size_t, size_t, bool, bool = false); // do NOT If a default value is ever added to the last parameter of the 4-parameter book::try_create, the 3-argument call becomes ambiguous between the two overloads ([over.match.viable]/2.3 makes both viable), sequence_cache<book> turns false, and the scheduler stops compiling (probe X4). The current 4-parameter overload has no defaults (kv_cache.hpp:1036-1039); the 3-parameter one has two (1026-1027), which is fine.

Where the bool comes from, and the three other gates

The comment says "the scheduler's flag" as if it alone decided the arena. Four independent gates stand between the scheduler and an allocated mirror; the bool is the first.

1 · compile time, per model typeamx_mirror_eligible<activation_scalar>(attention_kernels) (kv_cache.hpp:182-193): true when the scalar is bf16 and some kernel has head_size 128 and kv_mul() 4 (amx_attn_iface.hpp:136-138, 147-148). Evaluated once, when the token-tree root is made (full.hpp:1456-1459). An EAGLE speculator scheduler adopts the main model's root and its bool (full.hpp:1448-1450; src/tron/scheduler/full.cpp:316-325).
2 · run time, once per processamx_attn::available() (src/tron/kernels/amx_attn.cpp:56-82): CPUID and XCR0 report AMX, the kernel grants tile data (arch_prctl), and TRON_AMX_DISABLE is not "1". Checked in maybe_allocate_mirror_arena (kv_cache.hpp:1106), not by the scheduler.
3 · allocation::operator new[](bytes, align 64, std::nothrow) for kv_bytes/2 (kv_cache.hpp:1107-1112). A null return leaves the arena absent; the book still works.
4 · buildTRON_AMX_K_MIRROR, CMake option, default OFF (src/tron/CMakeLists.txt:181; needs TRON_AMX_DISPATCH). When off, gates 2-3 and the arena members do not exist and the bool is ignored ([[maybe_unused]], kv_cache.hpp:809, 1066).

Draft kept for the record; jhan chose the shorter "why"-only version shown at the top instead. Same facts, same identifiers, in the register of the right-hand column. Longer than the original (6 lines to 26) because each sentence now carries one fact the original folded into a clause.

// A second, optional check on top of sequence_cache. sequence_cache asks every
// cache type for a three-argument factory,
//   T::try_create(n_pages, storage_slot_count, support_eagle) -> std::shared_ptr<T>.
// amx_mirror_aware_cache asks, in addition, for a four-argument one whose last
// argument is the scheduler's amx_mirror_eligible bool. book has both; the bool
// tells book whether to allocate the K mirror arena. A cache that has only the
// three-argument factory is still a valid sequence_cache.
//
// create_sequence_cache is the one call the scheduler makes to create a book.
// It is a compile-time switch, decided once per cache type: for a cache that
// passes amx_mirror_aware_cache it calls the four-argument factory and passes
// the bool through; for any other sequence_cache it calls the three-argument
// factory and the bool is dropped. The second branch exists so that a cache
// which meets the public sequence_cache checklist compiles with the scheduler
// although it knows nothing about AMX. Today every production cache is a book,
// so that branch is compiled but not run.
//
// A cache created through the three-argument factory has no mirror arena. That
// is safe: mirror_at_storage returns nullptr when the arena is absent, and every
// place that would read or write a mirror plane checks for nullptr first and
// takes the non-mirror path. Note [K mirror parallel arena] lists the other
// reasons the arena may be absent (no usable AMX, allocation failure).
//
// The check is on the call shape only: any fourth argument a bool converts to
// satisfies it, and noexcept is not checked. Do not give the four-argument
// book::try_create a default for its last parameter: the three-argument call
// would become ambiguous and book would stop being a sequence_cache.

Glossary

concept
A named compile-time yes/no test on a type. sequence_cache<T> is a bool the compiler computes.
requires-expression
The body of such a test: a list of expressions that must compile (and, optionally, have a given type). Its parameters are notation only - they never exist at run time.
compound requirement
One item of that list written as { expression } -> type-constraint; - "this must compile, and its type must satisfy that".
factory
A static function that creates an object and returns it by pointer; here try_create, which returns nullptr instead of aborting when the DMA allocation fails (STORY-127).
sequence_cache
The checklist (kv_cache.hpp:1387-1431) a KV-cache type must pass to be used by the scheduler: page type, slot counts, the 3-argument factory, and 13 instance operations.
book
The KV cache: pages of K and V for one sequence, in DMA memory the FPGA can read (kv_cache.hpp:750-1377). Every production model's cache_t is a book instantiation.
K mirror arena
A second copy of K in the layout the AMX tile instructions want (VNNI), in ordinary RAM, owned by the book; kv_bytes/2 in size. Only the CPU reads it. See Note [K mirror parallel arena], kv_cache.hpp:555-591.
amx_mirror_eligible
Both a function (kv_cache.hpp:183, the compile-time predicate over a plugin's attention kernels) and the name of the resulting bool parameter carried by the scheduler's tree nodes and the book factories.
amx_attn::available()
Run-time answer to "can this process use AMX right now": CPU, OS permission, and the TRON_AMX_DISABLE kill switch. Probed once per process.
if constexpr
An if whose condition the compiler evaluates; the branch not taken is discarded and need not even be valid for that type.
subsumes / more constrained
Concept A subsumes concept B when A's requirements include all of B's. Used by the compiler only to rank overloads that differ in their constraints.
nothrow new
new (std::nothrow): returns nullptr instead of throwing when memory cannot be obtained. Under Linux overcommit, the return is not the last word - pages are committed on first write.
EAGLE
Speculative decoding with a small draft model; the draft scheduler shares the main scheduler's token-tree root and therefore its books and its bool.
TRON_AMX_K_MIRROR / TRON_AMX_DISPATCH
CMake options: the second compiles the AMX kernels and dispatch; the first, which needs the second, compiles the mirror arena and the write-through. Both default OFF.

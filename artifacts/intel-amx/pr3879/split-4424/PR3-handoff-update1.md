## Words used here

- PR: pull request. PR-2: PR #4887, the AMX kernel PR, a draft at 0ee8671d35. PR-3: the shared block save PR this handoff builds. AMX: Intel Advanced Matrix Extensions, the tile instruction set.
- Catch2: the C++ test framework of tron's unit tests (version 3.7.1 in this tree). Test spec: Catch2's command-line filter that selects test cases by name. Mutation check: a deliberate code change that a test must catch.
- The chain: the delphi-3bda build-and-test script the executor forks from exec/pr2-20261011/chain.sh. Serving: the production rinzler engines on delphi-3bda, which the chain stops for its whole-machine steps and must start again. The marker: the file /bill-has-instance-0,2 that says Bill may use his half of the machine.
- Arm: one binary with one environment setting in a smoke or a cell. newoff and headoff: PR-3's and PR-2's binaries with the kill switch TRON_AMX_DISABLE=1. The band: twice the larger standard deviation of two arms, never below 0.4 TPS (decode tokens per second per user) or 0.15 s of TTFT (time to first token).
- store_k_block: PR-3's function that groups a minibatch's tokens into runs and stores them. The option: the CMake switch TRON_K_VNNI.

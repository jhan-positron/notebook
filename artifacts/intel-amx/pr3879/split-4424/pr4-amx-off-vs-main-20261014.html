PR 4 against main with AMX disabled, 2026-10-14

Short version. With AMX disabled (TRON_AMX_DISABLE=1, the kill switch), PR 4 (#4901) is inside the noise band against main in decode TPS in all three CPU cells (+0.7 %, +2.7 % and -0.5 %), and its prefill at prompt 8,192 tokens is 4.98 s (4.1 %) faster than main. Against its parent PR 3 it is 3.3 % and 2.7 % slower at tp2, as in the two earlier runs. The deferred-dotter probe build recovers 2.0 points of that at tp2 prompt 1,024 (beyond the band) and is inside the band in the other two cells.

What this means for PR 4901

  • Against main, the kill-switch path is not slower in any cell. Decode TPS is inside the band in all three cells (+0.7 %, +2.7 % and -0.5 %). The +2.7 % at tp2 prompt 8,192 is 0.39 TPS, 0.01 TPS under the 0.40 TPS floor of the band. Prefill at prompt 8,192 is 4.98 s faster (beyond the 0.44 s band), and 68 to 79 ms faster in the other two cells (inside the 0.15 s floor).
  • PR 4 keeps little of the stack's kill-switch decode gain. PR 3 is +4.1 % and +5.5 % above main at tp2 (beyond the band) and 0.0 % at tp4. PR 4 is 3.3 % and 2.7 % below PR 3 at tp2 (beyond the band) and 0.5 % below at tp4 (inside). The three runs of 2026-10-12, 2026-10-13 and 2026-10-14 agree on this (table below).
  • The chained estimate of this morning was about 1 point too high. It said est. +1.8 % and +3.5 % for PR 4 vs main at tp2 (sum of the four per-PR kill-switch deltas). Measured: +0.7 % and +2.7 %.
  • The deferred-dotter probe is a partial fix, as before. Against PR 4 it recovers +2.0 % (beyond the band), +0.9 % and +0.2 % (inside); on 2026-10-13 it recovered +2.3 %, +1.6 % and +0.2 %. Against main it is +2.7 % and +3.6 % (beyond) and -0.4 % (inside). Its prefill is the same as PR 4's in every cell (0, +21 and -5 ms). It costs nothing measurable with AMX on (run of 2026-10-13). Issue #4934 tracks the slowdown against PR 3, with the probe as a partial fix and two further leads.
  • The prefill cost at prompt 8,192 against PR 3 repeats. PR 4 is 587 ms slower than PR 3 (beyond the 0.20 s band), after 453 ms and 521 ms in the two earlier runs. Against main it is still 4.98 s faster. The probe build does not change it.

Exact numbers

Per arm: mean over 3 repetitions (sample standard deviation). TPS = decode tokens per second per user. TTFT = prefill time in seconds, the maximum over the 8 users.

Pairs: difference of the means, the summary’s percentage of the second arm, the band, the verdict, and the paired t over the 3 repetition pairs (its sign matters only when the band is crossed).

Words used here

tron, runtron
tron is the inference program under test. runtron is its command-line tool, which ran every cell here.
AMX, the kill switch, AVX-512
AMX is the Intel tile instruction set that the stack's attention kernel uses. TRON_AMX_DISABLE=1 (the kill switch) turns the AMX kernels off at run time, and the AVX-512 reader scores the keys instead. Every arm on this page runs with the kill switch, which is also the path of a host without AMX.
main, PR 3, PR 4, probe; baseoff, headoff, newoff, lazyoff
main = commit 72308ec90c of the main branch. PR 3 = #4898 (dfafd13dce), the parent of PR 4. PR 4 = #4901 (ea94e95a4e), the last PR of the four-PR stack that replaces PR #4424. probe = the deferred-dotter build (ca6456b7dc on ea94e95a4e), which builds a page's dotters at its first row-major row instead of before every page. The "off" names are those binaries run with the kill switch.
dotter
The software routine that scores one row-major K row (a saved key vector) against a query row.
cell, tp2, tp4, p1024, p8192
A cell is one model, tensor-parallel width (tp2 = 2 cards, tp4 = 4 cards), user count and prompt length. p1024 and p8192 are prompt lengths in tokens.
TPS, TTFT
TPS is decode throughput, generated tokens per second per user. TTFT is the time to the first token, which here is the prefill time of the whole prompt.
band, beyond, inside
The campaign's threshold for a change: twice the larger sample standard deviation of the two arms over their 3 repetitions, never smaller than 0.40 TPS or 0.15 s. "Beyond" means the difference is larger than the band, "inside" means it is not.
paired t
The mean of the 3 repetition-pair differences divided by their standard error. A large magnitude means the sign is stable across repetitions.
chained estimate
The sum of the four per-PR kill-switch deltas measured in the four PR campaigns (PR 1 +4.4 / +5.3 %, PR 2 +1.0 / +1.3 %, PR 3 -0.1 / -0.1 %, PR 4 -3.4 / -2.9 % at tp2 p1024 / p8192), written before this run as an estimate of PR 4 vs main.

7. What this means for the nightly

  • The nightly installs tron from a Debian package (.deb, installed with apt). The GitHub Actions workflow publish-deb.yml builds that package every day from the CMake preset deb plus two flags.
  • Neither the preset nor the flags set TRON_AMX_DISPATCH (the option that compiles the AMX kernel) or TRON_K_VNNI (the option that turns on the VNNI K layout). Both options default to OFF [GNUmakefile:466-468; CMakePresets.json, configure preset deb; CMakeLists.txt:48-49; verified at ff680c8020].
  • So the package carries neither the AMX kernel nor the VNNI K layout. The nightly's numbers will not change when PR #4424 merges.
  • For the same reason the merge of PR #3879 on 2026-09-15 should not have changed them. This report did not compare the nightly's numbers before and after that merge. The two nightly runs of 2026-09-16 (GitHub Actions runs 35050734153 and 35052594106) ended with the GitHub Actions conclusion "failure", so there is no after-merge number to compare.
  • Only the older CMake-based CI workflow (cmake-single-platform.yml) compiles both options ON, and that build never becomes a package [.github/workflows/cmake-single-platform.yml:330-335; README.ci.md:518-556].

If the package build is changed to compile both options, the cells here predict the direction of the change per model.

  • The hand-written plugins (llama, mixtral, qwen-2.5, gemma-2) run CPU attention in the nightly. Blocks A and C apply to them. Block C (1536 generated tokens) is the closer match to the nightly's capture window (the range of generated tokens over which it measures TPS, section 4b).
  • qwen-3-4b and gpt-oss-120b run FPGA attention there. Block B and the FPGA rows of blocks D and E apply to them. gemma-4-31b has no FPGA attention, so block A is its nightly mode (no resolved change).

The size of the change in the nightly's own per-user TPS is not predicted by these runtron numbers. runtron runs one engine (one tron process serving the model). The nightly runs 2 to 4 engines per model (section 8 shows why the scales differ).

Words used here

tron, runtron
tron is the inference program under test. runtron is its command-line tool, which ran every cell here.
AMX, the kill switch, AVX-512
AMX is the Intel tile instruction set the stack's attention kernel uses. TRON_AMX_DISABLE=1 (the kill switch) turns the AMX kernels off at run time; the AVX-512 reader and the row-major dotter score the keys instead.
PR 3, PR 4, fix; head, new, fix and their off arms
PR 3 = #4898 (dfafd13dce), the parent of PR 4. PR 4 = #4901 (ea94e95a4e), the row-major tail block, the last PR of the four-PR stack. fix = the issue #4934 branch jhan-vnnik-5-i4934 on top of PR 4. An arm named <x>off runs the <x> binary with the kill switch.
the loop, the reader, the dotter
The loop is the software scoring loop of one query against one page. The reader is k_vnni::qk_group, the AVX-512 routine that scores the VNNI blocks of a page. The dotter is the per-token dot product over one row-major K row.
tail block, the conversion
PR 4 keeps an incomplete 16-token K block row-major inside its own bytes and converts it to the VNNI layout at the forward end of the pass that saves its 16th row. The fix runs that conversion on the app pool instead of serially on the main thread.
cell, tp2, tp4, p1024, p8192
A cell is one model (qwen-3-4b), tensor-parallel width (tp2 = 2 cards, tp4 = 4 cards), 8 users and a prompt length in tokens; every run generates 256 tokens per user.
TPS, TTFT
TPS is decode throughput, generated tokens per second per user. TTFT is the time to the first token, which here is the prefill time of the whole prompt.
band, beyond, inside
The campaign's threshold for a change: twice the larger sample standard deviation of the two arms over their repetitions, never smaller than 0.40 TPS or 0.15 s. Beyond means the difference is larger than the band.
paired t
The mean of the repetition-pair differences divided by their standard error. A large magnitude means the sign is stable across repetitions.

- Relates to round-1 id(s): F11

Only class completeness is required there: the fake kernel takes the view by value, and completing a class template instantiates the class body, not its member function bodies. AMX dispatch is a compile error in the 8-lane build, so no 8-lane code calls any packed operation. The test rows in section 8 are not chunk-guarded, so t_llama_unit would instantiate the bodies at 8 lanes unless the agent guesses to guard them.

## Summary

Backports corrections from the hwattention_sync → main merge stack PRs.

### Code-correctness fixes

- **`h/tron/models/kv_cache.hpp`**: removed a duplicate `// Returns true if this was the completing save (count reached 2).` comment above `mark_k_complete` (the line appeared twice).

- **`h/pos/hwattention.hpp`** (`xfer_v_entry`): passed literal `0` as the `readback_offset` argument for non-final fetcher transfers in V xfers. The "no readback" sentinel is `no_readback_sentinel = 0xffffffff`; literal `0` would install a readback at offset 0, which is a real (not dead) offset. The matching `v_hwcacheblock::xfer` in `src/pos/hwattention.cpp` already used `no_readback_sentinel`, so this aligns the inline helper with the canonical call site.

- **`h/pos/hwattention.hpp`** (`check_k_range` / `check_v_range`): silently no-op stubs now have a TODO marker so future readers can grep them up. Bodies remain no-ops pending shard-aware bounds tracking.

- **`h/pos/device.hpp`** (`wqentry::in_flight`): comment claimed `hw_prepare` asserts the field is false on entry. `hw_prepare` in `src/pos/worker.cpp` does not actually assert this. Rewrote the comment to describe what the field tracks without claiming a behavior that does not exist.

### Debug-value reverts

- **`h/pos/config.hpp`**: `maxpolls` back to `1e9 / timeout_ns` (~1 second of polling, was 100×); `max_xfer_time_in_ns` back to 100 ms (was 10 s). Both bumps were debug-only and should not have remained on this branch.

- **`src/pos/device.cpp`**: `DEBUG_INIT` flipped from 1 to 0 and the guard switched from `#ifdef DEBUG_INIT` to `#if DEBUG_INIT` so the value actually gates compilation (the macro is always defined). `DEBUG_RESETS` / `DEBUG_VFIO` converted to the same `#define X 0` + `#if X` form for consistency.

### Cleanup

- **`h/pos/device.hpp`**: removed five commented-out `wqentry` fields from the public struct surface.
- **`src/pos/device.cpp`**: removed three `#if 0` / commented blocks (pseudochannel debug print, init register dump, `wcmd/acmd/mdwd` req-id allocations).
- **`src/pos/CMakeLists.txt`**: dropped unused `nlohmann_json` link from both `pos` and `pos_fake`.
- **`src/pos/fake.cpp`**: TODO comment on `fake_devices` null-deref hazard.
- **`src/pos/device_dma_tracker.cpp`**: bounds-check assert on `await_layer`'s `layer` arg, mirroring `push()`.
- **`h/pos/dma/queue.hpp`**: extended move-ctor / move-assignment comments to state the quiescence invariant the relaxed atomic loads rely on.
- **`t/t_dma.cpp`**: one-line comment on why `kv_xfer = true` is the right path to exercise post-refactor.
- **`src/tron/models/ranged_mask.cpp`**: explanatory comments on the asymmetric loop guards and the SW→HW transition's caller-guarantee.

These were surfaced by the Code Quality Agent during reviews of [#2693](https://github.com/positron-ai/tron/pull/2693), [#2694](https://github.com/positron-ai/tron/pull/2694), and [#2695](https://github.com/positron-ai/tron/pull/2695). Backporting them here keeps the eventual main → `hwattention_sync` sync clean.

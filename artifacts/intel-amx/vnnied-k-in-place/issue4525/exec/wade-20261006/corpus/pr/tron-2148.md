> [!NOTE]
> **Medium Risk**
> Changes hardware-attention command generation, DMA descriptor sequencing, and result-buffer handling to split long sequences across multiple commands; mistakes here could cause incorrect results or hangs under load. Scope is mostly constrained to HW-attention paths but touches core POS TX/RX worker logic.
> 
> **Overview**
> Extends hardware attention (AoF) to handle token positions beyond a single 4096-token command by **splitting work across multiple activation/weight subcommands** and **using multiple result buffers**.
> 
> Updates POS TX/RX worker logic to sequence repeated `wcmd`/`acmd` descriptors per subcommand (only transferring activations once), route RX DMA destinations differently for HW-attn vs legacy matmul, and carry extra debug context (`tok_ix`, `layer`) through `rxinfo`.
> 
> Adjusts HW KV-cache allocation sizing (more pages per layer and updated per-entry sizing), adds shared config constant `max_positions_per_hwattn_cmd`, and includes optional token timing logging plus minor test include-order cleanup.

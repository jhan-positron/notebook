> [!NOTE]
> **Medium Risk**
> Touches low-level DMA completion and wait-loop timing logic; mistakes could cause premature completion or missed timeouts under wrap/counter/CPU-anomaly scenarios.
> 
> **Overview**
> Fixes a corner case in DMA transfer completion detection when the descriptor ring wraps.
> 
> `DmaQueue::check_xfer_complete` now treats a transfer as done if the queue’s wrap count has advanced past the transfer’s end wrap, or if it’s on the same wrap and the consumed descriptor index has reached/passed the end index.
> 
> Separately, the busy-wait loops in `readback_check` and `wait_for_xfer_blocks` now run `check_for_tsc_errs` only on the first iteration instead of every poll, reducing overhead during waits.

## PR body (as it is now; may have been edited after the review)

## Summary

Add high-resolution FPGA state counters to Tron's existing Perfetto traces. Independent mailbox, attention, and weight samplers feed bounded queues, which separate hardware reads from Perfetto writes.

## Changes

- Enable host tracing with `--tracer-core`; opt into attention and weight MMIO reads with `--tracer-registers`. Select devices and sampler CPUs explicitly. Dice grants reject tracer CPU overrides in both runtron and Rinzler.
- Keep `--tracer-period-us` for FPGA mailbox updates and the host mailbox wait. Add independent `--tracer-register-period-us`: a 10 µs delay after each register pass by default, or `0` for unthrottled diagnostics. The achieved interval includes read latency and scheduling. Neither option changes the writer's 200 µs poll or minimum 1 ms utilization window.
- Decode mailbox, attention, and weight state into existing trace categories, with raw register halves and sampler diagnostics. All samplers use the writer's filtered device list and never read unsupported devices.
- Preserve independent device/category baselines, retry rejected emissions, and advance timestamps after partial rejection. Stop all samplers before device teardown.
- Add CI coverage and refresh affected Slice benchmarks.

`_rmem_bp` now inverts the active-high ready bit; account for this polarity change when comparing older traces. Unthrottled MMIO can perturb the workload. Sampling cannot guarantee every transition is captured.

## Test plan

- Format, lint, lint-notes, direct Nix lint-toolchain check, and full build: passed.
- Three sampler guard-page cases and three Rinzler flag cases failed before their fixes. The tracer binary now passes 34 cases and 1,276 assertions; all 110 wrapper tests pass.
- CI-equivalent Slice tests: 782 passed, 2 skipped. Refreshed `t_fpga_tracer` benchmarks at 1, 2, and 4 slices.
- Developer host gate (`--exclude-tag slow`): 86 passed, 0 skipped, 0 failed.

Earlier hardware validation at `edff02db`:

- Two FPGA suites each passed 48 tests and failed `t_mwaitx` at its timing bound (#1516). An isolated rerun passed; full-suite QA remains failed.
- Paired captures kept the mailbox near 100 µs while register cadence changed from 11.087 µs to 1.020 µs. Both inference requests completed without reported trace loss or sampler drops.
- All 53,502 decoded emissions matched. One of 260,166 held-value checks failed at the final weights group, consistent with documented partial emission at gate closure. The strict failure remains disclosed.

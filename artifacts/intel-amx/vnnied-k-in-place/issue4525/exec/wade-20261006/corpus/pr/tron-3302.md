> **Overview**
> Adds **`.github/workflows/benchmark-only-pr.yml`**, a temporary GitHub Actions path that runs PR benchmarks **without** the main lint/build/test CI graph.
> 
> **Triggers:** `pull_request` on `labeled`, `synchronize`, and `reopened`. Jobs run only when the PR has the **`dev-benchmark-only`** label, the author is **`mcherba`** or **`Wado-posi`**, and (for `labeled` events) the label added is that one—not other labels.
> 
> **`benchmark` job:** Same self-hosted matrix as existing PR benchmarks (`2x96core` / `2x72core`), including cache check, `uv` sync for torch export when needed, FUSE mount, **`bin/ci/ci-run-benchmark.sh`**, and cleanup.
> 
> **`benchmark-report` job:** After benchmark success or failure, generates the unified report via **`bin/ci/generate_benchmark_report.sh`** and posts or updates the standard “### Benchmark of” PR comment.

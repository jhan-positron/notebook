## Summary

Long-pole implementation drop for the GoF/Shard merge. Lands
`src/tron/gof.cpp` (shard ctor/`xfer_gof`, `gof::populate`) plus the
pos-side infrastructure it depends on. 18 files, organized in two
layers:

- **Layer 1 — h/ infrastructure**: `h/libpos.hpp`, `h/pos/config.hpp`,
  `h/pos/device.hpp`, `h/pos/dma/queue.hpp`, `h/pos/hwattention.hpp`,
  and new `h/pos/device_dma_tracker.hpp` — extends `hw_attn_params`,
  introduces `dma_xfer_state`, virtualizes `xfer`/`xfer_blocking`/
  `isdone`/`wait` on cacheblocks, adds the `device_dma_tracker`
  singleton.
- **Layer 2 — src/ implementation**: new `src/tron/gof.cpp` and
  `src/pos/device_dma_tracker.cpp`; updates to
  `src/pos/{hwattention,driver,device,dma,dma_queue,fake}.cpp`
  matching the header changes; 1-line CMake add for `gof.cpp`.
- **Tests**: `t/t_dma.cpp`, `t/t_mwaitx.cpp` — call-site updates for
  the new `dma_xfer_state` return type from `xfer_blocks`.

## Stub note

`gof::backfill_shard` is intentionally a no-op in this PR (empty body,
parameters commented out, `TODO` comment). The full implementation
walks the scheduler tree via `node_base::tree_parent` /
`tree_height` / `tree_edge_gals` — APIs added in a separate later
patch. No caller in this PR's scope reaches `backfill_shard` (its
only invoker lives in code that depends on those node_base virtuals
that don't exist on main yet). The function declaration in the
already-merged `h/tron/gof.hpp` matches.

## Debug-flag scrub & cleanup (applied during review)

`src/pos/device.cpp` previously had `#define DEBUG_INIT 1` plus
`#ifdef DEBUG_INIT`. Because the macro is always defined, the
`#ifdef` guard was unconditionally true regardless of value — the
debug code was active in every build. Fixed two ways: value flipped
`1` to `0`, and guard changed to `#if DEBUG_INIT` so the value
actually gates compilation. The neighbouring `DEBUG_RESETS` /
`DEBUG_VFIO` macros were converted to the same `#define X 0` + `#if X`
form for consistency.

Two debug-only value bumps that landed in the source branch were
reverted here so they do not propagate to main:

- `maxpolls`: back to `1e9 / timeout_ns` (~1 second), was 100×.
- `max_xfer_time_in_ns`: back to `100000000` (100 ms), was 10 s.

Other small cleanups applied during review:
- Five commented-out `wqentry` fields removed from the public
  `h/pos/device.hpp` struct.
- Three `#if 0` / commented blocks removed from `src/pos/device.cpp`
  (pseudochannel debug print, init register dump, three
  `wcmd/acmd/mdwd` req-id allocations).
- Bounds-check assert added on
  `device_dma_tracker::await_layer`'s `layer` arg, mirroring `push()`.
- Unused `nlohmann_json` link dropped from `pos` and `pos_fake`.
- TODO comment on `fake_devices` null-deref hazard.
- Move-ctor / move-assignment comments on `DmaQueue` extended to state
  the quiescence invariant the relaxed atomic loads rely on.
- One-line comment on `t/t_dma.cpp`'s `kv_xfer = true` to record why
  the kv path is the right one to exercise post-refactor.

> [!NOTE]
> **Medium Risk**
> Changes default inference path from model-specific HW-attn defaults to software attention unless `USE_HW_ATTN=1`, which can affect performance and behavior wherever callers relied on `default_enabled`.
> 
> **Overview**
> **Hardware attention is now off unless explicitly enabled via `USE_HW_ATTN=1`.** Previously, leaving `USE_HW_ATTN` unset meant `fwd_hw_attn_enabled` fell through to each caller’s `default_enabled` argument; unset now behaves like an explicit off and returns `false` from the one-time env read.
> 
> Documentation in `hw_attn_config.hpp` is updated so unset is listed alongside `USE_HW_ATTN=0` as disabling HW attention for all models. Toggling back on remains a single env var (`USE_HW_ATTN=1`).

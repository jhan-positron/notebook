Implement the low level checks and paths for weight load reuse.  Plumb the legacy path up (also enables for HW attention partly, but the tests etc are disabled still until the CI machines have an updated bitfile with the proper fixes waiting on FPGA for a new bitfile release with one additional fix in it)  Also adds FUSE stats to check counts of times we take the reuse path.

> [!NOTE]
> **High Risk**
> Changes FPGA weight-command semantics on the hot TX path; incorrect reuse would produce wrong matmul/attention results, though HW-attn reuse stays off by default.
> 
> **Overview**
> Adds **weight load reuse (WLR)** in `hw_prepare`: when consecutive jobs use the same weights, the driver can send weight commands with **`hbm_stride=0`** instead of reloading from HBM.
> 
> **Legacy matmul** compares a normalized weight-command identity (excluding rotating `wmem_sect`), allows reuse only for **`hbm_cnt` 1–2**, restores the resident `wmem_sect`, and undoes the `csector` ping-pong flip on the reuse path. **HW attention** reuse logic is implemented behind **`ENABLE_HWATTN_WLR` (default 0)** until the bitfile contract is validated.
> 
> `PosDevice` gains **`PrevCmdKind`** and cached prior wcmd state plus **`legacy_wcmd_reuse_count` / `attn_wcmd_reuse_count`**. **Soft reset** clears all WLR tracking and resets **`csector`**. **`pos_driver_register_fuse_stats()`** exposes per-device reuse counters under `/rinzler/stats/devices/<idx>/wcmd_reuse/{legacy,attn}` (wired in **rinzler** and **runtron**; no-op in **fake**).
> 
> Adds FPGA test **`t_weight_load_reuse`** for legacy reuse correctness; attention reuse test is tagged **disabled** pending CI bitfile.

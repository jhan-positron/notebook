## PR body (as it is now; may have been edited after the review)

Introduces a new path for writing K/V data into FPGA HBM using group-of-four (GOF) blocks. Tokens are accumulated into 4-token `gof_buffers`, promoted to immutable `completed_gofs` on completion (zero-copy swap), then DMA'd to HBM. The new path is gated by `TRON_SHARD_TEST` env var — when unset, the existing `save_k/v_to_hardware` path is used.

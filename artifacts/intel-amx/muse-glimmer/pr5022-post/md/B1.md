The mapping stays. Catch2 v3.7.1 does not exit with the count of failed assertions.

v3.7.1 standardised the exit codes. A run with a failed assertion always exits with 42, and 4 means only that every selected case was skipped [catch_session.cpp:37, :39, :350-356 of the pinned source]. Its release notes for 3.7.1 say "Assertion failures are now always 42". Both builds fetch that archive by hash [cmake/versions.cmake:26-27; t/CMakeLists.txt:5-6; flake.nix:1056-1058]. The exit code that counts failed assertions is the behaviour up to v3.7.0.

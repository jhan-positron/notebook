## traps
- Column halves: the test geometries have value heads of 80 columns (5 chunks, t_gated_delta_net.cpp:1278-1284) and 16 columns (1 chunk, generated plugin). Two equal 64-column halves exist only at 128. The slice rule must work for any whole number of chunks, including 1, or these equal-bytes tests fail or do not compile.
- The replay tests feed FP32 rows and a chain whose job ids are not ascending. A chain path that assumes bf16 rows, or that reads rows by ascending job id instead of chain.order, fails t_gated_delta_net.cpp:2098.
- A head-group work item must write only its own group's checkpoint bytes, history runs and output columns. check_only_replay_group_written and the -1024.0f sentinel catch any wider write (t_gated_delta_net.cpp:2140-2157).
- Source and destination can be the same bytes for a multi-token chain (t_gated_delta_net.cpp:2208-2210). The chain path must copy the source into its buffers before it writes the destination.
- New chain buffers must not go into gdn_rolling_executor as direct members. The tests assert nothrow default construction and nothrow move, and the Note says default construction is allocation-free (gdn_rolling_executor.hpp:65-66). Put them in the heap-allocated working_set.
- step() must keep working for several tokens with access working_copy. Six rolling-executor cases call it directly (t_gated_delta_net.cpp:1633-1896).
- The abort tests expect SIGABRT from the TRON_ASSERTs of run_gdn_operation (gdn_execution.hpp:96-134). A new path that reads a malformed checkpoint span before those checks would end with another signal and fail the test.
- A new test target without a row in config/test-benchmarks.json passes configure and local runs, then fails CI at 'bin/slice bench --check'. Adding the file to an existing target (as t_attn_stats.cpp is in t_llama_unit) avoids the row.
- When FILES is passed to add_catch_test, the default <NAME>.cpp is not added. List it explicitly.
- Do not put a real model slug string (for example the Qwen3.5 slug) into a new test source. The configure-time audit fails unless the test declares it.
- Do not add AMX GDN tests to t_amx_dispatch_dtype. Its fakes replace the real amx_attn_h128g4 functions for the whole binary.
- Any new symbol that the 128 x 4 llama instantiation references and that only amx_attn.o defines makes the linker load amx_attn.o into t_amx_dispatch_dtype, which gives duplicate definitions of the 6 faked functions. Each such symbol needs a fake there. available() is already referenced unconditionally at self_attention.hpp:479.
- If the dispatch stops calling amx_attn_h128g4::available() (for example a shared probe for attention and GDN), the fake_amx_available switch of t_amx_dispatch_dtype no longer controls the test.
- The native preset leaves TRON_AMX_DISPATCH off. A plain 'make t_amx_numerics' builds the SUCCEED-only variant. Pass -DTRON_AMX_DISPATCH=ON as build-3b35.sh does.
- AMX kernel cases use WARN and return on a host without AMX. They pass without testing anything. AGENTS.md demands that every committed test runs in CI, and src/tron/CMakeLists.txt:216-217 still carries a TODO to make one real-AMX execution a required check.
- Code in amx_gdn.cpp that can run when available() is false (a fallback, a split helper exposed for tests) must execute no tile instruction, including LDTILECFG and TILERELEASE in a region bracket.
- Three comments say amx_attn.cpp is the only TU with the AMX flags (src/tron/CMakeLists.txt:210-211, amx_attn.cpp:2-3, amx_attn_iface.hpp:4-5). They become false with amx_gdn.cpp.
- A Note [..] reference to a name that is not defined fails 'make lint-notes'. A Note definition needs the ~~~ rule, the closing bracket on the same line, and a name of 5 or more characters.
- C++ library features newer than libstdc++ 12 fail the .deb build even if the local build passes: <format>, <print>, ranges::to, ranges::contains, std::expected monadic calls.
- Naming conflict: the user's guide asks for NAME_<value> constants, the user's memory limits them to AMX kernel files, and the GDN files use lower_snake constexpr names. Use NAME_<value> in amx_gdn.cpp / amx_gdn_iface.hpp and the local idiom in gated_delta_net.hpp, gdn_rolling_executor.hpp and gdn_execution.hpp.
- ctest runs every test binary with --benchmark-samples=2, so a new BENCHMARK case runs in every CI pass. Keep it cheap.
- A 128 x 128 executor test needs big buffers. One checkpoint of the full Qwen geometry (16 key heads, 32 value heads) is 2,195,456 bytes (computed). Allocate on the heap with chunk alignment, as the benchmark at t_gated_delta_net.cpp:1234-1236 does for the state.
- The 3b35 recipe build does not contain t_generate_mock_plugin. A green t_gated_delta_net there does not cover the generated-plugin path with 128-token chains at 1 chunk per value head.

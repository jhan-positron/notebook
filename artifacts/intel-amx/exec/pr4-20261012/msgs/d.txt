chore(bench): refresh the cost rows of the VNNI K tests (granite_rapids_6962p)

Words used here. config/test-benchmarks.json holds, per host block, the
measured run time of every test binary at 1, 2 and 4 slices (the test
tool's parallel lanes), which bin/slice uses to place the tests.
granite_rapids_6962p is the block of the test host delphi-3bda (Intel
Xeon 6962P). TRON_AMX_DISPATCH compiles the AMX attention kernels.
TRON_K_VNNI stores the K cache in the VNNI layout.

t_amx_dispatch_dtype ran on the whole delphi-3bda host (serving
stopped, both sockets) on 2026-10-13 00:16 UTC at ea94e95a4e, the
three-commit head of this branch, built with TRON_AMX_DISPATCH=ON and
TRON_K_VNNI=ON. It rewrote the four rows of the granite_rapids_6962p

t_amx_dispatch_dtype: literal default arguments, the named bools next to their calls

Coding-guide rule (jhan, 2026-10-15): a named constexpr bool only where it
is passed as a call argument. The three default arguments of exercise_page
take the literal, and RECORD_ROWS_TRUE, which had no call-site use, goes.
The four constants that remain are used only inside the TRON_AMX_DISPATCH
test case, so they move into that block: without the move the no-dispatch
syntax cells warn about four unused constants (measured), with it about
none, two fewer than before.

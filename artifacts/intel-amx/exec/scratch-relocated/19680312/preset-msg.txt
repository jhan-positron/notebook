CMakePresets: the deb preset compiles the VNNI K layout

The deb preset (the package the nightly installs and the release builds
use) sets TRON_K_VNNI=ON next to TRON_AMX_DISPATCH=ON. So the layout this
PR measures reaches the released package. README.ci.md says which presets
set the option. The package of the 2026-10-09 nightly-config measurements
was built with this line.

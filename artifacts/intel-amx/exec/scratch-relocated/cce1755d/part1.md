## Short version

PR-4 is the fourth and last of four stacked PRs that replace PR 4424. It keeps a 16-token block of the packed K cache row-major until the block's 16th row is saved, converts the block to the VNNI layout at the end of that forward pass, leaves the blocks of FPGA-scored operations row-major, and turns the layout on in the released Debian package. That removes the per-token 64-line scatter of every decode step (the FPGA-attention decode loss of issue #4500) and restores token identity with main under CPU attention in the measured cells. Your job: build the branch jhan-vnnik-4-tail-block on jhan-vnnik-3-shared-save from the two prepared patches (five conflicting files, five blocks, each resolved by exact text, plus one one-line edit), run the syntax checks on claude-box, build and test on delphi-3bda (the unit tests, the smokes, the cells including two FPGA-attention cells, the host suite, the cost-row refresh and the 8-hour whole-machine nightly-configuration campaign), write the body, and open PR-4 as a draft on jhan-vnnik-3-shared-save.

- K cache: the stored key vectors of past tokens. KV page (also "page"): a 64-token block of the K and V caches. Plane: the packed K storage of one page and one KV head (16 KiB). kv_mul: the number of query heads that share one KV head. bf16: the 16-bit brain floating-point format. fp32: the 32-bit float format. dword: a 4-byte unit. Line: a 64-byte CPU cache line.
- Slot (KV slot): one persistent K/V storage region (Note [KV slot retention] in h/tron/models/kv_cache.hpp). VNNI slot: a slot whose K planes hold the VNNI layout; with the option on that is every slot of 128-dimension heads (the layout gate k_vnni::layout_on<head_size>, a compile-time constant). Row-major slot: a slot that stores K as one row per token.
- AMX: Intel Advanced Matrix Extensions, the tile instruction set. AVX-512: the 512-bit vector instruction set. VNNI layout: the pair-interleaved operand layout (two consecutive dimensions of one token adjacent; one 64-byte line holds that pair for 16 tokens). Panel: one 1 KiB block of the plane, 16 dimension-pair rows x 16 tokens. Token block (also "block"): 16 consecutive tokens of a page (4 per page; block c holds the page offsets c * 16 to c * 16 + 15). Dimension step: 32 dimensions (4 per 128-dimension head). The plane holds 4 steps x 4 token blocks = 16 panels.
- The option: the CMake switch TRON_K_VNNI (off in every preset until PR-4; PR-4 turns it on in the deb preset only). AMX dispatch: the CMake switch TRON_AMX_DISPATCH that compiles the AMX attention kernels (on main since PR 3879; on in the deb preset since PR 4505). Kill switch: the environment variable TRON_AMX_DISABLE=1, which makes amx_attn_h128g4::available() false at run time, so no AMX kernel runs.
- deb preset: the CMake preset named "deb" in CMakePresets.json that builds the released Debian package (`make deb`, outside nix). Preset: a named CMake build configuration. The released package: the deb that the nightly installs and that production serving runs.
- The kernel: qk_vnni_128x4 (PR-2), the AMX QK (query-key score) kernel that reads a whole page's plane as its B operand; it runs only on a dense page (a full 64-token page that the query sees whole). The reader: k_vnni::qk_group (PR-1), the AVX-512 loop that scores the VNNI blocks of a page, one token per vector lane. Dotter: the row-major QK loop of main, one dot product per token; with PR-4 it also scores the rows of a row-major tail block of a VNNI slot.
- save_k: the function of h/tron/models/model.hpp that stores one pass's K rows into the cache, once per (layer, pass). Pass: one forward computation of the model over its current input. Prefill: the pass that processes the prompt tokens, many tokens per pass. Decode: the passes that follow, one generated token per user per pass. Minibatch (also "the batch"): one group of a pass's items; a generated plugin has one minibatch per pass. - Block save (PR-3): store_block (h/tron/tensor/k_vnni.hpp) writes the K rows of one 16-token block as whole 64-byte lines after a register transpose; page::set_k_block is the page accessor. - Row-major tail block (PR-4): a 16-token block of a VNNI slot whose rows are stored row-major (one contiguous 128-value row per token, 4 lines, inside the block's own 4 KiB) until all 16 rows are saved. Note [Row-major tail block] in h/tron/tensor/k_vnni.hpp describes it. Run: consecutive items of a pass that fall into one block of one page. PR-4's store_k_block rule: a run of 16 tokens that fills its block takes the block save (set_k_block, VNNI at once); a shorter run is stored row by row (set_k_row) into the block's row-major form.
- Saved-row bits and converted-block bits (PR-4): per slot and page, one bit per token row that says the row was saved (k_rows_saved_), and one bit per block that says the block holds the VNNI layout (page::k_vnni_blocks). note_k_row_saved sets a row bit and returns true when it completes the block's 16 rows. note_k_block_saved sets all 16 row bits and the block bit after a whole-block save. Pending block: a block whose 16th row a pass saved row-major; save_k queues it (pending_k_blocks_, main thread only) and convert_pending_k_blocks converts it at the forward end. block_to_vnni and block_to_rows (tensor/k_vnni.hpp): the in-place conversions of one block between its row-major and its VNNI form, bit-identical to store_row per token. row_major_row: the typed row view of one token of a row-major block, 4 lines. k_row_if_row_major: the page accessor that returns a token's row-major row when its block is row-major (the FPGA staging reads it directly). k_forget_row: clears a row's saved bit (and the block's converted bit when the block was converted, after block_to_rows) when a token is forgotten.

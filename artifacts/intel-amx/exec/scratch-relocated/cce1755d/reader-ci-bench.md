## Words used here

- Cost row: one line of config/test-benchmarks.json per test binary with its run time in seconds and peak memory in MB at 1, 2 and 4 slices. Platform block (also host key): the top-level JSON object of one machine type, for example granite_rapids_6962p. Slice: tron's test scheduler, bin/slice. Width (also slice mode): the number of FPGA slices a test run is placed on. Fake test: a test linked against the device fake (CMake label `fake`), which needs no FPGA card.

Lease: the file the nightly CI writes to claim delphi-3bda. Marker: /bill-has-instance-0,2. Serving: the rinzler@N production units.
- Draft filtering: the rule of gcp-nix.yml that runs only a subset of jobs on a draft PR without the label "Run CI". Note: a named comment block (`Note [Name]` with a tilde rule under it) that lint-notes checks.

## 7. The CI bench checks, bench_refresh*.py, and what a stale or missing row causes

- Build Tron runs `bin/slice bench --check-platform` before the build [gcp-nix.yml:487-488] and `bin/slice bench --check` with the portable manifest after it [gcp-nix.yml:502-505]; the legacy workflow does the same [cmake-single-platform.yml:191, 362].
- `--check-platform` fails when the current host's block is absent, incomplete, or has duplicate names [bin/slice:1917-1946]. `--check` fails when the manifest is empty, when the current block fails the platform check, when any complete block has duplicate names, or when a manifest test has no valid row in any block ("missing from every platform") [bin/slice:1949-1989, 1973-1978]; a test missing only from the current block is a warning [1980-1985; bin/slice_bench_manifest.py:100-119]. Neither check compares time or memory values. A stale row therefore cannot fail CI.
- What a stale row does at run time: `bin/slice run` packs the schedule from the rows [bin/slice:1333-1451] and prints "Drift detected" when a test's duration differs from its row by more than 30 % or the makespan by more than 20 % [bin/slice:117-118, 3179-3205]. Metadata differences (labels, min_slices, skip codes, filter) print a warning and the manifest wins [1259-1316].

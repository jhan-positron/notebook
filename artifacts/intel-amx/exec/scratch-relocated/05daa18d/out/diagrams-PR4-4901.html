Short version

PR #4901 is the last of the four PRs that split PR 4424: a 16-token block of K rows (saved key vectors) stays row-major (one contiguous row per token) in its own 4 KiB until its 16th row is saved, and the block is converted to the VNNI layout (the value order the AMX kernel reads) at the end of that forward pass. Under hardware attention (attention scored on the FPGA card) a block that decode completes stays row-major, and the deb preset (the build configuration of the released package) turns the layout option TRON_K_VNNI on. The page introduces the PR's three data models (the row-major tail block on KV_CACHE-B2, the page's saved-row and converted-block bits and the storage reference on KV_CACHE-B1) and the mechanisms that use them (the in-place conversion on K_VNNI-B4, the life of one block on KV_CACHE-B4, the save_k decisions and the hardware-attention policy on MODEL-B5, the thread order on KV_CACHE-B5 and K_VNNI-B5, every reader and writer on KV_CACHE-B3 and K_VNNI-B3), and seven context diagrams carry what PR #4868, #4887 and #4898 built.

Words used here

AMX
Advanced Matrix Extensions, the tile instruction set of the CPU. The kernel qk_vnni_128x4 reads a page's VNNI plane in place as its B operand (the second matrix of one tile multiply).
attention workers
The pool threads that run the attention kernels of a layer. They read a pending page only after every minibatch that writes it counted its latch (upstream_kvs_ready, a countdown) down.
band (noise band)
The noise band of the PR body's Performance section: twice the larger of the two binaries' sample standard deviations over 3 repetitions, never smaller than 0.4 TPS or 0.15 s. A difference beyond it counts as a change.
bf16
The 16-bit brain floating-point format of the stored K values. One 128-dimension K row is 128 bf16 = 256 bytes.
block (16-token block)
Page offsets 16 c .. 16 c + 15 of a plane, 4 KiB. A 64-token page has 4 blocks (c = 0..3).
block bit (converted-block bit, k_vnni_blocks_)
One bit per block and storage slot, kept in the page and set when the block holds the VNNI layout. Every reader and writer of a row takes the row's layout from it.
book
The struct that owns one KV cache allocation (h/tron/models/kv_cache.hpp:942). A page is a lightweight reference into it.
cache line (line)
64 bytes, the unit the CPU moves between memory and its caches. A row-major row is 4 whole lines. A VNNI column is 4 bytes in each of 64 lines.
conversion (block_to_vnni, block_to_rows)
The in-place rewrite of one block between its row-major form and its VNNI form, in h/tron/tensor/k_vnni.hpp. page::k_block_to_vnni_at runs block_to_vnni for every KV head of a storage slot and then sets the block bit.
deb preset
A preset is a named CMake build configuration, and the deb preset builds the released Debian package. This PR sets the option TRON_K_VNNI on in it, next to TRON_AMX_DISPATCH (AMX dispatch, the CMake option that compiles the AMX kernels).
decode / prefill
Prefill is prompt processing (many tokens per user per pass). Decode is one generated token per user per step.
dense page / dense gate (k_layout_dense)
A dense page is a full 64-token page that the query sees whole. The dense gate k_layout_dense in self_attention.hpp lets the kernel score a page only when every block of the page is converted (page::k_vnni_blocks equals BLOCKS_PER_PAGE_MASK_0XF, all 4 bits).
dotter
The per-token dot product of the main branch over one row-major row (struct dotter in h/tron/kernels/dotter.hpp). From this PR it also scores the rows of a row-major block through their typed row row_major_row.
EAGLE storage / EAGLE entry / EAGLE view
The separate K/V storage view of EAGLE speculative decoding (a draft-model technique). While it is selected, logical slot 0 addresses the extra physical slot and the extra K layout state entry (index layout_t::n_slots).
forward end
The point of a pass after the plugin's run() joined its workers and the cooperative staging drained (wait_for_coop_gof). convert_pending_k_blocks converts the blocks the pass completed there.
fp32
The 32-bit float format in which the score kernels add. The row-major dotter and the reader add in a different order.
FPGA
Field-programmable gate array, the card that scores hardware attention.
GOF / staging
A GOF is a group of four consecutive tokens, whose K and V rows the staging (gof::populate) copies into a buffer that DMA (direct memory access) moves to the FPGA card. Cooperative staging is that work done by idle attention workers (help_drain_gof) and by the main thread (wait_for_coop_gof).
hardware attention
Attention scored by the FPGA over the K/V it holds. cached_operation_uses_hw(operation) says, once per model, whether an operation's K is scored there.
issue #4500 / issue #4934
Issue #4500 records the FPGA-attention decode loss of the per-token 64-line column for the model qwen3-4b: 2.2 % at tp2 and 9.7 % at tp4 (tp2, tp4: the model split over 2 or 4 shards, tensor parallelism). Issue #4934 tracks the decode slowdown of this PR against its parent with the kill switch.
k_storage_ref / state entry (k_state_ix)
k_storage_ref pairs a physical storage slot with the index of its K layout state. k_state_ix maps logical slot 0 to the EAGLE entry while the EAGLE view is active, and to the slot's own index otherwise.
kernel (qk_vnni_128x4)
The AMX routine of PR #4887 that scores one dense page from the VNNI-packed plane, with the query pack as its A operand (the first matrix of the tile multiply).
kill switch (TRON_AMX_DISABLE)
TRON_AMX_DISABLE=1 stops the AMX kernels at run time. The layout stays, and the reader scores the VNNI blocks.
KV head / kv_mul
One key/value head. kv_mul is the number of query heads that share one KV head (the query group).
KV page / page
A 64-token unit of the KV cache. The page struct keeps the per-token save counters and, from this PR, the two K layout bit sets.
layer
One transformer layer. In the uniform topology (every slot shares one geometry, one logical slot per layer) the cache has one logical slot per layer.
main (branch)
The main branch of the tron repository, the base of PR #4868. In the labels of this page, '(from main)' means the code existed before the stack.
main helpers
Helper threads of the main thread in the generated plugins (worker_ix 1 .. n_workers - 1). PR #4898 lets them share the K store window.
main thread
The thread that runs the serial part of a forward pass (worker 0 of a generated plugin). Only it records the row bits of the runs shorter than a block (note_k_row_saved, after the join) and converts the queued blocks at the forward end.
minibatch
One chunk of a pass's token jobs that the forward runs together. A block may be split across two minibatches of one pass.
mutation check
A deliberate code change that the named test must fail on. The PR body reports three.
Note [name]
A named comment block in the tron source. Other comments refer to it by this name.
option (TRON_K_VNNI)
A CMake option that selects VNNI-packed K storage for every 128-dimension head through the gate k_vnni::layout_on. It is off in every preset except, with this PR, the deb preset.
parent (the parent PR)
PR #4898, the base of this PR. The PR body's Performance section compares against it under the name head.
pass (forward pass)
One forward() call that runs every layer for one step's tokens. The forward end is its last part on the main thread.
pending list (pending_k_blocks_)
The std::vector of {page, k_storage_ref, block} entries that save_k fills on the main thread, one per row that completes an unconverted block. convert_pending_k_blocks drains it at the forward end.
plane / panel / pair row
A plane is K for one KV head of one page (64 tokens x 128 dimensions of bf16 = 16 KiB), and a panel is 1 KiB of it for one 32-dimension step and one 16-token block. A pair row is one 64-byte line of a panel that holds one dimension pair for 16 tokens.
PR
A pull request of the tron repository. The stack is PR #4868, #4887, #4898 and #4901, each based on the one before.
prompt 1,024 tokens
The prompt length of a benchmark cell, passed as runtron --prompt-length. Every run then generates 256 tokens.
reader (k_vnni::qk_group)
The AVX-512 (the CPU's 512-bit vector instruction set) routine of PR #4868 that scores a query group against the tokens of a page whose bit is set in its live mask (a 64-bit mask, one bit per page offset), one token per vector lane. From this PR every block with a live bit must hold the VNNI layout, so the caller keeps the bits of a row-major block clear and scores those tokens with the dotter (h/tron/kernels/k_vnni.hpp:43-46).
row-major
One contiguous row of 128 bf16 per token. Every head size other than 128 keeps this layout, and a row-major block inside a VNNI plane holds its rows this way.
row-major tail block
A 16-token block of a VNNI plane whose rows are stored row-major until all 16 rows are saved. Token t of block c owns 256 contiguous bytes at row_major_row, in panel (t / 4, c), row t % 4.
save_k / save_k_impl / store_k_block
save_k (two overloads in h/tron/models/model.hpp:3465, 3476) stores the K rows of one minibatch into the KV cache once per layer and pass, through its body save_k_impl (3351), which every worker of a shared window calls. store_k_block (3244) stores one run of consecutive tokens inside one block, whole or row by row.
saved-row bits (k_rows_saved_)
One bit per page offset and storage slot, kept in the page, set when the K row at that offset is saved. note_k_row_saved sets one bit, and note_k_block_saved sets the 16 bits of a block at once.
storage slot
The physical storage of one persistent K/V storage region (kv_storage_offset). A logical slot (kv_slot_id) maps to one under the active view.
TPS
Tokens per second, the decode throughput measure of the PR body's Performance section.
tree lock
The lock on the scheduler's token tree, which the scheduler thread (the thread that runs the scheduler of full.hpp between forward passes) holds for clears (clear_kv_complete_at) and page copies (copy_from). No forward pass reads the book meanwhile.
tron
The inference program under test. runtron is its command-line tool.
VNNI / VNNI-packed
Vector Neural Network Instructions layout, the B-operand layout of the AMX tile multiply: the two values of one dimension pair of a token sit side by side, and one 64-byte row holds that pair for 16 consecutive tokens. VNNI-packed is the storage sense of packed.
whole-block save (set_k_block, store_block)
The store of a run of 16 tokens that fills one block, written directly in the VNNI layout (PR #4898). This PR drops its mask parameter and makes the caller publish the block's bits with note_k_block_saved.
window (k_store_window) / work unit / join
The shared K store of one minibatch (PR #4898): the main thread cuts the items into work units (runs inside one block of one page) and opens the window, and every thread of the window, main included, claims units. Main then joins: it waits until every helper has finished, and only then records rows.

The fix keeps an incomplete 16-token block row-major in its own bytes, converts it once at the forward end, and never converts the blocks that decode completes under hardware attention.

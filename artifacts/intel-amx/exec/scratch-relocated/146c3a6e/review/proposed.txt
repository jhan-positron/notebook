// `lane` of u[0..3][k], which holds tile column 4 * lane + k for tokens
// 4 * row_group .. 4 * row_group + 3. The shuffle selectors are immediates,
// so `lane` is a template argument.
// A 128-bit lane holds 4 fp32 values: 4 output rows per lane.
  // Stage 3 pairs row groups 0/1 and 2/3: lanes {0, 2} or {1, 3} by bit 0.
  // Stage 4 joins the two pairs: the first or the second lane by bit 1.
  // One scratch per instantiation, so a 16-head call's rows never reach a 4-head call.

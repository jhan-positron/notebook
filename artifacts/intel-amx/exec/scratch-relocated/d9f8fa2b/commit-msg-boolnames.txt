Name the boolean flag values of the new code

The C++ coding guide counts true and false as literal values. Commit
1c87d66926 named only the numeric values, and 39 boolean literals stayed
on 28 lines this PR adds. Each one now refers to a named constexpr with
its value in the name.

- kv_cache_fwd.hpp: VIEW_ALIGNED_TRUE and VIEW_DMA_FALSE, the values of
  the aligned and dma template flags of view and const_view. The native
  K aliases use them. Every file that passes these flags already sees
  this header, directly or through kv_cache.hpp and v_vnni.hpp.
- kv_cache.hpp, v_vnni.hpp, model.hpp, full.hpp and four tests: the
  typed V rows, the V plane views and the test rows pass the two names.
- kv_cache.hpp: book::RECLAIMABLE_FALSE and book::RECLAIMABLE_TRUE
  replace the /*reclaimable=*/false and /*reclaimable=*/true arguments
  of construct_kv_blocks.

The names hold the same values, so every view type and every template
instantiation stays the same. Lines unchanged from main keep their
literals. The literal 0 and 1 cases on added lines (unit strides, first
indices, loop starts, comparisons) are not part of this commit.

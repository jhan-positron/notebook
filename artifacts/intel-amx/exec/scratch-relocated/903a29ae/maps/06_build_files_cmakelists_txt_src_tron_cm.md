## design_contradictions

The limited 8-lane child check must use TRON_K_VNNI=OFF ... Report packed K at 8 lanes as not applicable.' On origin/main this is moot: 8d64eeed81 removes the AVX512 option and the chunk-8 typedefs (origin/main:h/tron/simd/auto.hpp:17 is the only TRON_CHUNK_SIZE definition, value 16) and bbc702251e removes every 8-wide branch from kv_cache.hpp, self_attention.hpp and t_llama_unit.cpp. Following the design here adds code that the later main merge must delete again.

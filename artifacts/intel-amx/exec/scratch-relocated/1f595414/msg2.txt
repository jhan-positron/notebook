Name the AMX tile numbers in the attention kernels

qk_rowmajor_128x4 and weights_times_v_128x4 passed tile numbers as bare
literals with inline /* dest tile */ comments. Each tile number is now a
named constexpr with its value in the name:

- ACCUMULATOR_TILE_0..3: the tiles _tile_dpbf16ps adds its products
  into, in both kernels.
- QK kernel: K_EVEN_BLOCK_TILE_4, K_ODD_BLOCK_TILE_5, Q_TILE_6.
- PV kernel: P_TILE_4, V_EVEN_SLICE_TILE_5, V_ODD_SLICE_TILE_6.

The "+ 0" in the first V slice offset is removed.

The names work because tron builds this file with clang++-19, whose tile
intrinsics take constant expressions. GCC's headers paste the argument
into the assembly text and would need literals.

Verified on delphi-3bda: the file compiled with the tree's own command
(clang-19, AMX flags) before and after the change gives identical
disassembly (940 lines, 96 AMX tile instructions). The later rename of
the accumulator constants changes names only. clang-format 19.1.7 and
git diff --check are clean.

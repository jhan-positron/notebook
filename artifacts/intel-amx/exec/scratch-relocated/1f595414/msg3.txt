Rewrite Note [KV block lifetime] in plain words

Comment change only, in kv_cache.hpp. The Note now says why
construct_kv_blocks exists. The cache calls member functions of
v_vnni_tensor on arena bytes, and C++ allows that only on objects whose
lifetime has started. The ::new line starts it without writing any
bytes, and it compiles to no instructions. The Note ends with the two
things the function does: it avoids that undefined behavior, and its
asserts check the block type and the arena size.

The per-geometry details (one array per arena or per slot, restore
scope, view expiry) are removed from the Note. The code of
construct_kv_blocks still shows them.

• Where the vnni binary came from. runtron.vnnik5 was built from commit d5b59b1101 (2026-09-16 00:09 UTC). The worktree was then moved to 65a1c41d72, a change to one test file. Only libversion.so was relinked. So the runtron file kept its sha256 (7f508484...). Its "Version:" log line, however, says 65a1c41d. The PR head ff680c8020 adds one JSON row of cost data to 65a1c41d72 and no C++. The base and headoff binaries were built by this campaign. Their build records are in section 3.1.
  • No AMX-on / AMX-off pair. The AMX kernel serves head size 128 with kv_mul 4 (amx_attn_iface.hpp shape_ok). qwen-3-30b-a3b has kv_mul 8. So the AMX path for dense pages (a full 64-token page that the query sees in full) is never compiled in for this model. TRON_AMX_DISABLE=1, the runtime switch that turns AMX off, changes nothing. All three binaries run the software attention path for this model.
  • Why headoff is the gate's stand-in. The layout gate is a compile-time constant (k_vnni::layout_on, TRON_K_VNNI). A gate on kv_mul 4 would leave qwen-3-30b-a3b on row-major K with the PR's other code (save_k with a worker count, save_k_helper calls that return at once, the k_head_fn scratch parameter). A build of the PR head with TRON_K_VNNI off runs exactly that code for every model. So headoff measures the gate's outcome for this model without writing the gate.
  • Log level. The cells ran with TRON_LOG_LEVEL=debug and SPDLOG_LEVEL=debug. That is the convention of the qwen3-4b campaigns of PR #4424. It is also the default of the nightly. The 2026-09-15 one-run cell used TRON_LOG_LEVEL=info. The smokes and traces use info.
  • Machine sharing. The marker file /bill-has-instance-0,2 was present. So the first half of delphi-3bda belonged to the other user during the runs. Every run recorded his process count (rt-results.txt machine line). Our runs used CPU socket 1 and cards 90/93 (tp2) or 90/93/b9/bc (tp4).
  • Chart colors.
    • The colors come from the reference palette of the dataviz chart-design guide used for this report: its first color (blue) for headoff, its second (orange) for vnni, and a neutral gray for base, the control binary.
    • The guide states that its first three colors pass its color-vision checks (simulated red-green color blindness) for every pair of the three. The guide's validator script runs under Node.js (a command-line JavaScript runtime). The container this report was written in (claude-box) does not have Node.js. So the validator was not run here.
    • Every bar and dot carries a direct value label, and every chart has a table. So no reading depends on color.
  • Traces. One traced run per binary and tp. Trace overhead on the earlier qwen3-4b runs was 0 to 3% of TTFT. The traced runs generate 32 tokens (not 256) and are not part of the TPS/TTFT cells.
  • Dry runs. summarize.py, compare_tokens.py and gen_report.py were exercised on synthetic data before the campaign. analyze.py reproduced the 2026-09-14 numbers on the earlier qwen3-4b trace (Save K 273.6 us per layer in prefill) before the KV-head count was changed to 4 for this model.

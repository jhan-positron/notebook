+Example of a casual group: the attention path statistics under
+`/model/<model_id>/attention/` (`h/tron/models/attn_stats.hpp`). They
+say how much of a model's attention work ran on the AVX software loop,
+the AMX kernel and the FPGA, per layer and per pool worker, with
+the attention time per job and per forward. Collection is off unless
+the environment variable `TRON_ATTN_STATS` is exactly `1` (read once at
+start); with it unset the leaves `summary`, `<class>_totals` and
+`<class>_forwards` still exist: `summary` reports `"on":false`, the
+other two read `{}`. With it set, the
+per-layer leaves `<class>_layer_<L>` and per-worker leaves
+`<class>_worker_<W>` appear as well, and one `[attn-stats]` summary is
+printed to stderr when the model state is destroyed (a batch runtron run
+ends before the tree can be read). `<class>` is `decode_like` (every
+token job of the forward had a listener) or `prompt_or_mixed`. Under
+continuous batching (rinzler adds and removes users between forwards, so
+one forward can mix a new user's prompt tokens with other users'
+generated tokens) a forward that carries one prompt chunk (the slice of
+a prompt that one forward processes) of any user is `prompt_or_mixed`.
+So `decode_like` counts pure-decode forwards only. `listener_jobs` and
+`kv_only_jobs` in `<class>_forwards` say how many token jobs of the
+class had a listener (every generated token has one, and so does the
+last token of a prompt chunk) and how many did not (prompt tokens that
+only stored their K and V). The three job counts of a forward
+(`token_jobs`, all token jobs of the class, plus the two above) are
+added together at the end of the forward. So a read during a forward
+does not show the two listener counts ahead of `token_jobs`, and
+`listener_jobs` + `kv_only_jobs` = `token_jobs` at every read except in
+the few instructions of the three adds. The stderr
+lines label the classes `decode_like/all_jobs_with_listener` and
+`prompt_or_mixed/some_jobs_without_listener`, name plus rule. Values
+count from the construction of the model state and carry no reset: an
+interval is the difference of two reads. Cycle counters are TSC ticks; `summary`
+carries `tsc_hz`. Software `k_tokens` count one KV head per visit;
+`fpga_k_tokens` count one query per pass for all KV heads at once, so
+`fpga_k_tokens_x_kv_heads` is the value on the software scale. An EAGLE
+draft state, which shares the target's model id, publishes under
+`attention_eagle/`. A later state of the same model id (runtron makes
+one per prompt batch) takes the leaves over, with one info line in the
+log, and prints its own summary at its end. After the last state is
+destroyed the leaves read `{}`. `W` in `<class>_worker_<W>` is the pool
+worker index. The attention workers of a forward are the last
+`n_attn_workers` pool workers (`n_attn_workers` is the number of
+attention workers the plugin chose for that forward, the split). The
+first rows belong to the main helpers (the pool workers the plugin keeps
+for the non-attention work) and read zero. A row stays on one thread
+across forwards even when the plugin changes the split.
+`n_attn_workers_min` and `n_attn_workers_max` in `<class>_forwards` give
+the range of the split over the run. The T3 and

+failed polls on the other workers' sections. T5 is inside T2
+(`busy_cycles`) in both modes. T2 minus T5 is compute plus fold.

+// Attention path statistics: how much of the attention work of one model ran
+// on each path (AVX software loop, AMX kernel, FPGA), per layer and per
+// attention worker, plus the time attention took per layer and per forward.
+//
+// Note [Attention path stats]
+// ~~~~~~~~~~~~~~~~~~~~~~~~~~~
+// Switch: the environment variable TRON_ATTN_STATS (an environment variable,
+// not a CMake option like TRON_PAGE_SHARE_COUNTERS or TRON_MWAIT_STATS).
+// Exactly "1" turns collection on (the same rule as TRON_AMX_DISABLE); unset
+// leaves it off, and any other value leaves it off with one warning in the
+// log. The variable is read once per process. Every hook is compiled into
+// every build. Off-state contract: a per-visit hook may test one bool that
+// was copied once per apply_page_range call and nothing else, no memory
+// write and no atomic. Per call the cost is one byte load and one stack tally.
+// Per job and per forward it is one branch. No row is allocated when the
+// switch is off.
+//
+// Unit of the path counters: one visit = one call of apply_page_tok, i.e. one
+// (query token, KV page, kv head) triple that passed the page-level checks of
+// apply_page_range. The AMX kernel serves a whole dense page (64 K tokens) per
+// visit. The AVX loop serves the relevant K tokens of the page. An empty visit
+// reached apply_page_tok and found no software work (the range belongs to the
+// FPGA, or every token of the page is outside the query's window). Pairs that
+// apply_page_range dismisses before the call (workless ranges, invisible pages,
+// whole-page window skips) are not visits. K tokens are counted per visit, once
+// per kv head, so the number of dot products is k_tokens times the number of
+// query heads per kv head (kv_mul).
+//
+// Timers, all in TSC cycles (summary carries tsc_hz): T1 = wall time of one
+// model forward, taken by forward_scope inside model::state::forward: from after
+// its perfetto slice to its return (the layers, logits and listener delivery,
+// and the latch arena release). T2 = busy time of one attention job on one
+// worker (run_attention_job's attn_elapsed: both passes and the join, without
+// the upstream K/V wait). T3 = wall time of one attention job as worker 0 sees
+// it (entry to return). T4 = layer period on worker 0: from its first job of one
+// attention operation to its first job of the next operation, so the last layer
+// of a forward has no period. T5 = time a worker spends waiting in the join with
+// no join progress. It is measured in both join modes. In a hardware join it is
+// the wait loop of stream_hw_joins, which ends when an FPGA pass or the peer
+// workers' software partials become ready. In a software-only join it is the
+// stretches of failed polls on the peer workers' sections in run_joins. T5 is
+// inside T2 in both modes. T2 minus T5 is compute plus fold.
+//
+// Rows: one row per (forward class, pool worker, layer). Only the owning
+// worker writes its rows, because apply_page_range runs on that worker. The
+// writes are plain load-add-store on relaxed atomics. The FUSE read callbacks
+// read the same atomics with relaxed loads. The FPGA counters and the
+// per-forward counters are written on the main thread with relaxed fetch_add.
+//
+// Forward class: decode_like when every token job of the forward has a listener
+// (one generated token per user, but also a one-token final prompt chunk or a
+// speculative verify step), prompt_or_mixed otherwise (prompt chunks, or a mix).
+// Under continuous batching (rinzler adds and removes users between forwards)
+// a forward that carries a prompt chunk of any user is prompt_or_mixed. So
+// decode_like counts pure-decode forwards only. listener_jobs and kv_only_jobs
+// in the forwards record say how many token jobs of a class had a listener and
+// how many did not.
+// One object, forward_scope, owns the per-forward record: its constructor stores
+// the class and sizes the per-forward scratch before the attention workers start
+// (begin_forward), and its destructor records T1, folds the path bits and adds
+// the three job counts after the workers, logits and listener delivery are done
+// (note_forward_wall, end_forward). The workers read the class once per
+// apply_page_range call. The per-forward scratch (path bits, FPGA bits, the T4 fields
+// of worker 0) is plain data because forwards of one model state are serialized: the
+// main thread writes before the workers start and reads after they have all finished,
+// and worker 0 is the only worker that touches the T4 fields.
+//
+// Output: casual FUSE leaves under /model/<model id>/attention/ (see
+// README.stats.md). The values count from the construction of the model state
+// and never reset, so an interval is the difference of two reads. One summary
+// goes to stderr when the model state is destroyed. runtron builds one state
+// per prompt batch: each prints its own summary, and the leaves follow the
+// newest state. W in <class>_worker_<W> is the pool worker index. The attention
+// workers of a forward are the last n_attn_workers pool workers, where
+// n_attn_workers is the number of attention workers the plugin chose for that
+// forward, the split (Note [Attention workers are the last pool workers] in
+// model.hpp). The first rows belong to the main helpers (the pool workers kept
+// for the non-attention work) and read zero. A row stays on one thread across
+// forwards even when the plugin changes the split. The forwards leaf carries
+// the smallest and largest n_attn_workers of the class. T3 and T4 are per (class,
+// layer), observed by attention worker 0, in a separate per-layer struct.
+// Memory when on: 2 classes x pool workers x layers x 192 bytes of rows, for
+// example 27 x 36 x 2 x 192 = 373 KB, plus 2 x layers x 64 bytes of timers.

+// The software path that served one visit: the AMX kernel, the AVX loop, or
+// none. An empty visit is one where apply_page_tok found no K token for the
+// software to score. The FPGA is not a visit path. Its share is counted per
+// hardware pass (note_fpga_pass) and per token job (note_fpga_query). The
+// values index the per-row arrays.
+enum class visit_path : uint8_t { empty = 0, avx = 1, amx = 2 };
+inline constexpr size_t N_PATHS_3 = 3;
+inline constexpr const char* PATH_NAMES[N_PATHS_3] = {"empty", "avx", "amx"};
+
+// The two software passes of one attention job. run_attention_job calls
+// run_sections twice: first over the ready pages, then, after the upstream
+// K/V wait, over the pending pages (Note [Ready versus pending attention
+// work] in model.hpp). Index 0 = the ready pass, 1 = the pending pass. These
+// are not the FPGA hardware passes (hw_workload.passes, note_fpga_pass).
+inline constexpr size_t N_PASSES_2 = 2;
+inline constexpr size_t PASS_READY_0 = 0;
+inline constexpr size_t PASS_PENDING_1 = 1;
+
+// Forward classes. CLASS_NAMES is the leaf name segment (<class>_totals and
+// friends), so it holds no slash. CLASS_LABELS names the class in the stderr
+// report together with the rule that defines it.
+enum class forward_class : uint8_t { decode_like = 0, prompt_or_mixed = 1 };
+inline constexpr size_t N_CLASSES_2 = 2;
+inline constexpr const char* CLASS_NAMES[N_CLASSES_2] = {
+    "decode_like", "prompt_or_mixed"};
+inline constexpr const char* CLASS_LABELS[N_CLASSES_2] = {
+    "decode_like/all_jobs_with_listener", "prompt_or_mixed/some_jobs_without_listener"};
+
+// Bits of the per-token path set: which paths served a token job in one
+// forward, over all layers, kv heads and pages. 8 possible sets.
+inline constexpr uint8_t PATH_BIT_NONE_0 = 0;
+inline constexpr uint8_t PATH_BIT_AVX_1 = 1;
+inline constexpr uint8_t PATH_BIT_AMX_2 = 2;
+inline constexpr uint8_t PATH_BIT_FPGA_4 = 4;
+inline constexpr size_t N_PATH_SETS_8 = 8;
+inline constexpr const char* PATH_SET_NAMES[N_PATH_SETS_8] = {
+    "none", "avx", "amx", "avx+amx", "fpga", "fpga+avx", "fpga+amx", "fpga+avx+amx"};
+
+inline constexpr uint8_t path_bit(visit_path p) noexcept {
+  return p == visit_path::avx   ? PATH_BIT_AVX_1
+         : p == visit_path::amx ? PATH_BIT_AMX_2
+                                : PATH_BIT_NONE_0;
+}

+inline constexpr uint64_t UNSET_CYCLES_0 = 0;  // a timestamp not taken (switch off)
+inline constexpr size_t WORKER_0 = 0;
+inline constexpr bool LEAF_READ_ONLY_TRUE = true;
+inline constexpr bool AMX_COMPILED_TRUE = true;

+// TRON_ATTN_STATS, read once per process: exactly "1" turns the stats on. Any
+// other set value is ignored with one warning.
+inline bool env_enabled() noexcept {
+  static const bool enabled = [] {
+    const char* value = std::getenv("TRON_ATTN_STATS");
+    if (value == nullptr) return false;
+    if (std::strcmp(value, "1") == 0) return true;
+    spdlog::warn(
+        "TRON_ATTN_STATS='{}' ignored: exactly \"1\" turns the attention path stats on",
+        value);
+    return false;
+  }();
+  return enabled;
+}

+// Adds value to a relaxed atomic. Single-writer: the owning thread is the only
+// writer, readers (FUSE callbacks, the exit report) load relaxed.
+inline void inc_relaxed(std::atomic<uint64_t>& counter, uint64_t value) noexcept {
+  counter.store(
+      counter.load(std::memory_order_relaxed) + value, std::memory_order_relaxed);
+}
+inline void max_relaxed(std::atomic<uint64_t>& counter, uint64_t value) noexcept {
+  if (value > counter.load(std::memory_order_relaxed)) {
+    counter.store(value, std::memory_order_relaxed);
+  }
+}
+inline void min_relaxed(std::atomic<uint64_t>& counter, uint64_t value) noexcept {
+  if (value < counter.load(std::memory_order_relaxed)) {
+    counter.store(value, std::memory_order_relaxed);
+  }
+}
+inline uint64_t load_relaxed(std::atomic<uint64_t> const& counter) noexcept {
+  return counter.load(std::memory_order_relaxed);
+}

+// Counts gathered by one apply_page_range call (one worker, one kv head, one
+// page range, one pass) as plain integers on the stack, then added to the
+// worker's row once per call.
+struct visit_tally {
+  uint64_t visits[N_PATHS_3] = {};
+  uint64_t k_tokens[N_PATHS_3] = {};
+  // AVX visits that scored a whole page: AMX-eligible volume that did not take
+  // the AMX path (the page failed is_dense_amx_page, for example a full page
+  // written in this forward, or AMX is off). For the same prompts and
+  // generated lengths, the kill-switch run's (TRON_AMX_DISABLE=1) value equals
+  // the AMX-on run's amx visits plus its own avx_full_page_visits.
+  uint64_t avx_full_page_visits = 0;
+  size_t n_visits = 0;
+
+  inline void record(visit_path p, int relevant_k_tokens, size_t page_size) noexcept {
+    const size_t ix = static_cast<size_t>(p);
+    visits[ix]++;
+    k_tokens[ix] += static_cast<uint64_t>(relevant_k_tokens);
+    // Branch-free: one when an AVX visit scored the whole page.
+    avx_full_page_visits += static_cast<uint64_t>(
+        (p == visit_path::avx) & (static_cast<size_t>(relevant_k_tokens) == page_size));
+    n_visits++;
+  }
+};
+
+// One row per (forward class, pool worker, layer). W is the pool worker index
+// (Note [Attention workers are the last pool workers] in model.hpp): attention
+// worker i of a forward with n attention workers writes row
+// num_workers - n + i, so a row stays on one thread and one core across
+// forwards even when the split moves. The main-helper rows read zero.
+// alignas(64) keeps rows of neighbouring workers on separate cache lines.
+struct alignas(64) worker_layer_row {
+  std::atomic<uint64_t> visits[N_PASSES_2][N_PATHS_3] = {};
+  std::atomic<uint64_t> k_tokens[N_PASSES_2][N_PATHS_3] = {};
+  std::atomic<uint64_t> avx_full_page_visits[N_PASSES_2] = {};
+  // T2: attention jobs of this worker in this layer and their busy cycles.
+  // The busy cycles are run_attention_job's attn_elapsed: both passes and the
+  // join, without the upstream K/V wait.
+  std::atomic<uint64_t> attn_jobs{0};
+  std::atomic<uint64_t> busy_cycles{0};
+  // T5: cycles this worker spent waiting in the join with no join progress.
+  // Hardware join: its wait loop (FPGA passes or the peer workers' software
+  // partials, whichever ends it). Software-only join: its failed polls.
+  std::atomic<uint64_t> join_wait_cycles{0};
+
+  inline void add(visit_tally const& tally, size_t pass) noexcept {
+    for (size_t p = 0; p < N_PATHS_3; ++p) {
+      inc_relaxed(visits[pass][p], tally.visits[p]);
+      inc_relaxed(k_tokens[pass][p], tally.k_tokens[p]);
+    }
+    inc_relaxed(avx_full_page_visits[pass], tally.avx_full_page_visits);
+  }
+};
+
+// T3 and T4 of one (forward class, layer), observed by attention worker 0 of
+// the forward. They describe the layer, not a worker, so they live apart from
+// the worker rows. Kept apart from layer_fpga_counters too, which a later
+// per-job split may re-key by job class.
+struct alignas(64) layer_timers {
+  // T3: entry-to-return cycles of the job as worker 0 sees it, every wait
+  // included (the job's wall time, in TSC cycles like every timer here).
+  std::atomic<uint64_t> wall_cycles{0};
+  std::atomic<uint64_t> wall_max_cycles{0};
+  // T4: entry-to-entry cycles between this layer's job and the next layer's
+  // job of the same minibatch on worker 0 (the whole layer as worker 0 sees
+  // it). The last layer has no successor.
+  std::atomic<uint64_t> period_cycles{0};
+  std::atomic<uint64_t> period_count{0};
+  std::atomic<uint64_t> period_max_cycles{0};
+};
+
+// FPGA work programmed for one layer of one forward class: K tokens the FPGA
+// card scores (the inclusive last token index + 1 per (pass, query)) and the
+// number of (pass, query) pairs. Written where the hardware job is prepared.
+// Unit note: one pass serves all n_kv_heads of a query at once, so these K
+// tokens compare with the software k_tokens (counted once per kv head) after
+// multiplying by n_kv_heads; the leaves carry that product too.
+struct layer_fpga_counters {
+  std::atomic<uint64_t> k_tokens{0};
+  std::atomic<uint64_t> query_passes{0};
+};
+
+// Per forward class: forwards, their wall cycles (T1), token jobs with FPGA
+// work, the per-token path sets, and the listener and KV-only job counts.
+struct forward_counters {
+  std::atomic<uint64_t> forwards{0};
+  std::atomic<uint64_t> wall_cycles{0};
+  std::atomic<uint64_t> wall_max_cycles{0};
+  std::atomic<uint64_t> fpga_queries{0};
+  std::atomic<uint64_t> token_jobs{0};
+  // How mixed the forwards of this class were, summed over its forwards.
+  // listener_jobs: token jobs with a listener. Every generated token has one.
+  // The last token of a prompt chunk has one too (with an empty logits buffer
+  // when the chunk is not the prompt's last). A chunk cut by the per-forward
+  // token limit gets its listener in the forward that finishes it.
+  // kv_only_jobs: token jobs without a listener, the prompt tokens that only
+  // stored their K and V. A prompt_or_mixed forward can hold other users'
+  // generated tokens. The record does not carry the number of users in
+  // prefill, so a reader who wants the generated tokens per forward takes
+  // that number from the run shape and subtracts it from the listener jobs
+  // per forward. Speculative verify steps carry one listener per draft token.
+  std::atomic<uint64_t> listener_jobs{0};
+  std::atomic<uint64_t> kv_only_jobs{0};
+  // Attention workers of this class's forwards, smallest and largest over the
+  // run. The plugin picks the split per forward (recommend_n_main_helpers),
+  // so a reader needs the range to know which pool rows were attention rows.
+  std::atomic<uint64_t> n_attn_workers_min{UINT64_MAX};
+  std::atomic<uint64_t> n_attn_workers_max{0};
+  std::atomic<uint64_t> token_jobs_by_path_set[N_PATH_SETS_8] = {};
+};

+// All statistics of one model state. Created with the state; the FUSE leaves

+struct model_stats {

+  // the hooks can test this one bool. No row, FPGA counter or path-bit vector

+  const std::string model_id;
+  const bool is_eagle;  // an EAGLE draft state shares the target's model id

+  const size_t n_layers;

+  std::vector<layer_fpga_counters> fpga;  // [class][layer], empty when off
+  std::vector<layer_timers> timers;       // [class][layer], empty when off

+  // Off-state placeholder for a worker index that is never read: the hooks

+  static constexpr size_t NO_WORKER = SIZE_MAX;

+  // Per-forward state. The main thread writes before the attention workers
+  // start and reads after they finish; the workers read the class and write
+  // their own path_bits vector.
+  std::atomic<uint8_t> current_class{0};
+  std::vector<std::vector<uint8_t>> path_bits;  // [pool worker][token job]
+  // The split of the current forward, set by note_attn_workers from the
+  // attention plan; UNKNOWN_SPLIT (a forward without attention work, or a
+  // unit test that never assembled a plan) makes end_forward fold every row.
+  static constexpr size_t UNKNOWN_SPLIT = SIZE_MAX;
+  size_t forward_n_attn_workers = UNKNOWN_SPLIT;
+  // The listener count of the current forward, kept from begin_forward to
+  // end_forward, where every job count of the forwards record is added.
+  size_t forward_n_listeners = 0;
+  std::vector<uint8_t> fpga_bits;  // [token job]: PATH_BIT_FPGA_4 or 0, main thread
+  // T4 state of worker 0. Worker 0 writes and reads it. The main thread resets
+  // t4_last_operation in begin_forward, before the workers start. The other two
+  // fields are read only after worker 0 has set them. A layer's period runs from
+  // worker 0's entry into the first job of one attention operation to its
+  // entry into the first job of the next operation. The other minibatches of
+  // the same operation do not start a new period.
+  static constexpr size_t NO_OPERATION = SIZE_MAX;
+  size_t t4_last_operation = NO_OPERATION;
+  size_t t4_last_layer = 0;
+  uint64_t t4_layer_start_cycles = 0;

+  model_stats(bool stats_enabled,
+      std::string id,
+      bool eagle,
+      header_facts f,
+      size_t workers,
+      size_t layers)
+  : enabled(stats_enabled)
+  , model_id(std::move(id))
+  , is_eagle(eagle)
+  , facts(f)
+  , n_workers(workers)
+  , n_layers(layers) {
+    if (enabled) {
+      rows = std::vector<worker_layer_row>(N_CLASSES_2 * n_workers * n_layers);
+      fpga = std::vector<layer_fpga_counters>(N_CLASSES_2 * n_layers);
+      timers = std::vector<layer_timers>(N_CLASSES_2 * n_layers);
+      path_bits.resize(n_workers);
+      spdlog::info(
+          "attention path stats on (TRON_ATTN_STATS=1) for model '{}'{}: rows for "
+          "{} app-pool workers x {} layers",
+          model_id, is_eagle ? " (EAGLE draft)" : "", n_workers, n_layers);
+    }
+  }

+  ~model_stats() {
+    if (enabled) print_report(stderr);
+  }

+  worker_layer_row& row(size_t cls, size_t worker, size_t layer) noexcept {
+    TRON_ASSERT_LT(cls, N_CLASSES_2);
+    TRON_ASSERT_LT(worker, n_workers);
+    TRON_ASSERT_LT(layer, n_layers);
+    return rows[(cls * n_workers + worker) * n_layers + layer];
+  }
+  worker_layer_row const& row(size_t cls, size_t worker, size_t layer) const noexcept {
+    TRON_ASSERT_LT(cls, N_CLASSES_2);
+    TRON_ASSERT_LT(worker, n_workers);
+    TRON_ASSERT_LT(layer, n_layers);
+    return rows[(cls * n_workers + worker) * n_layers + layer];
+  }
+  size_t current_class_ix() const noexcept {
+    return current_class.load(std::memory_order_relaxed);
+  }
+  layer_fpga_counters& fpga_at(size_t cls, size_t layer) noexcept {
+    TRON_ASSERT_LT(cls, N_CLASSES_2);
+    TRON_ASSERT_LT(layer, n_layers);
+    return fpga[cls * n_layers + layer];
+  }
+  layer_fpga_counters const& fpga_at(size_t cls, size_t layer) const noexcept {
+    TRON_ASSERT_LT(cls, N_CLASSES_2);
+    TRON_ASSERT_LT(layer, n_layers);
+    return fpga[cls * n_layers + layer];
+  }
+  layer_timers& timers_at(size_t cls, size_t layer) noexcept {
+    TRON_ASSERT_LT(cls, N_CLASSES_2);
+    TRON_ASSERT_LT(layer, n_layers);
+    return timers[cls * n_layers + layer];
+  }
+  layer_timers const& timers_at(size_t cls, size_t layer) const noexcept {
+    TRON_ASSERT_LT(cls, N_CLASSES_2);
+    TRON_ASSERT_LT(layer, n_layers);
+    return timers[cls * n_layers + layer];
+  }
+  // The pool worker that runs attention worker attn_ix of a forward with
+  // n_attn_workers attention workers (Note [Attention workers are the last
+  // pool workers] in model.hpp). Both inputs are asserted: the pair must fit
+  // the pool that sized the rows.
+  inline size_t pool_worker(size_t attn_ix, size_t n_attn_workers) const noexcept {
+    TRON_ASSERT_LE(n_attn_workers, n_workers);
+    TRON_ASSERT_LT(attn_ix, n_attn_workers);
+    return n_workers - n_attn_workers + attn_ix;
+  }
+  // The per-worker path bits of one forward, hoisted out of the visit loop.
+  // Called with the switch on only. begin_forward sized the vector for every
+  // token job of the forward, so the visit loop needs no bound of its own.
+  inline uint8_t* token_path_span(size_t worker, size_t n_token_jobs) noexcept {
+    TRON_ASSERT_LT(worker, path_bits.size());
+    TRON_ASSERT_LE(n_token_jobs, path_bits[worker].size());
+    return path_bits[worker].data();
+  }
+
+  // Main thread, before the attention workers of a forward start. The
+  // scheduler registers at most one listener per token job, so n_listeners
+  // never exceeds n_token_jobs. The job counts of the forwards record are
+  // added in end_forward, all three together: a live read during a forward
+  // then never shows listener_jobs and kv_only_jobs ahead of token_jobs.
+  void begin_forward(forward_class cls, size_t n_token_jobs, size_t n_listeners) {
+    if (!enabled) return;
+    TRON_ASSERT_LE(n_listeners, n_token_jobs);
+    current_class.store(static_cast<uint8_t>(cls), std::memory_order_relaxed);
+    forward_n_listeners = n_listeners;
+    fpga_bits.assign(n_token_jobs, 0);
+    for (auto& bits : path_bits) {
+      if (bits.size() < n_token_jobs) bits.resize(n_token_jobs, 0);
+    }
+    t4_last_operation = NO_OPERATION;
+    forward_n_attn_workers = UNKNOWN_SPLIT;
+  }
+
+  // Main thread, once per forward with attention work, from
+  // assemble_attention_plan_impl: the split the plugin chose. end_forward then
+  // folds the last n_attn_workers rows only, and the forwards record keeps
+  // the smallest and largest split of the class.
+  void note_attn_workers(size_t n_attn_workers) noexcept {
+    if (!enabled) return;
+    TRON_ASSERT_LE(n_attn_workers, n_workers);
+    forward_n_attn_workers = n_attn_workers;
+    forward_counters& fc = forwards[current_class_ix()];
+    min_relaxed(fc.n_attn_workers_min, n_attn_workers);
+    max_relaxed(fc.n_attn_workers_max, n_attn_workers);
+  }
+
+  // Worker-side, once per apply_page_range call: add the call's tally to the
+  // worker's row of the current class. Rows exist for the app pool's workers
+  // and the model's layers. Any other index is asserted, not ignored: in
+  // production every index is in range by construction, and a wrong one
+  // must fail instead of going uncounted.
+  inline void add_visits(
+      size_t worker, size_t layer, visit_tally const& tally, size_t pass) noexcept {
+    if (!enabled || tally.n_visits == 0) return;  // row() asserts the bounds
+    row(current_class_ix(), worker, layer).add(tally, pass);
+  }
+
+  // Worker 0, at the entry of every attention job: the T4 layer period.
+  inline void note_attn_job_entry_w0(
+      size_t operation, size_t layer, uint64_t t_entry) noexcept {
+    if (!enabled || operation == t4_last_operation) return;
+    if (t4_last_operation != NO_OPERATION) {
+      layer_timers& t = timers_at(current_class_ix(), t4_last_layer);
+      const uint64_t period = t_entry - t4_layer_start_cycles;
+      inc_relaxed(t.period_cycles, period);
+      inc_relaxed(t.period_count, 1);
+      max_relaxed(t.period_max_cycles, period);
+    }
+    t4_last_operation = operation;
+    t4_last_layer = layer;
+    t4_layer_start_cycles = t_entry;
+  }
+
+  // Every worker, at the end of every attention job: T2 (busy), under the
+  // pool worker that ran the job.
+  inline void note_attn_job(
+      size_t worker, size_t layer, uint64_t busy_cycles) noexcept {
+    if (!enabled) return;  // row() asserts the bounds
+    worker_layer_row& r = row(current_class_ix(), worker, layer);
+    inc_relaxed(r.attn_jobs, 1);
+    inc_relaxed(r.busy_cycles, busy_cycles);
+  }
+
+  // Attention worker 0, at the end of every attention job: T3, the job's wall
+  // time as that worker sees it, filed per layer.
+  inline void note_attn_job_wall_w0(size_t layer, uint64_t wall_cycles) noexcept {
+    if (!enabled) return;  // timers_at asserts the bounds
+    layer_timers& t = timers_at(current_class_ix(), layer);
+    inc_relaxed(t.wall_cycles, wall_cycles);
+    max_relaxed(t.wall_max_cycles, wall_cycles);
+  }
+
+  // Every worker, once per job: T5, cycles spent waiting in the join (both
+  // join modes; see run_joins in self_attention.hpp).
+  inline void note_join_wait(size_t worker, size_t layer, uint64_t cycles) noexcept {
+    if (!enabled || cycles == 0) return;  // row() asserts the bounds
+    inc_relaxed(row(current_class_ix(), worker, layer).join_wait_cycles, cycles);
+  }
+
+  // Main thread, once per hardware pass programmed for a layer: the K tokens
+  // the FPGA card scores for the pass's queries and the number of queries.
+  inline void note_fpga_pass(
+      size_t layer, uint64_t k_tokens, uint64_t n_queries) noexcept {
+    if (!enabled) return;  // fpga_at asserts the bounds
+    layer_fpga_counters& f = fpga_at(current_class_ix(), layer);
+    f.k_tokens.fetch_add(k_tokens, std::memory_order_relaxed);
+    f.query_passes.fetch_add(n_queries, std::memory_order_relaxed);
+  }
+
+  // Main thread, after a forward: T1.
+  inline void note_forward_wall(uint64_t cycles) noexcept {
+    if (!enabled) return;
+    forward_counters& fc = forwards[current_class_ix()];
+    fc.forwards.fetch_add(1, std::memory_order_relaxed);
+    fc.wall_cycles.fetch_add(cycles, std::memory_order_relaxed);
+    max_relaxed(fc.wall_max_cycles, cycles);
+  }
+
+  // Main thread, after every attention worker of the forward has finished:
+  // fold the per-worker path bits and the FPGA bits into the path-set
+  // histogram of the current class, then clear the bits for the next forward.
+  // It also adds the three job counts of the forward (token_jobs,
+  // listener_jobs, kv_only_jobs) to the forwards record.
+  void end_forward(size_t n_token_jobs) {
+    if (!enabled) return;
+    // begin_forward sized both scratch vectors for this count of token jobs.
+    TRON_ASSERT_EQ(fpga_bits.size(), n_token_jobs);
+    for (auto const& bits : path_bits) {
+      TRON_ASSERT_LE(n_token_jobs, bits.size());
+    }
+    // Only the attention workers of this forward wrote path bits: the last
+    // forward_n_attn_workers rows. Every row when the split is unknown.
+    const size_t first_row = forward_n_attn_workers == UNKNOWN_SPLIT
+                                 ? 0
+                                 : n_workers - forward_n_attn_workers;
+    forward_counters& fc = forwards[current_class_ix()];
+    for (size_t job = 0; job < n_token_jobs; ++job) {
+      uint8_t set = fpga_bits[job];
+      for (size_t w = first_row; w < n_workers; ++w) {
+        set |= path_bits[w][job];
+        path_bits[w][job] = 0;
+      }
+      // A wrong writer of fpga_bits or path_bits would index past the
+      // histogram. Fail here instead of counting the job under another set.
+      TRON_ASSERT_LT(static_cast<size_t>(set), N_PATH_SETS_8);
+      fc.token_jobs_by_path_set[set].fetch_add(1, std::memory_order_relaxed);
+    }
+    // The three job counts move together, in three relaxed adds. A read
+    // between them can differ from listener_jobs + kv_only_jobs == token_jobs
+    // by this one forward. A read at any other time sees the equality.
+    TRON_ASSERT_LE(forward_n_listeners, n_token_jobs);
+    fc.token_jobs.fetch_add(n_token_jobs, std::memory_order_relaxed);
+    fc.listener_jobs.fetch_add(forward_n_listeners, std::memory_order_relaxed);
+    fc.kv_only_jobs.fetch_add(
+        n_token_jobs - forward_n_listeners, std::memory_order_relaxed);
+  }
+
+  // Main thread: the hardware plan of a minibatch gave this token job at least
+  // one FPGA pass (read from hw_workload::by_job after set_passes).
+  inline void note_fpga_query(size_t token_job) noexcept {
+    if (!enabled) return;
+    TRON_ASSERT_LT(token_job, fpga_bits.size());
+    fpga_bits[token_job] = PATH_BIT_FPGA_4;
+    forwards[current_class_ix()].fpga_queries.fetch_add(1, std::memory_order_relaxed);
+  }
+
+  // Sums over workers for one (class, layer).
+  struct layer_sums {
+    uint64_t visits[N_PASSES_2][N_PATHS_3] = {};
+    uint64_t k_tokens[N_PASSES_2][N_PATHS_3] = {};
+    uint64_t avx_full_page_visits[N_PASSES_2] = {};
+    uint64_t attn_jobs = 0, busy_cycles = 0, wall_cycles = 0, wall_max_cycles = 0;
+    uint64_t period_cycles = 0, period_count = 0, period_max_cycles = 0;
+    uint64_t join_wait_cycles = 0;
+    void add(worker_layer_row const& r) noexcept {
+      for (size_t pass = 0; pass < N_PASSES_2; ++pass) {
+        for (size_t p = 0; p < N_PATHS_3; ++p) {
+          visits[pass][p] += load_relaxed(r.visits[pass][p]);
+          k_tokens[pass][p] += load_relaxed(r.k_tokens[pass][p]);
+        }
+        avx_full_page_visits[pass] += load_relaxed(r.avx_full_page_visits[pass]);
+      }
+      attn_jobs += load_relaxed(r.attn_jobs);
+      busy_cycles += load_relaxed(r.busy_cycles);
+      join_wait_cycles += load_relaxed(r.join_wait_cycles);
+    }
+    // T3 and T4 come from the per-layer struct, not from a worker row.
+    void add_timers(layer_timers const& t) noexcept {
+      wall_cycles += load_relaxed(t.wall_cycles);
+      wall_max_cycles = std::max(wall_max_cycles, load_relaxed(t.wall_max_cycles));
+      period_cycles += load_relaxed(t.period_cycles);
+      period_count += load_relaxed(t.period_count);
+      period_max_cycles =
+          std::max(period_max_cycles, load_relaxed(t.period_max_cycles));
+    }
+    void add_sums(layer_sums const& o) noexcept {
+      for (size_t pass = 0; pass < N_PASSES_2; ++pass) {
+        for (size_t p = 0; p < N_PATHS_3; ++p) {
+          visits[pass][p] += o.visits[pass][p];
+          k_tokens[pass][p] += o.k_tokens[pass][p];
+        }
+        avx_full_page_visits[pass] += o.avx_full_page_visits[pass];
+      }
+      attn_jobs += o.attn_jobs;
+      busy_cycles += o.busy_cycles;
+      wall_cycles += o.wall_cycles;
+      wall_max_cycles = std::max(wall_max_cycles, o.wall_max_cycles);
+      period_cycles += o.period_cycles;
+      period_count += o.period_count;
+      period_max_cycles = std::max(period_max_cycles, o.period_max_cycles);
+      join_wait_cycles += o.join_wait_cycles;
+    }
+    uint64_t visits_all(size_t p) const noexcept {
+      return visits[PASS_READY_0][p] + visits[PASS_PENDING_1][p];
+    }
+    uint64_t k_tokens_all(size_t p) const noexcept {
+      return k_tokens[PASS_READY_0][p] + k_tokens[PASS_PENDING_1][p];
+    }
+  };
+  // The layer view carries T3 and T4; the worker view (sum_worker) does not,
+  // because those timers describe the layer, not a worker.
+  layer_sums sum_layer(size_t cls, size_t layer) const noexcept {
+    layer_sums s;
+    for (size_t w = 0; w < n_workers; ++w) {
+      s.add(row(cls, w, layer));
+    }
+    s.add_timers(timers_at(cls, layer));
+    return s;
+  }
+  layer_sums sum_worker(size_t cls, size_t worker) const noexcept {
+    layer_sums s;
+    for (size_t l = 0; l < n_layers; ++l) {
+      s.add(row(cls, worker, l));
+    }
+    return s;
+  }
+
+  // ---- rendering (JSON, one object per leaf; every leaf stays well below
+  // fuse_sysfs::MAX_STRING_LENGTH) ----
+
+  // with_layer_timers: the T3/T4 keys, present in the layer and totals leaves
+  // and absent from the worker leaf.
+  static void put_counts(
+      std::string& out, layer_sums const& s, bool with_layer_timers) {
+    for (size_t pass = 0; pass < N_PASSES_2; ++pass) {
+      const char* pass_name = pass == PASS_READY_0 ? "ready" : "pending";
+      for (size_t p = 0; p < N_PATHS_3; ++p) {
+        fmt::format_to(std::back_inserter(out),
+            "\"{}_{}_visits\":{},\"{}_{}_k_tokens\":{},", pass_name, PATH_NAMES[p],
+            s.visits[pass][p], pass_name, PATH_NAMES[p], s.k_tokens[pass][p]);
+      }
+      fmt::format_to(std::back_inserter(out), "\"{}_avx_full_page_visits\":{},",
+          pass_name, s.avx_full_page_visits[pass]);
+    }
+    fmt::format_to(std::back_inserter(out), "\"attn_jobs\":{},\"busy_cycles\":{},",
+        s.attn_jobs, s.busy_cycles);
+    if (with_layer_timers) {
+      fmt::format_to(std::back_inserter(out),
+          "\"wall_cycles_w0\":{},\"wall_max_cycles_w0\":{},"
+          "\"period_cycles_w0\":{},\"period_count_w0\":{},\"period_max_cycles_w0\":{},",
+          s.wall_cycles, s.wall_max_cycles, s.period_cycles, s.period_count,
+          s.period_max_cycles);
+    }
+    fmt::format_to(
+        std::back_inserter(out), "\"join_wait_cycles\":{}", s.join_wait_cycles);
+  }
+
+  // FPGA K tokens as counted (per query, all kv heads at once) and on the
+  // software scale (per kv head), plus the (pass, query) pairs.
+  void put_fpga(std::string& out, uint64_t fpga_k, uint64_t fpga_qp) const {
+    fmt::format_to(std::back_inserter(out),
+        ",\"fpga_k_tokens\":{},\"fpga_k_tokens_x_kv_heads\":{},\"fpga_query_passes\":{"
+        "}",
+        fpga_k, fpga_k * facts.n_kv_heads, fpga_qp);
+  }
+
+  // Workers that ran at least one attention job (the app pool has more
+  // workers than the plugin uses for attention).
+  size_t active_workers() const noexcept {
+    size_t n = 0;
+    for (size_t w = 0; w < n_workers && enabled; ++w) {
+      bool active = false;
+      for (size_t cls = 0; cls < N_CLASSES_2 && !active; ++cls) {
+        for (size_t l = 0; l < n_layers && !active; ++l) {
+          active = load_relaxed(row(cls, w, l).attn_jobs) != 0;
+        }
+      }
+      n += active ? 1 : 0;
+    }
+    return n;
+  }
+
+  std::string render_summary() const {
+    std::string out;
+    // tsc_hz converts the cycle counters to seconds; 0 until the calibration
+    // thread has published a frequency.
+    fmt::format_to(std::back_inserter(out),
+        "{{\"on\":{},\"model_id\":\"{}\",\"eagle\":{},\"amx_compiled\":{},"
+        "\"amx_available\":{},\"n_kv_heads\":{},\"kv_mul\":{},\"head_size\":{},"
+        "\"n_layers\":{},\"page_size\":{},\"n_workers\":{},\"active_workers\":{},"
+        "\"tsc_hz\":{},\"switch\":\"TRON_ATTN_STATS=1\"}}",
+        enabled, model_id, is_eagle, facts.amx_compiled, facts.amx_available,
+        facts.n_kv_heads, facts.kv_mul, facts.head_size, facts.n_layers,
+        facts.page_size, n_workers, active_workers(), hardware::system::get_cpu_freq());
+    return out;
+  }
+
+  // Path totals per class, summed over workers and layers, plus the FPGA
+  // K tokens and query passes summed over layers.
+  std::string render_totals(size_t cls) const {
+    std::string out = "{";
+    if (enabled) {
+      layer_sums s;
+      for (size_t l = 0; l < n_layers; ++l) {
+        s.add_sums(sum_layer(cls, l));
+      }
+      put_counts(out, s, /*with_layer_timers=*/true);
+      uint64_t fpga_k = 0, fpga_qp = 0;
+      for (size_t l = 0; l < n_layers; ++l) {
+        fpga_k += load_relaxed(fpga_at(cls, l).k_tokens);
+        fpga_qp += load_relaxed(fpga_at(cls, l).query_passes);
+      }
+      put_fpga(out, fpga_k, fpga_qp);
+    }
+    out += "}";
+    return out;
+  }
+
+  // Forward counters per class: forwards, wall cycles, FPGA queries and token
+  // jobs by path set. Empty while the switch is off, like the totals.
+  std::string render_forwards(size_t cls) const {
+    std::string out = "{";
+    if (enabled) {
+      forward_counters const& fc = forwards[cls];
+      fmt::format_to(std::back_inserter(out),
+          "\"forwards\":{},\"wall_cycles\":{},\"wall_max_cycles\":{},\"fpga_queries\":{"
+          "},"
+          "\"token_jobs\":{},\"listener_jobs\":{},\"kv_only_jobs\":{},"
+          "\"n_attn_workers_min\":{},\"n_attn_workers_max\":{},"
+          "\"token_jobs_by_path_set\":{{",
+          load_relaxed(fc.forwards), load_relaxed(fc.wall_cycles),
+          load_relaxed(fc.wall_max_cycles), load_relaxed(fc.fpga_queries),
+          load_relaxed(fc.token_jobs), load_relaxed(fc.listener_jobs),
+          load_relaxed(fc.kv_only_jobs),
+          // UINT64_MAX is the "no forward yet" initial value of the minimum.
+          load_relaxed(fc.n_attn_workers_max) == 0
+              ? 0
+              : load_relaxed(fc.n_attn_workers_min),
+          load_relaxed(fc.n_attn_workers_max));
+      for (size_t set = 0; set < N_PATH_SETS_8; ++set) {
+        fmt::format_to(std::back_inserter(out), "{}\"{}\":{}", set == 0 ? "" : ",",
+            PATH_SET_NAMES[set], load_relaxed(fc.token_jobs_by_path_set[set]));
+      }
+      out += "}";
+    }
+    out += "}";
+    return out;
+  }
+
+  std::string render_layer(size_t cls, size_t layer) const {
+    std::string out;
+    fmt::format_to(std::back_inserter(out), "{{\"layer\":{}", layer);
+    if (enabled) {
+      out += ",";
+      put_counts(out, sum_layer(cls, layer), /*with_layer_timers=*/true);
+      put_fpga(out, load_relaxed(fpga_at(cls, layer).k_tokens),
+          load_relaxed(fpga_at(cls, layer).query_passes));
+    }
+    out += "}";
+    return out;
+  }
+
+  std::string render_worker(size_t cls, size_t worker) const {
+    std::string out;
+    fmt::format_to(std::back_inserter(out), "{{\"worker\":{}", worker);
+    if (enabled) {
+      out += ",";
+      put_counts(out, sum_worker(cls, worker), /*with_layer_timers=*/false);
+    }
+    out += "}";
+    return out;
+  }

+  // The stderr summary. Printed once, when the model state is destroyed, if
+  // the switch was on and anything was counted.
+  void print_report(std::FILE* f) const {
+    if (!enabled) return;
+    bool any = false;
+    for (size_t cls = 0; cls < N_CLASSES_2; ++cls) {
+      any = any || load_relaxed(forwards[cls].forwards) != 0;
+    }
+    for (auto const& r : rows) {
+      for (size_t pass = 0; pass < N_PASSES_2 && !any; ++pass) {
+        for (size_t p = 0; p < N_PATHS_3; ++p) {
+          any = any || load_relaxed(r.visits[pass][p]) != 0;
+        }
+      }
+    }
+    if (!any) return;
+    std::fprintf(
+        f, "\n[attn-stats] model %s: %s\n", model_id.c_str(), render_summary().c_str());
+    for (size_t cls = 0; cls < N_CLASSES_2; ++cls) {
+      std::fprintf(f, "[attn-stats] %s totals: %s\n", CLASS_LABELS[cls],
+          render_totals(cls).c_str());
+      std::fprintf(f, "[attn-stats] %s forwards: %s\n", CLASS_LABELS[cls],
+          render_forwards(cls).c_str());
+      // One line per class with the per-layer K tokens (ready + pending, summed
+      // over workers): layer=amx/avx/fpga.
+      std::string layers;
+      for (size_t l = 0; l < n_layers; ++l) {
+        const layer_sums s = sum_layer(cls, l);
+        fmt::format_to(std::back_inserter(layers), "{}{}={}/{}/{}", l == 0 ? "" : " ",
+            l, s.k_tokens_all(static_cast<size_t>(visit_path::amx)),
+            s.k_tokens_all(static_cast<size_t>(visit_path::avx)),
+            load_relaxed(fpga_at(cls, l).k_tokens));
+      }

+// One forward's record, owned by one object at one site (model::state::forward).
+// Construction: the T1 start stamp, then the class store and the scratch reset
+// (begin_forward), so T1 includes that reset. Destruction, after logits and
+// listener delivery and the latch arena release: the T1 stop stamp
+// (note_forward_wall), then the path-set fold and the job-count adds
+// (end_forward). The fold may run this late. The path bits are written only by the
+// attention workers inside the plugin's run, which waits for them. The FPGA bits are
+// written only by construct_hw_plan on the main thread, and fpga_queries keeps that
+// writer. Off state: one bool copied at construction, tested twice there (start stamp,
+// begin_forward) and once at destruction, no write. A caller of the hooks
+// without this object gets a half record: token jobs without forwards, or a
+// wall filed under the previous forward's class. The destructor also runs
+// when forward() unwinds through an exception, so such a forward is still
+// counted; tron's asserts abort rather than throw.
+struct forward_scope : noncopyable<forward_scope> {
+  model_stats& stats;
+  const bool on;
+  const size_t n_token_jobs;
+  const uint64_t t_start;
+  forward_scope(model_stats& s, forward_class cls, size_t n_jobs, size_t n_listeners)
+  : stats(s)
+  , on(s.enabled)
+  , n_token_jobs(n_jobs)
+  , t_start(on ? hardware::system::rdtsc() : UNSET_CYCLES_0) {
+    if (on) stats.begin_forward(cls, n_jobs, n_listeners);
+  }
+  ~forward_scope() noexcept {
+    if (!on) return;
+    stats.note_forward_wall(hardware::system::rdtsc() - t_start);
+    stats.end_forward(n_token_jobs);
+  }
+};

+// A model id is used as one FUSE path segment and inside a JSON string: the
+// expert-stats rule (non-empty, no leading dot, no slash) plus a character
+// whitelist so no quote, backslash or control character reaches the JSON.
+inline bool is_safe_model_id(std::string_view id) noexcept {
+  if (id.empty()) return false;
+  if (id.front() == '.') return false;
+  for (char c : id) {
+    const bool ok = (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') ||
+                    (c >= '0' && c <= '9') || c == '-' || c == '_' || c == '.' ||
+                    c == ':';
+    if (!ok) return false;
+  }
+  return true;
+}

+  stats->note_attn_job_entry_w0(OPERATION_0, LAYER_0, CYCLES_1300);

+TEST_CASE("attn-stats forward_scope: one object owns the per-forward record",
+    "[attn_stats]") {
+  // forward_scope is the one owner of the record behind <class>_forwards. The
+  // class is stored at construction. The wall and the fold are recorded at
+  // destruction. So every caller of model::state::forward gets a whole record

+        *stats, forward_class::decode_like, N_TOKEN_JOBS_5, LISTENERS_ALL_5);

+TEST_CASE(
+    "attn-stats: an out-of-range worker, layer or token job aborts", "[attn_stats]") {
+  // In production every index is in range by construction (the worker index
+  // is below the pool size that sizes the rows, the layer id below n_layers,
+  // the token job below the count that begin_forward sized). A wrong index
+  // must therefore fail, not go uncounted. Each call runs in a forked child
+  // that must die with SIGABRT.
+  auto stats = make_stats(STATS_ON_TRUE);
+  stats->begin_forward(forward_class::decode_like, N_TOKEN_JOBS_5, LISTENERS_ALL_5);
+  visit_tally tally;
+  tally.record(visit_path::avx, K_TOKENS_TAIL_17, PAGE_SIZE_64);
+  REQUIRE(tron::assertion_signal([&] {
+    stats->add_visits(N_WORKERS_3, LAYER_0, tally, PASS_READY_0);
+  }) == SIGABRT);
+  REQUIRE(tron::assertion_signal([&] {
+    stats->add_visits(WORKER_0, N_LAYERS_4, tally, PASS_READY_0);
+  }) == SIGABRT);
+  REQUIRE(tron::assertion_signal([&] {
+    stats->note_attn_job(N_WORKERS_3, LAYER_0, CYCLES_100);
+  }) == SIGABRT);
+  REQUIRE(tron::assertion_signal([&] {
+    stats->note_attn_job_wall_w0(N_LAYERS_4, CYCLES_100);
+  }) == SIGABRT);
+  REQUIRE(tron::assertion_signal([&] { stats->note_attn_workers(N_WORKERS_3 + 1); }) ==
+          SIGABRT);
+  // pool_worker: a split larger than the pool, or an attention worker index
+  // at or past the split, is a caller bug.
+  REQUIRE(tron::assertion_signal(
+              [&] { stats->pool_worker(WORKER_0, N_WORKERS_3 + 1); }) == SIGABRT);
+  REQUIRE(tron::assertion_signal(
+              [&] { stats->pool_worker(WORKER_2, N_WORKERS_3 - 1); }) == SIGABRT);
+  REQUIRE(tron::assertion_signal([&] {
+    stats->note_join_wait(WORKER_0, N_LAYERS_4, CYCLES_100);
+  }) == SIGABRT);
+  REQUIRE(tron::assertion_signal([&] { stats->note_fpga_pass(N_LAYERS_4, 1, 1); }) ==
+          SIGABRT);
+  REQUIRE(tron::assertion_signal([&] { stats->note_fpga_query(N_TOKEN_JOBS_5); }) ==
+          SIGABRT);
+  REQUIRE(tron::assertion_signal(

+  // workers] in model.hpp). The plugin picks the split per forward
+  // (recommend_n_main_helpers), so attention worker 0 of a 1-worker forward

+  // forwards would land in row 0, a row that no thread of either forward

+  // (row = pool_worker(attention index, split)) and checks that the two

+  visit_tally tally;

+TEST_CASE("attn-stats end_forward folds the attention rows of the forward only",
+    "[attn_stats]") {
+  // With the split known, end_forward reads and clears the path bits of the
+  // last n_attn_workers rows. Bits left in a main-helper row (which no thread
+  // of the forward writes) are neither counted nor cleared. Without a split
+  // (a unit test that assembled no plan) every row is folded.
+  constexpr size_t SPLIT_2 = 2;
+  constexpr size_t JOB_0 = 0;
+  constexpr size_t JOB_1 = 1;
+  // The histogram index of a job is the OR of its path bits (path_bit()).
+  constexpr size_t SET_AVX_1 = PATH_BIT_AVX_1;
+  constexpr size_t SET_AMX_2 = PATH_BIT_AMX_2;
+  constexpr size_t SET_FPGA_4 = PATH_BIT_FPGA_4;
+  auto stats = make_stats(STATS_ON_TRUE);
+  stats->begin_forward(forward_class::decode_like, N_TOKEN_JOBS_5, LISTENERS_ALL_5);
+  stats->note_attn_workers(SPLIT_2);
+  // Attention rows: pool workers 1 and 2.
+  stats->token_path_span(WORKER_1, N_TOKEN_JOBS_5)[JOB_0] |= path_bit(visit_path::avx);
+  stats->token_path_span(WORKER_2, N_TOKEN_JOBS_5)[JOB_1] |= path_bit(visit_path::amx);
+  // A stray bit in the helper row.
+  stats->token_path_span(WORKER_0, N_TOKEN_JOBS_5)[JOB_0] |= path_bit(visit_path::amx);
+  stats->end_forward(N_TOKEN_JOBS_5);
+  forward_counters const& fc = stats->forwards[CLASS_DECODE_0];
+  CHECK(load_relaxed(fc.token_jobs_by_path_set[SET_AVX_1]) == 1);
+  CHECK(load_relaxed(fc.token_jobs_by_path_set[SET_AMX_2]) == 1);
+  CHECK(load_relaxed(fc.token_jobs_by_path_set[SET_AVX_1 | SET_AMX_2]) == 0);
+  CHECK(load_relaxed(fc.token_jobs_by_path_set[SET_FPGA_4]) == 0);
+  CHECK(load_relaxed(fc.token_jobs_by_path_set[0]) == N_TOKEN_JOBS_5 - 2);
+  // The attention rows are clear, the helper row still holds its bit.
+  CHECK(stats->token_path_span(WORKER_1, N_TOKEN_JOBS_5)[JOB_0] == 0);
+  CHECK(stats->token_path_span(WORKER_2, N_TOKEN_JOBS_5)[JOB_1] == 0);
+  CHECK(stats->token_path_span(WORKER_0, N_TOKEN_JOBS_5)[JOB_0] ==
+        path_bit(visit_path::amx));
+  // The next forward has no split: every row is folded, so the stray bit is
+  // counted now and cleared.
+  stats->begin_forward(forward_class::decode_like, N_TOKEN_JOBS_5, LISTENERS_ALL_5);
+  stats->end_forward(N_TOKEN_JOBS_5);
+  CHECK(load_relaxed(fc.token_jobs_by_path_set[SET_AMX_2]) == 2);
+  CHECK(stats->token_path_span(WORKER_0, N_TOKEN_JOBS_5)[JOB_0] == 0);
+}

+  CHECK_FALSE(read_report(*forwards_only).empty());
+  auto fpga_only = make_stats(STATS_ON_TRUE);

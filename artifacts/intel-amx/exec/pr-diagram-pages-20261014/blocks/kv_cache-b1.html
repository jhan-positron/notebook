KV_CACHE-B1. Data model: book, page, kv_block, and the per-page K layout state

A book holds one storage slot per layer (plus one EAGLE storage), pages of 64 token offsets, and one kv_block per (slot, KV head, page). The PR types the K plane of a kv_block and adds two bit arrays to the page, one entry per logical slot plus one for the EAGLE storage. Every arrow says how many.

MODEL-B5. Decision model: what one run of tokens becomes in the page

For each run of consecutive items in one 16-token block of one page, three cases. A run of 16 tokens is stored as one VNNI block (set_k_block, then note_k_block_saved). A shorter run is stored row by row (set_k_row), into the row-major form, or into the VNNI column when the block is converted already. In more detail: after the stores, main records the saved rows. A block that a short run completed is queued. The forward end converts the queued blocks (convert_pending_k_blocks). Under hardware attention main records no row and queues no block, and the block stays row-major. The diagram reuses the block colours of the kv_cache.hpp page.

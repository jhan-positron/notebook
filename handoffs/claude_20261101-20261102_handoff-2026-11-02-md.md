## Words used here

- **Asimov**: Positron's chip. One hemisphere has 5 DSUs of 2 C1-Nano cores, a CMN S3 mesh with 5 home nodes, a 5 MiB SLC and 5 OCM regions.
- **DSU**: DynamIQ Shared Unit, a 2-core cluster with a shared 128 KiB L2 and a 256 KiB L3. CPU pairs {2,3}, {4,5}, {6,7}, {8,9}. CPUs 0 and 1 run the kernel.
- **CMN S3, home node (HN-S), SLC**: the Arm mesh interconnect, the node that owns an address, and the System Level Cache (1 MiB per home node, 16 ways). **Crosspoint (xp)**: one mesh switch. **Hop**: one crosspoint-to-crosspoint step.
- **OCM**: On-Chip Memory, 4 of the 16 SLC ways in each home node locked by firmware in CMN OCM mode. Five regions of 256 KiB, one per home node, reached through `/dev/ocm` in 4 KiB pages. No memory sits behind OCM.
- **Emulator**: Jesse Zhang's Palladium model `hemi_rtws_tlm` (RTL image 0d9e214). One chip second takes 2,779 wall seconds. Jesse builds and runs our code. We never log in.
- **Chip time**: time as the chip sees it. Jesse allows 5 s per run.
- **membench-jibin-001, -002, -003**: Jesse's result folders for run 1 (commit 9c6b8e7, 2026-10-31), run 2 (commit 8ae533c, 2026-11-02) and the control run (run 2's code on run 1's firmware, 2026-11-02). They sit on the lab's shared /home at /home/jzhang/dev/emuMemBenchBox/results/jibin/.
- **SCP, TF-A**: the two firmware parts of the emulator image (system control processor firmware and Trusted Firmware-A). Run 1 used SCP 0.34.0 and TF-A 0.24.0. Run 2 used SCP 0.48.0 and TF-A 0.35.0.
- **delphi-3bda**: the CI machine. Used here only for read-only `ls`, `rsync` and `scp` of the lab share, which claude-agentsrv cannot reach.
- **CRB**: the Arm Neoverse V3AE reference server at 192.168.2.45 (user jhan). Used only to compile the aarch64 binaries with Jesse's flags and run the quick self-test. It must not be used while /tmp/positron-perf.RUNNING exists there.
- **cmncount**: the new C helper of run 2. It opens the mesh PMU `arm_cmn_0` through `perf_event_open` (the image has no `perf` tool), counts requests at each of the five home nodes around one command, and writes the command's lifetime rows.
- **fresh chain**: a random pointer chase walked exactly once. **flushed**: `DC CIVAC` (clean and invalidate) over every line of the buffer before a timed pass. **L3 read refills**: core PMU event 0xA2 per load, 1.00 when every line came from beyond the DSU.

## Gotchas & decisions

- tp4 thread split: a prefill window has 15 main helpers and 40 attention workers. The helper count is `fixed_main_helper_split` = pool workers x 2 / 7 (27 workers give 7 at tp2, 55 give 15 at tp4), then capped by `available_main_parallelism(items)` = items x the model's MoE top-k (1 for qwen). A decode pass has 8 items, so its cap gives 8 helpers and 47 attention workers [model.hpp:1933-1935, 1950-1960, 1976-1982 and TronCpp.hs:1397-1412]. The "threads" field of `analysis.json` and the "cls" output of `lanes.py` report the decode split for tp4 and are misleading for prefill.
- Do not cite Save K numbers with the wrong helper count: the ideal factor at tp4 is 16x, the measured shared-save-alone factor is 7.86x.
- `lanes.py TRACE 2 10` means pass index 2 (0-based, the third prefill pass) and layer 10 (0-based, the 11th layer). The report calls it "prefill pass 3, layer 10".
- Kernel names in the traces: the rope kernel of layer L is `kernel_rmsnorm_rope_rmsnorm_rope_L`, the residual-add kernels are `kernel_add_rmsnorm_2L` and `_(2L+1)`. Layer 0 has no suffix.
- Pages written in a pass are not dense for that pass's queries (a visible range closes above each query token). So the Pending sections run the AVX-512 reader `k_vnni::qk_group`, and the AMX kernel reads the planes only in later passes.
- The K completion marks are consumed only by the FPGA GOF dispatch and an assertion. CPU attention's gate is the latch, which needs both Save K and Save V.
- `store_block` runs its body once per dim step: per block and KV head that is 64 loads, 4 transposes and 64 stores, not 16 loads and one transpose.
- The Write tool refuses to overwrite a file it has not read in the session. Read `context_sections.py` first, then Write.
- Every generator patch is a Python script that asserts each search string occurs exactly once. A string that spans two Python literals fails and nothing is written. Three patch attempts stopped that way. Check `cmp` against the backup before rerunning.
- `levels_tree()` in `context_sections.py` asserts every ASCII tree line is at most 118 characters. Long thread-count labels broke it twice.
- A grep with a long regular expression fails with "ugrep: error: ... exceeds complexity limits". The shell's grep is ugrep. Use a Python script instead.
- The Artifact tool's read of a live artifact returns the file wrapped in its own skeleton plus a trailing `</body></html>`. Compare bodies, not whole files.
- No node on claude-agentsrv. cairosvg and PIL are present, so static SVG figures can be rendered to PNG and inspected with the Read tool.
- Wording rules the reviews enforced: define Save V, K row versus K buffer entry, and every thread class at first use. Cite one commit consistently (the page now cites 30c4ac82cb everywhere). Do not call the helper set "fixed" (its size is chosen per pass).

## Gotchas & decisions

- User preference recorded in memory: header comments should say why/context
  in plain words, not restate what the code does; a later session should not
  propose mechanics-describing comments again.
- The chosen replacement comment deliberately drops the undefined term
  "factory contract" and the test-file name.
- `if constexpr` vs run-time `if` is a type question, not a value question:
  only `if constexpr` discards the branch whose `try_create` call would be
  ill-formed for a 3-argument-only cache. The in-tree test type
  `three_argument_sequence_cache` (t_llama_unit.cpp) exists exactly to catch
  this.
- "Today every production cache is a book" (book = the only cache type with a
  mirror arena): the 3-argument fallback path is compiled but never runs in
  production; it exists for cache types that know nothing about AMX.
- Even a `book` created with the eligibility bool true can lack the arena at
  run time (AMX unavailable, `TRON_AMX_DISABLE=1`, nothrow `new` returning
  null, or the default build with `TRON_AMX_K_MIRROR` off), which is why every
  mirror consumer null-checks.

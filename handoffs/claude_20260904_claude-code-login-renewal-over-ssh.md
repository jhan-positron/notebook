## The answer given (login renewal over ssh)

1. Type `/login` and pick the account type (Claude subscription account, or Console/API billing).
2. Do not press Escape or Ctrl-C while it waits. It prints a long `https://claude.ai/oauth/authorize?...` URL; copy the whole URL even if the terminal wraps it.
3. Open the URL in the browser on the laptop and approve access.
4. Paste the shown authorization code into the terminal prompt "Paste code here" and press Enter.

"Login interrupted" means the wait was cancelled before the code was pasted (Escape, Ctrl-C, or a dropped ssh session). Run Claude Code inside tmux or screen if the connection is unreliable.

Long-lived alternative (subscription accounts only):

```
claude setup-token
export CLAUDE_CODE_OAUTH_TOKEN=<token>     # put in the shell profile on the server
```

The token is valid for about a year (Claude's statement in the session; not verified against documentation). With it set, Claude Code skips the interactive login and the expiry warning goes away. Console/API accounts use `ANTHROPIC_API_KEY` instead.

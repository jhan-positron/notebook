### The four new majors

- **N01 (with M01, N61): 8-lane build guidance.** The design orders packed-V bodies and test runs for the 8-lane build. At unmodified main, `t_llama_unit` and `t_heterogeneous_scheduler` do not compile there, because `page::set_v` and `page::get_v` exist only under the 16-lane build. Only class completeness is needed at 8 lanes. (Inferred from `#if` guards; not compiled.)
- **N02: TRON_IGNORE_NAN.** The macro is a PUBLIC compile option for every non-Debug build (src/tron/CMakeLists.txt lines 292 to 295). The native, deb and Nix test builds are RelWithDebInfo. So the design's NaN rule describes Debug builds only, and a NaN test expectation written from it is build-dependent.
- **N03: child K storage.** The child adaptation table promises a `k_vnni_view` accessor but never says the K member of `kv_block` becomes the `k_vnni_tensor` owner under `layout_on`. The child head still casts the raw array in four places (kv_cache.hpp lines 1692, 1706, 1730, 1742).
- **N04: reviewer answers.** The definition of done requires recorded answers from Ben, and the design names no record place and no fallback if he has not answered.

Also for jhan's decision: native-K typing is jhan's request, not Ben's, and the design neither names jhan nor asks Ben (N08). The issue-body edits F19 to F21 are jhan's to post; the page carries proposed text.

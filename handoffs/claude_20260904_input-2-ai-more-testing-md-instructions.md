## Gotchas & decisions

- CI's client runs remotely over 2-4 engines, so its TPS numbers are not
  comparable to one engine on the same host; only within-round ratios and
  MMLU accuracy compare.
- The `talos` reporting library writes to the CI database and Slack; a no-op
  stub keeps the perf and soak code runnable outside CI.
- Production engines run under systemd with no memlock limit; an interactive
  shell needs the limit raised for rinzler to start (handled in `rz.sh`).
- The systems_test client and its Python environment live on delphi-3bda's
  local disk (/var/tmp/jhan/st-venv), not in the NFS home.

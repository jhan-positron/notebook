## Gotchas & decisions

- Self-match trap (bit >= 4 times): `pkill/pgrep -f <pattern>`
  matches its own ssh/shell cmdline (even `[c]hain` bracket forms,
  since the bracket pattern is in the cmdline too). Fix: put the
  check in a script file, or match on binary paths.
- `local A=$1 B="$A/x"` under `set -u` expands before `local` binds
  — silent shell death, no trap, no restore (left the trio down
  once). Split the `local` statements.
- `ci-runner.sh stop` brings inference UP — any kit stopping the trio
  right after it loses the race ("rinzler did not stop; refusing
  hugepage wipe"). Only reclaim when the runner is actually active;
  sleep 90 s.
- `systemctl mask` silently fails for units whose file lives in
  /etc/systemd/system; use `disable`. Log the verified outcome, never
  the intent (same root cause as the hardcoded `DRAW_STOP_UTC=0230`
  ignoring a passed env var).
- Kits rotate `results/` and clear ALL_DONE/RESTORE_DONE on every
  launch — a cited path can be repointed by another agent's run; cite
  `results.prev.<ts>` snapshots.
- Trace loss masquerades as "inter-batch holes": 19-41% of every
  25 s window is producer-buffer discard loss; the five-stat loss
  gate reads all-zero through it; trace_processor's `data_loss` flag
  was firing all along. Perfetto `fill_policy: RING_BUFFER` +
  span-conservation assertion is the fix.
- `perf record -a` on 288 CPUs takes ~1.2-1.4 s to emit its first
  event — clip analysis windows to perf coverage or the leading
  windows score 100% off-CPU.
- `MAP_HUGE_1GB` is not in glibc's sys/mman.h (`<linux/mman.h>`
  only) — `#ifdef` compiled the whole 1G path out; `--page 1g`
  silently fell back to 4K/THP. Also calibrate on the backing you'll
  run (K 96357 4K vs 110423 1G, 15%).
- tronsim renames its main-thread comm to "24/0-Main" via
  set_thread_name — `pgrep/pkill -x tronsim` never matches; match the
  cmdline path.
- gpt-oss aliases need the `ingested-` prefix
  (`ingested-gpt-oss-120b-tp4`); grepping for a substring of an
  assignment gave the wrong alias twice. Read the assignment, don't
  grep fragments.
- A single 26-draw CV is unstable near a threshold: same
  argv/binary/host an hour apart gave 3.358% vs 1.794% (2.17x across
  5 rounds). Near-bar verdicts need pooling; ab60g's 2.615% flagged
  provisional.
- Unquoted `|` in a remote `rg` (`rg -n a|b files`) hangs on stdin
  forever; the harness pre-flight greps cmdlines for "runtron",
  matches the hung shell, and refuses to start —
  `logdir-never-appeared` failures that look like disk/harness
  faults.
- Both of jhan's SSH keys land on the DUT as uid jhan — only source
  IP + authorized_keys comment distinguish sessions; unix ownership
  can't.
- ab57's "tail carries ~94%" localization was a coverage artifact —
  against the true per-token cost, both rounds put the tail at
  17.5-30%; rho(mem-stall,gen) ~ -0.75 is NOT a lottery fingerprint
  (flips sign within gpt-oss between geometries).

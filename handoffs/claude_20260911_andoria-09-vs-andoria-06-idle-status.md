## Gotchas & decisions

- ssh to andoria hosts from the container: use `ssh -i ~/.ssh/id_ed25519 -l jhan <host>`; the default is root and is refused. Host keys were accepted with StrictHostKeyChecking=accept-new.
- andoria-09 is a CI runner with no lease file, so the delphi-3bda busy check does not apply there. The only guard is checking for a Runner.Worker process; jobs arrive without warning. Its load average of 81 is stale D-state threads, not work.
- andoria-06: bhamon logs in daily and runs agents from a tron checkout; a short test does not collide, a long benchmark should be announced. 87 GB of free RAM fits a small model, not a 120b model.
- Build on the AMD host in a fresh directory. A binary built with -march=native on delphi-3bda may contain AVX512-FP16 instructions that Zen 4 lacks and would die with SIGILL. gen-amd/ is that fresh directory; the build took about 11 minutes niced.
- strace cannot be used on runtron: tracing breaks its setuid FUSE mount helper and runtron exits before loading the model. The LD_PRELOAD shim on the syscall() function is the working method; runtron links syscall dynamically, so interposition works.
- There is no log line or counter that names the AMX or AVX path. Observable evidence is the arch_prctl call (shim), SIGILL absence, and t_amx_numerics printing "AMX unavailable on this host". t_amx_dispatch_dtype uses fakes and proves nothing about the real probe.
- Identical tokens between AMX-on and kill-switch arms do not prove the AVX path; on Intel they were identical too in this run.
- tron adopts a stale slice file of the right name in /dev/hugepages even when owned by someone else, and truncates it to its own size. Check /dev/hugepages before a run on a shared machine.
- The .passed marker has no platform dimension: a pass on an AMD runner suppresses later Intel test runs of the same source (35 of 47 test-host jobs skipped). A green run log looks the same in all three cases.
- The FPGA runner group has four Intel hosts with AMX; delphi-3af6 is missing from the README inventory; the delphi-3bda runner is disabled by configuration (0 jobs this week). The per-commit benchmark job runs on AMD only.

- **kv_cache.hpp**: h/tron/models/kv_cache.hpp, the KV cache data structures (book, page, kv_block). The PR adds 484 lines and removes 55 in this file.
- **VNNI K layout**: the pair-interleaved K cache layout of https://github.com/positron-ai/tron/pull/4424, which the AMX kernel reads as one B operand. **Row-major**: the plain layout, one token's K per row.
- **Book**: the unit of KV memory allocation. It holds the K and V of one run of consecutive tokens for all layers. The token tree owns many books. **Page**: 64 tokens of a book. **Block**: 16 tokens of one KV head's K inside a page. **kv_block**: the K plane plus V plane of one (storage slot, KV head) pair in a page.
- **Storage slot**: one layer's K and V storage in a page. **State entry**: the per-slot layout state (k_rows_saved_ and k_vnni_blocks_ bits) that the PR adds.
- **k_rows_saved_**: per slot, one bit per saved K row. **k_vnni_blocks_**: per slot, one bit per block that holds the VNNI layout.
- **save_k's row-recording loop**: the loop the PR adds to save_k in model.hpp. It records each saved row and queues a block for conversion when its 16th row arrives. The page first called it "note loop", a name Claude made up and later removed.

- **Okabe-Ito palette**: a colourblind-safe set of eight colours. The page assigns one colour per concept.
- **cairosvg**: the Python SVG renderer used to check every figure as a PNG.

- Labels centred on a vertical arrow's x collide. Offset them.
- Inside `<pre>`, rows with `display:block` must have no newline between them, or every row gets an empty line.

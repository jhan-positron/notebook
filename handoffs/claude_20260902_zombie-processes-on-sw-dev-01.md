## Gotchas & decisions

- Zombies cannot be killed; only their parent can reap them, or the parent
  must exit so PID 1 of the parent namespace adopts and reaps them. A
  `sleep infinity` PID 1 never reaps, so the container must be recreated.
- Recreating the container ends the Claude sessions inside it; transcripts
  live on NFS and `claude --resume` brings them back.
- Ubuntu's catatonit package installs /usr/bin/catatonit plus the
  /usr/libexec/podman/catatonit symlink podman looks for; without sudo,
  `--init-path` to a static copy in the home directory works the same.

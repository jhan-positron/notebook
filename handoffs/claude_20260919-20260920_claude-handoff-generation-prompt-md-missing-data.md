## Gotchas & decisions

- Agent fix loops on prose add text every round. The 25-agent Workflow grew the prompt from 410 to 988 lines. Writing the condensed version by hand from the verifiers' findings, with agents used only to verify, gave 601 lines. For this user's prose: agents verify, the session writes.
- rows.json `source_files` is a Python list rendered as a string. `ast.literal_eval` fails on some rows (apostrophes inside descriptions); a split on `', '` is the fallback. Citations come as `path:lines (description)`, with brace lists `{meta.json,perf.json}` and sibling shorthand `(and rep2-rep6 ...)`. Expand braces before splitting on file extensions, or brace members are read as separate files and reported missing (47 false "missing" files on the first pass).
- A citation with a line range but no description says nothing about what the line holds. Server logs are cited by line for version and NUMA data. Test the content of the cited lines (`Parsing the prompt took`, `average tok/s`) instead of the presence of a line range, or every `rinzler.log` is proposed (9.5 MiB).
- The duplicate check for per-repetition logs must compare the `[Request N] ...` payload, not the whole line: the timestamp prefix differs between the log and the compact text.
- The twelve t4 runtron logs (`cap*.log`, `capsweep*.log`, `capover*.log`, `power*.log`, 3.46 MiB) are cited by line for TPS and TTFT values the page shows, and no t4 compact text holds those lines (checked with grep on 2026-09-20). The rule proposes them. The status doc's tier 2 assumed the compact texts held them and listed only the five `t4/*.txt` files.
- The two `pwd`-only sessions (kv-head 2026-08-28, single-attention 2026-09-01) are not activity. One of the two handoffs carries the lone-`pwd` note already; do not update them.
- Eight Codex processes were running during this run, and one edited `codex-handoff-generation-prompt.md` in the same clone. Commit only own paths and re-check `git status` before committing.
- `git mv` stages the rename at once. A later `xargs git add` plus `git commit` then carries the staged rename into whichever commit comes next. In this run the rename of the tron-4500 handoff rode into the lineage batch commit a54f6df with the old content, and the merged content followed in 4709e1e. Commit an update right after its `git mv`, and add the new path only.
- Drafter agents list many artifacts by basename under a directory header. Exact-path annotation then hits few lines (41 of 191 proposals). A one-line summary annotation per Artifacts section plus the README registry covers the rest.
- When a copy pass is interrupted and re-run, test "already mirrored" against `git ls-files`, not against the working tree, or the second pass records the first pass's copies as skips.
- `gen_compare.py ROWS_JSON` with one argument overwrites the canonical page. Always pass the output path.

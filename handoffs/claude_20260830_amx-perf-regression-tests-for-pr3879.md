## Gotchas & decisions

- Piping a build through `| tail -2` hides compile failures; check the exit
  status or the binary hash instead.
- `pgrep -x runtron` does not match renamed binaries; the guard now matches
  `runtron.*`.
- gpt-oss-120b 8-user cells are very noisy (34% peak to peak on one arm);
  three reps cannot detect a real 8% effect there.

| prompt | arm | QK | PV | common (softmax pieces + state update) | total | AVX / arm |
|---:|---|---:|---:|---:|---:|---:|
| 8192 | AVX | 1.87 | 1.62 | 0.16 | 3.64 | 1.00x |
| 8192 | canonical | 1.49 | 1.11 | 0.29 | 2.89 | 1.26x |
| 8192 | mirror | 1.12 | 1.23 | 0.31 | 2.66 | 1.37x |
| 2048 | AVX / canonical / mirror | | | | 2.80 / 2.14 / 2.07 | 1.31x / 1.35x |
| 256 | AVX / canonical / mirror | | | | 2.88 / 2.38 / 1.36 | 1.21x / 2.12x |

Readings: in the cache regime (prompt 256) the mirror's QK is 3.0x faster
than the dotter, in the RAM regime only 1.67x and PV 1.31x, because both
arms read the same 32 KB per unit and the tile unit waits for RAM like the
vector unit does. Canonical vs mirror is a QK story: the transposing store
costs 0.37 us per unit at 8192 and 1.0 us at 256. Fixed cost per attention
operation (joins plus closing barrier) is 9-13 us, or 320-480 us per token,
which exceeds the hot-loop time at prompt 256. The common work is only 4-12%
of a unit, so it is not what dilutes the 8x MAC ratio. The probe's own cost:
instrumented stamp 7605 sits 0-5% above fence round 3; the timed phases
account for 83-98% of it. Power: not captured (Insufficient data).

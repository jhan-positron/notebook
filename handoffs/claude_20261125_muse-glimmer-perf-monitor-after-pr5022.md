## Words used here

- **tron**: Positron's inference program (GitHub repository positron-ai/tron).
- **PR 5022**: https://github.com/positron-ai/tron/pull/5022, "AMX attention: serve kv_mul 16 (Muse Glimmer) with a group_heads template parameter". It merged on 2026-11-25 at 18:33 UTC as commit `67a380d9c0`. The peer handoff `claude_20261124-20261125_pr5022-rebase-and-merge.md` covers the merge.
- **AMX**: Intel's CPU instruction set for matrix math. The PR lets Muse Glimmer's CPU attention use it. AMD machines have no AMX.
- **Muse Glimmer 30B**: the model the PR targets. Its nightly setting is tp4 (four FPGA cards), 8 users, a 1024-token prompt and 1536 generated tokens.
- **Nightly systems test**: the scheduled test session of each machine, named "System CI (date)". A bot named talos posts its report to the Slack channel #ci-cd-notifications.
- **delphi-3bda**: the Intel CI machine (Granite Rapids). **andoria-b1a3**: the AMD CI machine (Genoa). This session read their results and did not log in to them.
- **Talos**: the internal test-results service. Its REST interface is `http://talos:5000`, and its web page is `http://talos:5174`.
- **TPS**: tokens per second per user during decode (token generation). **TTFT**: time to first token in milliseconds, the nightly's measure of prefill (prompt processing).
- **Series**: one model at one setting, for example "llama-3.1-8b tp2, 8 users". Each machine has 12 series. **tp2** and **tp4**: a model layout on two or four FPGA cards.
- **Normal**: the median of the baseline nights of one series. **Spread**: 1.4826 times the median distance from the median, a robust stand-in for the standard deviation.
- **Band**: the normal plus or minus the largest of 4 spreads, a floor of 0.75% (decode) or 1% (TTFT), and 3 ms (TTFT). A night outside the band counts as changed.
- **Baseline nights**: the newest nights before the PR with the same platformd version, the same FPGA image and the same test settings, back to the last level shift.
- **Level shift**: two nights in a row more than 3 spreads from the median.
- **platformd**: the platform software whose version each session records. **Bitfile**: the FPGA image.
- **Day N**: the Nth night whose tron build contains the PR.
- **Running session**: a nightly session that has not finished. Talos names it `Performance Benchmarks (date)` and gives it no `dut` field (the machine name) until its last phase ends.
- **Soak test**: the long stability run at the end of a nightly session.
- **Package build**: the tron workflow `publish-deb.yml`, which builds the package that the nightly tests. It started at 01:20 UTC (17:20 Pacific) on the last 3 days.
- **Session cron job**: a prompt that the Claude Code session runs on a schedule (tool `CronCreate`). It lives only in that session and expires after 30 days.
- **Cloud watch**: a separate hourly cloud task that watches PR 5022 for review activity, from the session of handoff `claude_20261120_pr5022-review-monitoring.md`.
- **MMLU Pro**: an accuracy score in the nightly. The page lists it, and the watch does not judge it.
- **Backtest**: leave one baseline night out, build the band from the others, and test the night. A flagged night is a false alarm.
- **claude-agentsrv**: the podman container that Claude Code ran in, on the user's Linux dev server agentsrv.

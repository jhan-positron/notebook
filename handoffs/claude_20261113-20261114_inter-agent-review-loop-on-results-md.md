### The findings that changed the design most

- **T1 (high).** The first draft's main experiment tested the effect of a preceding loop. In the original run each read loop ran alone in its own process, so that effect could not occur there. It also has the wrong sign: it makes old read slower, which enlarges the gain.
- **T2 (high).** The draft stated no candidate explanation. The earlier plan holds one: old read stays near 67 GB/s at 32 KiB, 1 MiB and 8 MiB, and new read falls from 85 to about 67 GB/s between 1 MiB and 8 MiB. So the two rates may be close at 8 MiB by two different limits.
- **T5 (high).** The trial schedule tied each condition to the same preceding trial.
- **U1.** The limit of the size experiment left out the variation between processes.
- **U2.** Several pass gates could not pass with fixed margins of 0.10 and 0.20 GB/s. The margins are now set from measured variation.
- After the review the design tests the size explanation first, with one read loop per process, and adds 4 MiB and 16 MiB.

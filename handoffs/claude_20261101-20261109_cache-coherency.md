## Gotchas and decisions

- `python3 -I` cannot import `fitz` or `pymupdf4llm` on this host, because isolated mode skips /home/jhan/.local. Run the conversion scripts with plain `python3`.
- Split the md into pages with a pattern that allows missing spaces, such as `Page\s*\*\*(\d+)\*\*\s*of\s*\*\*914\*\*`. Two footers (pages 248 and 623) are inside a table cell as `Page**248**of**914**`.
- Compare words only after a normalization that makes "field", "feld" and "eld" equal. The session deleted every run matching `f+[il]?` on both sides. Without this step the measured coverage is 60.5 %. With it the coverage is 79.6 %.
- A whole-document conversion is the valid test, not single pages. pymupdf4llm chooses headers from font statistics of the whole document.
- The txt files keep ligatures as single glyphs. The session read this as the output of `pdftotext -layout`. This is an inference from the file format, and the tool was not recorded.

## Gotchas & decisions

- The guard, CI, and Bill-sharing rules live in the notebook repo's handoffs folder, not under intel-AMX. The intel-AMX handoffs are work-state files that cite the guard doc instead of restating it.
- On gpt-oss one GQA group per decode step is 8 queries x 64 values. On qwen it is 4 x 128. Same byte count, different shape, so the 128-wide K packing and the 4-row Q stacking do not fit. Supporting gpt-oss is a second kernel instance, not a parameter change.
- What a 64 x 8 variant changes: Q group stays 1024 bytes but packs as 2 panels of 64 dims instead of 4 of 128. QK covers the head dimension in 2 tile passes instead of 4. The scores tile fills 8 of 16 columns instead of 4, which is better tile use per page. PV writes 8 rows x 64 instead of 4 x 128. Packers, mirror arena layout, and tests all carry the 128x4 suffix and need a twin.

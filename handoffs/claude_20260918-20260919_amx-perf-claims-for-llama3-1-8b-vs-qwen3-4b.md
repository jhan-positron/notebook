## Words used here

- **tron**: Positron's inference program (GitHub repo positron-ai/tron). **rinzler**: the inference server process, installed from a Debian package (a deb). One running rinzler is one **engine**. **runtron**: tron's command-line benchmark tool (one process, no proxy).
- **AMX**: Intel Advanced Matrix Extensions, the tile matrix unit. **The kernel**: the AMX software-attention kernel of **PR #3879** (https://github.com/positron-ai/tron/pull/3879, merged on 2026-09-15). It is compiled only when the CMake option **TRON_AMX_DISPATCH** is ON. **PR #4424** (https://github.com/positron-ai/tron/pull/4424): the VNNI-K layout, not merged. PR #3879 and PR #4424 below refer to these two links.
- **kill switch**: TRON_AMX_DISABLE=1 in the environment, which makes a binary with AMX code take the old path. **clean binary**: a build without any AMX code. A kill-switch arm runs 2 to 5 percentage points slower than a clean binary, so every gain must name its denominator.
- **canonical**: the kernel reading the K cache as stored. **mirror**: the kernel reading a VNNI K mirror (an option of PR #3879). Mirror against canonical is a layout effect, not an AMX gain.
- **TPS**: decode tokens per second per user. **TTFT**: time to first token. **tp2**: the model split over two FPGA cards per engine.
- **nightly, System CI, systems_test**: the automated nightly test job of the systems_test repository, run on delphi-3bda at 03:30 UTC. **CI harness**: its client code (systems_test scripts/perf.py and testlib/tps.py). **config** or **shape**: one row of the harness perf list: a model, its tp and a user count. **users per engine**: the nightly spreads its users over 4 tp2 engines behind the **Caddy** proxy, so 8 users means 2 per engine.

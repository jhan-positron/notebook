## Gotchas & decisions

- `dpkg -S` owning a file under /etc does not make it a conffile. tron ships no conffiles list, so a reinstall overwrites the unit silently. `dpkg -V tron` shows `??5??????` for it.
- The nightly's first steps on the test machine are `apt-get remove -y tron` then `apt-get install -y tron`, then `apt-get upgrade -y`. prerm does no daemon-reload. postinst runs `systemctl daemon-reload`.
- systemd loads a template instance's configuration when the instance is first referenced. Instances not loaded now read the edited file at their next start. The running one keeps its old command line until a daemon-reload plus restart.
- A dense model such as llama ignores `--num-expert-replicas` silently. Only `--expert-placement none` plus a nonzero count is rejected.
- Verification was read-only by design. No rinzler may be started on delphi-3bda from a Claude session for a check like this, because pos_startup resets all cards without a SYSTEM_CONFIG slice.
- The 2026-09-16 perf round: "no AMX" meant a main build from before PR 3879 (eb2de0265a), not the kill switch. Blocks A and C forced CPU attention with `USE_HW_ATTN=0`. Blocks B, D, E and F left it unset (FPGA attention for ingested models). Driver was runtron with 8 users per process on our half, not the CI harness on the whole machine.
- A drop-in that replaces ExecStart needs an empty `ExecStart=` line first, because Type=simple allows exactly one command.

## Gotchas & decisions

- Half of the user's memory was right. The policy predates Bill's final commit but not his layout. Bill's 2026-07-02 change renamed die-A cores to their HT-sibling ids, so the map's core ids differ from FAST_CORE_RANGES while the physical cores are the same.
- launch.sh blocker: a `pgrep -f '<path>/campaign.sh'` inside an ssh command string matches the remote `bash -c` shell that carries the same text, so the launcher believed the campaign was already running and never started it. Fix: anchor the pattern to the campaign's own argv (`^bash <path>/campaign\.sh$`), or test the campaign's flock instead.
- Idle detection of a rinzler unit: request activity is visible only in the periodic `#EVT# SYSTEM_STATS` journal line. The interval between those lines grows past 10 min when the unit is idle (gaps of 960 s to 2278 s were seen). A window with lines but no SYSTEM_STATS line must not be judged idle. The same weakness exists in lib-guard.sh's rinzler_takeover_if_idle.
- The campaign watcher process must write the done marker, status and summary when the main process dies by SIGKILL, because the EXIT trap does not run on SIGKILL.
- "1k prompts" was read as 1024-token prompts, the p1024 shape of the July and nightly tests, not 1000 different prompts.
- Model choice: the three tp2 configurations that barely fluctuated in the August matrix (llama-3.1-8b-instruct-good, mixtral-8x7b-instruct-v0.1, qwen-2.5-32b-it-fast) plus the requested qwen-3-4b (ingested-qwen-3-4b-instruct-2507-tp2).
- The nightly CI run on 2026-09-17 held the lease from 03:39 UTC to 13:20 UTC, about 9.7 h. Plan campaigns for after 13:30 UTC, not the 11:25 UTC end that older notes assume.
- Coordination worked through peer messages: announce scope and window, wait for replies, message again when the flock is released.
- Moving the project folder was safe because both paths are on the same NFS share (a rename) and no process held files in it. A running Claude Code session keeps its old project key until restarted in the new folder.
- Three review rounds (122 agents in total) found 3 blockers and about 40 lesser defects before launch. The most consequential were a watcher expectation that would have killed every boot-arm run, a restore path that could have rewritten Bill's socket, and a silent fallback to an older binary.

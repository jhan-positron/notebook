- **Read kernel**: the inner loop of the benchmark that reads memory. It is not the Linux kernel. **Old read kernel**: a C loop with sums (`read` of `bw_old`, `oldread` of `bwx12`). **New read kernels**: load-only loops (`read` of `bw_new`, `read` and `asmread` of `bwx12`).
- **As-run copies**: the script texts that are on CRB in `~/cache-perf/w120-7200-20261117` since 2026-11-17. **local.sha, go2.sha**: the checksum lists on CRB that these texts must fit.
- **Boot-id check**: one line of go.sh and go2.sh that stops the script in every boot except the one of 2026-11-17. **go-direct.sh, go2-direct.sh**: copies of the two drivers without that line, written on CRB by a `sed` command.
- **run.sh**: the user's older saved command, `code/manual-run/run.sh`. It starts go.sh only and copies no results.
- **Run id**: the UTC start time of a run, here `20261126T010958Z`.
- **stat_k120.py, stat_bwx.py**: the two statistics scripts of the repository that print the rate tables.
- **stderr.txt**: a file in each `bwx12` result folder. `bwx12` writes to it when a hardware counter does not open, and it still ends with status 0.

## Words used here

- tron: the inference program under test. rinzler: its production server binary, shipped as a Debian package (deb).
- AMX: Intel Advanced Matrix Extensions, the CPU matrix unit the new attention kernels use. "AMX kernels" = the code path compiled in when the build flag TRON_AMX_DISPATCH=ON is set.
- "AMX-off": a project term that means the TRON_AMX_DISABLE kill switch of a build that HAS the kernels. It is not the same as a build without the kernels. The session had to correct this wording.
- TPS: decode tokens per second per user. TTFT: time to first token (the prefill wait).
- nightly / System CI: the GitHub Actions workflow of positron-ai/systems_test that runs every night on delphi-3bda.
- delphi-3bda: the CI machine (Intel Xeon 6, "Granite Rapids", 72 cores per socket). andoria (genoa): the AMD CI machine that runs the same suite.
- l8b-8u4k campaign: our own run of 2026-09-20 (exec/l8b-8u4k-20260920) that measured the same 32-user, 4096-token cell with the CI harness, three passes without the AMX kernels ("base") and three passes with them ("canon").
- Workflow: the Claude Code orchestration that fans work out to sub-agents. The session used one to verify its claims adversarially.

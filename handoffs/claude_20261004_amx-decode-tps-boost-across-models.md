## Short version

The user asked whether the decode throughput of most models in nightly CI rose after AMX was enabled on 2026-09-22, and if so why. The session parsed 40 nightly run logs from both CI machines (502 usable performance rows, 09-15 to 10-04), audited the 154 tron merges of the period with a 97-agent workflow, and wrote the report page Was-AMX-boosting-all-models.html. The answer is no: AMX explains only the llama-3.1-8b 32-user row, three other large Intel gains came with the same 09-23 package from two non-AMX merges, and a broad 1 to 2.5 % Intel step on 09-29 has a strong but unconfirmed hardware hypothesis.

## Words used here

- **tron**: Positron's inference program (GitHub repo positron-ai/tron). **systems_test**: the CI repo (positron-ai/systems_test) whose nightly workflow runs the performance rows.
- **Nightly CI**: the scheduled run that installs the newest tron .deb package and measures every model row on two machines. **delphi-3bda**: the Intel machine (also the user's test server). **andoria-b1a3**: the AMD machine.
- **Decode TPS**: generated tokens per second per user. **Prefill**: prompt processing, reported as tokens per second (and time to first token, TTFT).
- **Row**: one model and configuration in the nightly, for example "qwen-3-4b tp4, 8 users". **tp2, tp4**: tensor parallel over 2 or 4 FPGA devices.
- **AMX**: Intel Advanced Matrix Extensions. The AMX attention kernels of PR 3879 run only for head size 128, 4 query heads per KV head, CPU attention, on an Intel CPU. **FPGA attention**: attention scored on the FPGA cards instead of the CPU.
- **Package**: one tron .deb build, named by date and source head, for example 2026.09.23-5cf65b92. **Night step**: the change of a row from one night to the next.
- **CV**: coefficient of variation, the night-to-night spread of a row as a percent of its mean.
- **PR 4505**: https://github.com/positron-ai/tron/pull/4505, the AMX kernels compiled into the .deb (merged 09-22). **PR 4534**: https://github.com/positron-ai/tron/pull/4534, wait statistics off by default (merged 09-22). **PR 4258**: https://github.com/positron-ai/tron/pull/4258, FPGA attention join starts earlier (merged 09-18, first installed 09-23). **PR 4353**: https://github.com/positron-ai/tron/pull/4353, software attention pages split by query (first installed 09-24). **PR 3879**: https://github.com/positron-ai/tron/pull/3879, the AMX kernels source.
- **platformd**: the Positron platform daemon that brings up the FPGA cards. **Bitfile**: the FPGA firmware image, apt-installed with the nightly and programmed into the cards only at a bring-up.
- **RTM and MWAITX**: the Intel and AMD paths of tron's timed wait loop.
- **Workflow**: the multi-agent verification tool. Classifiers and lenses collect evidence, refuters (skeptics) try to disprove each finding.
- **claude-agentsrv**: the podman container this Claude Code ran in, on the user's Linux dev server agentsrv.

Findings tied to the data:

- Every Intel gain is a step on one night, then flat. Post-09-23 night-to-night CV is at most 1.3 % on every Intel row (Table 1, "spread after" column). So the gains are consistent, not fluctuating.
- Group A (the 09-23 package 2026.09.23-5cf65b92, 32 merges): the AMX row +15 %, qwen tp4 +16 %, gpt-oss +8 %, 70b tp4 +3 % on that night. AMD moved +1.5 to +1.8 % on the same rows that night, which matches PR 4258's own numbers. The AMX row's +15.4 % matches the user's own 09-20 on/off test (+14.0 %).
- Group B (the 09-29 package, 13 merges): a broad +1 to +2.5 % Intel step on 11 rows. None of the 13 merges has a mechanism. platformd restarted and the 8 FPGA cards re-enumerated on delphi-3bda at 00:04 UTC that night. On AMD a rise of the same size switches on and off with the bitfile 1.5.9.0 (on 09-26 to 09-30 and 10-02, off 10-01 and 10-03 to 10-04). Labeled hypothesis, not confirmed: the platformd journal needs group adm or one sentence from Rhys.
- Prefill: the three FPGA-attention rows gained prefill on both machines (Intel +8 to +13 %, AMD +7 to +10 %), so those gains are not AMX. Only the AMX row's +61 % is Intel-only.
- Gap: Intel went from 79 % to 89 % of AMD on qwen tp4, 87 % to 97 % on gpt-oss, 97 % to 114 % on the AMX row. Other rows moved at most 1.8 points.
- Bill's PR 4353 first shipped 09-24 and is a small prefill contributor only, so the user's earlier exclusion stands.

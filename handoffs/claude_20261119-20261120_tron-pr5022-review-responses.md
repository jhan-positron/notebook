- **AMX**: Intel's tile-matrix instruction set. **AVX-512**: Intel's 512-bit vector instruction set, the older path ("AVX loop").

- **TRON_AMX_DISPATCH**: the CMake build option that compiles the AMX kernels. Its default is OFF. **Kill switch**: the environment variable `TRON_AMX_DISABLE=1`. The same binary then runs without AMX.

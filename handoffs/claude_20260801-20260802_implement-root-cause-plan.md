  (a) weakening fail-closed checks, (b) writing terminal markers a
  run didn't earn, (c) actions relaying a peer session's declined

  the first character): `ssh delphi-3bda *` never matched
  `ssh -o ConnectTimeout=20 delphi-3bda ...`. Compound commands
  (`cd ... && sha256sum ... && scp ...`) split so each fragment
  needs its own rule. Commands over ~10,000 chars ALWAYS prompt
  (three rendered installers were 12,914/10,587/10,227 chars).

  file (a missing comma killed all rules + autoMode). `autoMode` in
  project-level settings is inert — it must live in user settings
  `~/.claude/settings.json`.

  the delegation addendum was appended to at 20:15Z without
  re-hashing; 7 downstream records cited the stale identity (Codex
  P0, verified bit-for-bit).

## Gotchas & decisions

- Verified flags where the original comments said more than the sources
  (recorded in the memory file and the published page):
  - "bit-parity with AVX" over-promises: a truncating PV variant removes only
    the rounding-mode delta; fp32 add-order differences remain.
  - "anywhere else the arena RAM is wasted" is wrong under current code:
    `maybe_allocate_mirror_arena` returns early when AMX is unavailable, so no
    arena RAM is allocated on non-AMX hosts.
  - The benchmark date in the comment (2026-08-19) was wrong; the sweep header
    says 2026-08-18T18:34Z. The benchmark source `amx_fused_bench.cpp` was
    later removed from the tree.
  - "1250 vs 686 ns" is not a pure orientation comparison: at pages=1 the
    canonical column includes a per-page Q pack the mirror lacks; the amortized
    gap is about 500 ns per page.
  - The store-to-TILELOADD forwarding restriction applies to both kernels
    (the P pack in the PV kernel pays it), not only to canonical-K.
- `TRON_AMX_K_MIRROR` does not gate compilation of the mirror kernel — the
  kernel is compiled in every `TRON_AMX_DISPATCH` build; the flag gates
  dispatch, the K-mirror arena, the `save_k` write-through, and the test.

## Current state

- Main conclusion: slow tokens are not executing more host instructions,
  saturating DRAM, transferring more FPGA data, or being descheduled. They are
  consistent with longer residency in instruction-light waits.
- Group F does not identify which readiness event is late or which producer
  releases it.
- Stage 3 was useful for late-stage localization, but Codex judged its headline
  "one stage owns the difference" as too strong.

## Words used here

- **CRB**: the Arm AGI CPU reference board, also called the Phoenix Reference Server. Its address is 192.168.2.45, its hostname is `ubuntu`, and it has 128 CPUs.
- **Die, chip, chiplet**: one of the two 64-core chips in the processor package of the CRB. The kernel log calls CPUs 0 to 63 "chip number 0" and CPUs 64 to 127 "chip number 1". A die-to-die link joins them (UCIe, a standard for links between chips).
- **PCIe port (root port)**: the point where a PCIe device or a card slot attaches to one die. **PSS**: PCIe subsystem, Arm's name for one group of ports. Each chip has 3.
- **PCI segment**: the first field of a PCI address, for example 0007 in 0007:01:00.0. On the CRB each root port has its own segment.
- **CEM slot**: a standard PCIe card slot. **OCP slot**: the slot of the installed network card.
- **NUMA node**: a group of cores and memory that Linux treats as one place. **UMA**: the firmware setting under which Linux sees one node for the whole machine. **PER_CHIPLET_NUMA**: the firmware setting that gives one node per chip.
- **DMA**: the device reads or writes host memory itself. **Register access (MMIO)**: a core reads or writes a register of the device.

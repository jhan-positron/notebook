## Words used here

- **platformd**: Positron's host daemon. At each provisioning it writes /etc/rinzler/instance-N.env (core list and command-line arguments per engine) and starts the rinzler@N units.
- **rinzler**: the production inference server binary, one systemd unit per engine. **tron**: the inference engine library and repository rinzler is built from. **runtron**: tron's command-line benchmark tool.
- **AMX**: Intel Advanced Matrix Extensions, the tile instruction set. tron's AMX attention kernels are compiled in when the CMake option TRON_AMX_DISPATCH is on. **TRON_AMX_DISABLE**: the environment variable that turns the kernels off at run time when its value is exactly "1".
- **deb preset**: the CMake preset that builds the released Debian package (`make deb`). **PR 4505**: https://github.com/positron-ai/tron/pull/4505, the PR that turned TRON_AMX_DISPATCH on in that preset (merged 2026-09-22).
- **Intel Speed Select (SST)**: Intel's per-core frequency control. The tool intel-speed-select is built from Intel's GPL source and installed at /opt/intel-speed-select/intel-speed-select on delphi-3bda. **CLOS**: a class of service, the per-core priority the tool sets. The configuration does not survive a reboot.
- **intel-speed-select-state**: the systemd oneshot service that Hannah's Ansible role (positron-infrastructure PR https://github.com/positron-ai/positron-infrastructure/pull/165) installs. It applies the configuration at every boot.
- **delphi-3bda**: the Granite Rapids test machine that runs the nightly CI. **andoria**: another machine family. **OCI machines**: the production hosts.
- **Workflow**: the multi-agent tool. Readers collect facts, a drafter writes, verifiers check against the sources.

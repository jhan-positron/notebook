## Words used here

- **Asimov**: Positron's chip. **Emulator**: a Cadence Palladium Z3 machine that runs the chip's design (the RTL) before silicon exists.
- **GA13**: the Cadence cloud site with the large emulator. Login host `ga13ut01.cadence.com`, launch hosts `ga13pd01` and `ga13pd02` (18 boards each). Each person needs an account that Cadence issues.
- **Spokane**: the local emulator site with 4 boards. Driver host `palladium-94a4`. It needs no Cadence account.
- **Board**: one unit of emulator capacity. A model needs a fixed number of boards.
- **Release**: a dated folder of prebuilt chip images that Alexey builds, for example `a10181848`. **Model**: one image in a release. **`hemi_rtws_tlm`**: the model Jesse uses for the user's tests (one hemisphere of the chip with the reduced TWS block, 4 boards). The transcript does not expand TWS.
- **Boot stack**: the asimov-os version (SCP firmware, TF-A firmware, kernel, address map) that a release needs.
- **Queue**: the shared list of emulator requests. At Spokane it is the file /ice/infra/asimov-emu/queue.sqlite3. **Request**: one row of it, with a number such as #4045.
- **`run.sh`**: the entry script for every emulator run, `emu/common/scripts/run.sh` in the asimov repo. **`--run-only`**: run a prebuilt model without a build. **`link_results.sh`**: the script that links a release's prebuilt models into one's own tree.
- **Chip time**: time as the emulated chip sees it. **Cycle**: one period of the emulator's 2 GHz clock, so 2,000,000,000 cycles are 1 s of chip time.
- **Skill**: a folder with a `SKILL.md` that an agent loads when a task matches. **Plugin**: a packaged skill installed from a **marketplace** (a git repo that lists plugins).
- **palladium-emulation**: the team's skill for launching, watching and stopping emulator runs. It is a plugin of the marketplace `aps`, the repo positron-ai/aps-agent-skills. The handoff calls it the team skill.
- **asimov-emu-models**: the personal skill this session wrote. Its file `models.md` is the model table.
- **Global instruction files**: /home/jhan/.claude/CLAUDE.md (read by every Claude Code session) and /home/jhan/.codex/AGENTS.md (read by Codex on this host).

## Findings

### 1. Config column "2K, 512"

512 is `output_tokens` (OSL, the requested output length per request, in tokens). The label is `"<prompt_tokens>, <output_tokens>"`, i.e. ISL (input sequence length), OSL. Formatting: a value divisible by 1024 renders as `<n/1024>K` (2048 -> "2K"). It is not concurrency; concurrency (1-16) is a separate selector/x-axis.

Michael's two batches (REF `5967a460`, run 2026-08-22 08:35-10:42; CAND `edcaf26b`, run 2026-08-21 21:46-23:53) are identical 5-cell grids on the same endpoint and model (`ingested-qwen-3-4b-instruct-2507-tp4`), ISL fixed at 2048, OSL varied, concurrency swept 1 to 16 at 300 s per level, aiperf 0.8.0:

| Config label | ISL | OSL requested | measured OSL mean at c=1 (REF / CAND) |
|---|---|---|---|
| 2K, 128 | 2048 | 128 | 128.0 / 128.0 |
| 2K, 256 | 2048 | 256 | 256.0 / 256.0 |
| 2K, 512 | 2048 | 512 | 511.8 / 512.0 |
| 2K, 1K | 2048 | 1024 | 1014.2 / 1009.0 |
| 2K, 2K | 2048 | 2048 | 1809.2 / 1819.1 |

Caveat noted for readers: on the 1K and 2K rows the model stops early at EOS (about 1010-1020 and 1780-1820 tokens generated), which affects per-token metrics there.

### 2. EAGLE merge date

EAGLE speculation merged to tron main on 2025-02-17: https://github.com/positron-ai/tron/pull/1154 "Support speculation via EAGLE models" (author Fritz Obermeyer, merge commit `f49f999f8`, GitHub mergedAt 2025-02-17 20:37:51 UTC). The feature landed in two steps: https://github.com/positron-ai/tron/pull/1105 (2025-01-25) added generic draft-model speculation with the EAGLE-2 tree algorithm but an ordinary small llama as draft; PR 1154 is the first commit where an actual EAGLE draft model runs. Follow-ons: https://github.com/positron-ai/tron/pull/1157 (llama-3.3-70b EAGLE), https://github.com/positron-ai/tron/pull/1200 (TRON_USE_SPECULATION env var, 2025-03-04), https://github.com/positron-ai/tron/pull/1317, https://github.com/positron-ai/tron/pull/1316, https://github.com/positron-ai/tron/pull/1359.

Speculation has been configured on by default in the deployment stack since mid-2025; what is recent (2026-08-14 to 08-24) is a crash fix, a CI default flip to off, and configuration-change proposals. Gate audit:

| Layer | Setting | Default | Since |
|---|---|---|---|
| tron code | `TRON_USE_SPECULATION` env var (`prefer_eagle`) | off | 2025-03-04, https://github.com/positron-ai/tron/pull/1200 (unchanged, `src/tron/scheduler/full.cpp:40`) |

Scope limit: the draft model is looked up as `eagle-<model>` in the compiled-in registry, and `config/models.yaml` registers only `eagle-llama-3.1-8b-instruct` and `eagle-llama-3.3-70b-instruct` — so the flag only matters for Llama 8B/70B; qwen3-4b and gpt-oss-120b never speculate.

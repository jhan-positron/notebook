## Words used here

- **AMX**: Intel Advanced Matrix Extensions, the matrix unit on Granite Rapids CPUs.
- **TRON_AMX_DISPATCH**: the CMake option that compiles the AMX software-attention kernels of tron PR 3879 into the binary.
- **deb preset**: the CMake preset named `deb` in CMakePresets.json. `make deb` and the workflow publish-deb.yml use it to build the tron apt package.
- **the nightly**: the System CI job of the systems_test repository. It installs the newest tron apt package each night on delphi-3bda (Intel) and andoria-b1a3 (AMD) and runs functional, performance, MMLU Pro and soak phases.
- **TPS**: decode tokens per second per user, the nightly's performance metric.
- **rinzler**: the tron inference engine binary that the package installs at /opt/positron/bin/rinzler.
- **Skip benchmarks**: a tron repository label. The repo's AGENTS.md requires it on every PR.

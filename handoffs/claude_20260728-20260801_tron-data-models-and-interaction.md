## Gotchas & decisions

- **PAL is reachable** despite no local `pal` CLI or session MCP
  entry:
  `ssh andoria-11 "python3 /tmp/pal_chat.py gpt-5.6-sol <promptfile>"`;
  check prior sessions before declaring a capability unavailable (the
  pattern was in "run CI tests" under `claude_debug_3bda_flat_freq`)
- **Standalone SVG is parsed as strict XML**: nested double quotes
  inside attributes (e.g. `font-family`) break it even though HTML
  tolerates them; use `&quot;` and assert parse in the build
- **Figures at natural width overflow the 1120px HTML column** — must
  be full-bleed scale-to-fit, capped at 1:1 to avoid upscaling narrow
  charts
- **Screenshots of the preview pane fail when it's hidden** — measure
  layout programmatically (collision/overflow checks) instead of
  eyeballing
- **Heredoc quoting breaks long PAL prompts** — write the prompt to a
  file and pass the filename
- **`dtensor` declaration order is `<result, contraction>` (output
  first)** — the opposite of the intuitive `in → out` arrow, a
  repeated source of label ambiguity
- **`src/pos/fake.cpp:143` stubs AoF entry points** — fake build
  fires the callback without writing results, so AoF numerics cannot
  be validated without cards
- Averaged per-layer timings can hide prefill no-ops — the "0.73 µs
  per layer" host-cost claim had to be retracted for this reason

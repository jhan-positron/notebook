## Words used here

- **tron**: Positron's inference program (GitHub repo positron-ai/tron). Its software attention path runs on CPU cores.
- **AMX**: Intel Advanced Matrix Extensions. A CPU instruction set with 8 tile registers of 16 rows x 64 bytes. One instruction multiplies tile A by tile B into an fp32 tile C.
- **VNNI**: Vector Neural Network Instructions. Here it names the pair-interleaved layout that the AMX B operand needs.
- **Baseline AMX / canonical-K kernel**: the AMX attention kernel in https://github.com/positron-ai/tron/pull/3879 (PR1). It reads the K page as stored, computes the scores transposed, and transposes them back with AVX-512.
- **Mirror AMX / K\* kernel**: the variant built with the CMake option `TRON_AMX_K_MIRROR`. It reads a second, pre-interleaved copy of K (called K\* or the K mirror) that is written when K is generated. It is parked as PR 2 of the PR 3879 split.
- **pre-split tree**: the git worktree claude-agentsrv:/home/jhan/workspace/ai-runs/tron-presplit at commit 60d66d9c04. It is the last head that holds both kernels.
- **Q pack**: copying the 4 query heads of one KV head into the tile layout the kernel needs.
- **softmax tail**: the steps after the QK multiply: scale, running max, exp, P times V, running-state update, final division.
- **TTFT**: time to first token.
- **G1 / round-1 soak**: earlier measurement campaigns on delphi-3bda whose numbers the page quotes.
- **claude-agentsrv**: the podman container this Claude Code runs in (host machine `agentsrv`, called `claude-box` in the user's notes). /home/jhan is NFS.
- **Artifact**: a page published at claude.ai by the Artifact tool.
- **notebook repo**: https://github.com/jhan-positron/notebook, the user's durable archive. Local clone claude-agentsrv:/home/jhan/workspace/notebook.
- **mojibake**: text shown with wrong characters after a bytes-to-text decoding mismatch.
- **Workflow**: the Claude Code tool that runs many verification subagents from one script.

## Gotchas & decisions

- The Artifact publishing path decoded a valid UTF-8 file as Latin-1 and corrupted every non-ASCII character. Decision: publish only pure-ASCII HTML. Use numeric entities, `<sup>` tags, and CSS escapes, and assert ASCII before calling the Artifact tool. Recorded in memory `artifact-utf8-mojibake-trap.md`.
- Inside inline SVG do not use superscript tspans. Both `baseline-shift` and `dy` variants mis-rendered under `text-anchor="middle"`. Write S^T as plain text, the notation the tron code comments use.
- Number traps corrected by the verification agents: 0.37 us is the QK-phase gap only, the whole-unit gap is 0.22 us. Arena sizes are GiB (kv_cache.hpp divides by 1024^3 but prints "GB"). Q pack happens once per token x KV head x section, not per token x KV head.
- Sketch corrections: P is never normalized before P times V, only its sum is kept. The sketch's second "softmax" is the running-state rescale c = exp(m_old - m). The final division happens once per token after the cross-worker join, not once per page. The multiply by the attention scale is missing from both columns.
- What the sketch leaves out: K\* sits beside K, it does not replace it. V needs no mirror because V is already stored pair-interleaved. The two kernels' scores are bit-identical by unit test. Only dense 64-token pages take either AMX path.
- Notebook preservation recipe (five steps, in memory `notebook-preservation-convention.md`): edit the canonical file first, prepend the "Rendered page" comment block, copy into artifacts/intel-amx/pr3879/, add a dated README batch entry, commit as "Preserve artifact: ..." and push, then republish the Artifact from the canonical file.

## Gotchas and decisions

- The first diagnosis ("the agents died at 20:43") was wrong. It scanned only the container cgroup. Socket peer-inode matching found the host server. Check host-side herdr servers and socket peers before declaring panes dead.
- A `read` inside a startup file, interrupted by Ctrl-C, makes bash abandon the rest of all startup files.
- `herdr --session NAME` starts an empty session by design. Plain `herdr` reopens the default session's spaces. The user chose to keep the named session.
- The host has yama ptrace_scope=1 and no reptyr, so the live agents under the host server cannot be re-attached to a terminal.
- The runner-up design (trap INT around the read) needs the read in a subshell on bash 5.1.16, because a trapped SIGINT does not end a plain `read`. Rejected as fragile.
- The third design (a late per-host hook from ~/.profile) touches the shared .profile, which the user wanted to avoid.

## Objective

A reviewer comment on tron (Positron's model-serving/inference runtime) PR
https://github.com/positron-ai/tron/pull/3879 claimed that
`book::mirror(kv_slot_id)` in `h/tron/models/kv_cache.hpp` (the accessor for
the AMX K-mirror arena; AMX = Intel Advanced Matrix Extensions) indexes by
logical slot and ignores the EAGLE storage view (EAGLE = a speculative-decoding
scheme where a small draft model shares the validator model's KV cache through
a shifted "storage view"), so a draft write corrupts the validator's mirror
plane. The session's goals, in order: explain the comment in an HTML page,
verify every claim in it, implement the chosen fix (Option A) with unit tests,
and then work through several more items from the same mock ("persona")
review.

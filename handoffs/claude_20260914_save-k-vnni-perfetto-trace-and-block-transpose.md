## Short version

A Perfetto trace showed the VNNI K store ("Save K") at 859 us per prefill layer against 274 us for the row-major store, on the prefill critical path, which explains the whole +171 ms TTFT loss at tp4. Two remedies, a 16-token block store and striping the store over the idle helper threads, were built as commit 9928cb2849, measured in an 84-run campaign, and cut the span to 60 to 80 us per layer so that TTFT is now below the AMX baseline at every prompt length. A 40-agent review led to fix commit 10fc7c724c, a confirmation round reproduced the gain, and the results live in `status/store-remedies-report.html` and `status/handoff-store-remedies.md`.

## Gotchas & decisions

- Editing a running bash script shifts its read offset. The session compensated by removing the same number of bytes from the already-parsed header, then restored the header after the run. Do not repeat this. Copy the script before launching, or wait.
- `pgrep -f` matches its own `bash -c` command line. Use a bracket pattern (`[c]ampaign.sh`) or exclude the caller.
- g++ 11 on delphi-3bda has no `__bf16`. Standalone checks of the kernel headers must use the nix clang (`nix develop --command`).
- A syntax-only check of `t_llama_unit.cpp` needs the fuse3 header, so `build.sh` builds `libfuse3_external` first.
- The Haskell emitter test compared a substring that depends on the test module's buffer name (`kv`, not `k`). Assertions on generated code need the module's real names.
- Thread roles (helper versus attention worker) are re-decided every pass in tron. Classify threads from the spans of the drawn window, not from the whole trace.
- TraceProcessor (the Perfetto Python module) is available on claude-agentsrv only. Copy traces over NFS and analyse them here.
- A token alone in its 16-token block (every decode token) keeps the per-token scatter. A masked full-line store would write the same 4 bytes per line and gain nothing. So the remedies do not change the decode span.
- Striping the store over helpers is legal for K because tokens write disjoint bytes in this layout. V's pair-interleaved plane does not allow it.
- Pages are kept pure ASCII. Every regeneration asserts it.
- The user's decision on 2026-09-14 22:54 PT: a+b is the solution, drop the individual switches. The follow-up naming decision ("shared block save", "binary" instead of "arm") came on 2026-09-15.

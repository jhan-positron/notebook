## Short version

The session built the "VNNIed K in place" design on a new branch `jhan-amx-vnniK` on top of PR #3879, so that the K cache of 128-dim heads is stored in the AMX VNNI layout at generation and the AMX kernel reads it without a transpose. On delphi-3bda the branch passed all unit tests and, in a 60-run campaign after the CI window, gained +6.1% to +10.4% decode TPS at tp2 over the AMX baseline, but lost time to first token at short prompts (+7.8% at tp4, prompt 1024). Three deliverable pages were written and published: the design page, the Monday morning report (with answers to the user's three questions), and a one-glance comparison of AMX off, AMX compiled off, canonical, mirror and VNNI-K over all past campaigns.

## Gotchas & decisions

- The kill switch on the VNNI binary is not a rollback to the old numerics. It keeps the VNNI layout and runs the AVX-512 VNNI reader. A layout A/B needs two builds.
- runtron prints "Generating 253 response tokens" for `-l 256`. Any early-stop rule that tests `< 256` flags every run.
- Editing a campaign script while bash runs it shifts the read offset (bash reads the file incrementally from NFS). The launcher pattern here waits for the lease first, so the script can still be edited until then.
- Never `git worktree prune` from claude-agentsrv in the shared tron repo (worktrees on delphi-3bda local disk look missing). Recorded earlier in memory `worktree-prune-nfs-trap.md`.
- Edits made on claude-agentsrv and built on delphi-3bda can hit the NFS attribute-cache trap. Build from a commit, or verify the file content on the build host.
- Building with `TRON_AMX_DISPATCH=ON` and `TRON_K_VNNI=ON` is required. `TRON_K_VNNI` alone fails to configure.
- In the ingested qwen plugin, `save_k` runs on the forward pass's main thread once per layer and pass. The RX-worker placement holds only for the handwritten llama plugin. The first draft of the report said otherwise and was corrected.
- Column naming decision: "AMX compiled off" = a build without any AMX option (earlier campaign names: clean, pr1clean). "AMX off" = the AMX build with `TRON_AMX_DISABLE=1`. "canonical" = PR #3879 with AMX on (the Monday report calls it "base"). The two AVX columns differ by 0.6 to 0.7% with the same sign in all six September pairs, a property of the two builds, not noise.
- In the mirror-vs-VNNI-K page VNNI-K exists only in the 2026-09-14 rows, which had no mirror arm. There is no CI-harness measurement of VNNI-K.
- The Artifact tool needs an icon on the first publish of a new page. Re-publishing with `url` keeps the icon.
- HTML pages are kept pure ASCII to avoid the mojibake trap recorded in memory `artifact-utf8-mojibake-trap.md`.

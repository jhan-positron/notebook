- **Trial**: one measured unit of `bwx8`: prefix windows, an optional predecessor loop, then target windows. **Window**: one timed period, 300 ms in the size sweep. **Plan file**: the text file that tells one `bwx8` process its trials.
- **Step**: one batch of processes of the run script. `B6W` repeats an old sequence to check the new wrapper. `S2` is the size sweep (3 kernels at 32 KiB, 1, 4, 8 and 16 MiB). `S4` is sustained reads of 60 s at 8 MiB. `P3G` and `P3` are the paired-allocation branch and its gate. `S3G` and `S3` are the mixed-sequence gate and test. `BIN`, `CS`, `CM` and `C4` are the instrumentation and counter steps.

- **Repeatability rule**: the rule of the design for a difference. The spread of repeated equal measurements gives a limit. A difference is "repeatable" if its median is above the limit with one sign. It is "confirmed" only if both measurement sessions agree.
- **Matched set**: the processes of one repetition set, one per kernel, that are compared with one another. Each CPU has 6 sets per measurement session.
- **Two-spread limit**: the sum of two spreads of repeated equal measurements. A difference of two rates must be above it to count.
- **Wrapper**: the code around a loop that times it. The old runs used an interval wrapper, and `bwx8` adds a trial wrapper.
- **Listing check**: a comparison of the machine code of the built kernels with the accepted `bwx` build.
- **Gate, margin**: a gate is a check that must pass before a stage counts. The margin is the largest difference that a gate still calls "equal". "Precision insufficient" means the expected spread is above the highest margin allowed.
- **Disturbed mark**: a quality mark on a trial. The design sets it when the thread CPU time is below 99 % of the wall time, when an involuntary context switch occurs, or when the gap before the target is above 100 µs.
- **Low level, high level**: the two rates between which a load-only kernel switches at 8 MiB.
- **`DECISIONS-bwx8.md`**: the contract file of the implementation. It fixes the file formats and one reading for every place where the design can be read in two ways.

- **PMU**: the performance monitoring unit of a core, which holds the hardware counters.
- **Stand-in kernels**: on x86 the AArch64 loops are replaced by plain C loops. Rates from local tests mean nothing.

## Gotchas and decisions

- Stop herdr with its own command (`herdr server stop`, `herdr --session <name> server stop`) so the socket files are cleaned up. A `kill` by pid also works, and the next start binds over leftover socket files without error, as the 20:44 log showed.
- Do not `pkill` by name inside the container (the keepalive hazard note).
- Two servers can run side by side because the named session uses its own socket directory. Neither was a duplicate of the other; they were two sessions.
- A herdr server in the host pid namespace is invisible from the container even though the config directory is shared.

## Open items / next steps

1. If the goal is to see AMX in the nightly, the package build must set `-DTRON_AMX_DISPATCH=ON` (or the default must change). This session did not propose a change to the systems_test or tron repos.

## Gotchas & decisions

- "KV head size = 12" in the question was read as head size 128. The user did not object. The kernel constant is in amx_attn_iface.hpp line 137.
- The llama-family geometry is aggregate-initialized in the `TRON_LLAMA_CONFIG` macro. Field order is type, dim, hidden_dim, n_layers, n_heads, n_kv_heads, vocab_size, head_size, ... [tron-amx h/tron/plugins/llama.hpp:139-153]. Miscounting fields is the easy mistake here.
- gemma-4-31b has two attention geometries (sliding and global layers). Neither fits.
- The Slack-free, read-only probe on delphi-3bda used `strings` on the installed binaries. `TRON_AMX_DISABLE` survives stripping and is the reliable marker for an AMX-enabled build. `TRON_NO_RTM` served as the control to show the probe works.
- ssh as `positron@delphi-3bda.positron.internal` is refused (publickey). Use the `delphi-3bda` alias from ~/.ssh/config (user jhan).
- One workflow deriver made an arithmetic slip (64 / 8 written as 4). The skeptic plus critic layer caught it. Do not trust a single deriver's kv_mul without the division shown.

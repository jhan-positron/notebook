## Short version

The 2026-09-29 fix for issue 4500 still lost decode throughput on qwen3-4b against canonical AMX. A 25-agent code reading found the cause: at the end of every 16th decode step the main thread converted every completed K block to the VNNI layout, and under FPGA attention nothing ever reads those converted blocks. Commit 452b2052c9 skips that conversion for KV slots the FPGA scores, and a 4-repetition campaign on delphi-3bda shows qwen3-4b decode now within noise of canonical AMX while time to first token stays better.

- **VNNI K layout**: the pair-interleaved K cache layout of https://github.com/positron-ai/tron/pull/4424 (PR 4424), so the AMX kernel can read a page as one B operand.

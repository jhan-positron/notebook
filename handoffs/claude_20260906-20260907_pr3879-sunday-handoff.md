## Gotchas & decisions

- jhan's directives: half split of delphi-3bda; whole-machine work only when Bill has no process, stopped within about 30 seconds if he returns; no message to Bill, Ben or Jeremy; PR 1 only after an explicit go; PR 2 not opened until asked; no `Run CI` label, `Skip benchmarks` on every PR; plain English everywhere.
- `SYSTEM_CONFIG` overrides command-line placement: the login environment on delphi-3bda exports `SYSTEM_CONFIG="--instance 1,2"` into every detached process; runtron applies the command line first and then the environment again (`pos_startup_host` -> `system_parse_env`, no "already configured" check), so `--instance 1,2` replaces `--devices`, `--app-cores`, `--dev-cores` and `--numa`. The sharing document's sentence that a command-line `--instance` wins is wrong for placement. Every script that pins cards or cores must run tron under `env -u SYSTEM_CONFIG`. The 30 older campaign scripts that pin Bill's cards have the same exposure.
- `bin/slice bench --update` cannot measure on one half: it launches one run per NUMA node at every width and refuses a partial Dice grant. Cost data therefore needs the whole machine and a quiet host.

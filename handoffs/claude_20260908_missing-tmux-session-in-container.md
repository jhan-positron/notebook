## Gotchas & decisions

- The same symptom (empty tmux) has two different causes seen two days apart. Check the host first: `last -x reboot shutdown` on agentsrv. A `shutdown system down` plus `reboot system boot` pair means host reboot; a container kill leaves no wtmp entry and shows `died 143` in the podman events log.
- `journalctl --user -b -1` exists only after a reboot; "Stopped claude-dev container" followed by "Reached target Shutdown" means the user manager was torn down at host shutdown.
- After any reboot the container is up but empty because claude-dev.service restarts it; tmux and Claude sessions must be re-entered (`claude --resume <id>`).
- tmux-continuum saves only while attached, so the 06:51 save marks the last attachment, not the death time.

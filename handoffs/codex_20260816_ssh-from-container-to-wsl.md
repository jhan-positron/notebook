## Objective

Provide a safe SSH path from the `claude-box` container on server alpha back to
WSL on a NATed laptop.

## Current state

The recommended design is a reverse SSH tunnel initiated by WSL and bound only
to alpha's Docker bridge, for example port 22022. The container then connects
to the host-gateway address on that port. Binding to `0.0.0.0` was rejected
because it could expose the laptop SSH service publicly.

## Open items / next steps

- Confirm the actual Docker bridge or container host-gateway address.
- Enable `AllowTcpForwarding yes` and `GatewayPorts clientspecified` on alpha's
  SSH server before starting the reverse tunnel.
- Consider Tailscale for a longer-lived connection.

## Gotchas & decisions

The tunnel must originate from WSL because the laptop is probably behind NAT.

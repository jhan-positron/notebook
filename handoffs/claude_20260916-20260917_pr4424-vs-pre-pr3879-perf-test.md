- **TPS**: decode tokens per second per user, runtron's "average tok/s" averaged over the users of one run. **TTFT**: time to first token in seconds, runtron's "Parsing the prompt took S s", maximum over the users.
- **paired t**: for each repetition present in both arms, the difference target minus base. The tables report the mean, the sample standard deviation (sd), the count n and t = mean / (sd / sqrt(n)). **resolved**: |t| of 2 or more and a change of the mean of at least 1%. With n of 2 or 3 this is a coarse rule, not a significance test.

- **smoke**: a one-user greedy run of 128 tokens per model per arm, used to compare generated tokens between arms.

## Gotchas & decisions

The five scalar leaves are `page_visits`, `relevant_query_tokens`, `shared_visits`, `shared_tokens`, and `pending_visits`, under the virtual FUSE path `<mountpoint>/rinzler/stats/page_share/` in each inference process. `histogram` holds seven JSON slots: 1, 2, 3, 4, 5–8, 9–16, and more than 16 relevant query tokens. They are casual leaves, not exported Prometheus metrics; there is no reset file. Independent relaxed atomic reads do not form a consistent multi-counter snapshot while workers flush. These values measure sharing opportunities, not realized memory-load savings.

The retained exit summary is necessary for batch runs because the FUSE tree unmounts before static destructors report final totals. The runtime setting is cached: change it by launching a fresh process. The focused FUSE constructor rejects root; the successful historical command was `unshare --user --map-user=1000 --map-group=1000 /tmp/page-share-validation/t_page_share_counters` on `claude-agentsrv`.

## Words used here

- **tron, runtron**: Positron's inference program (GitHub repository positron-ai/tron) and its command-line tool.
- **Qwen3.5 4B**: the model under study. 24 of its 32 layers are GDN layers, and 8 are attention layers. It is registered only on the branch of PR 3696, not on main.
- **GDN (GatedDeltaNet)**: a recurrent layer type. A GDN layer has 16 key heads and 32 value heads. Its state is one matrix of 128 by 128 FP32 values per value head.
- **AMX, AVX-512**: Intel's tile-matrix instructions and Intel's 512-bit vector instructions. **bf16, FP32**: 16-bit and 32-bit float formats. A **bf16 step** is the distance between two neighbouring bf16 values.
- **Part 0, Part A, Part B**: the three changes of the design. Part 0 is a faster GDN loop without AMX (the **chain kernel**), with equal bits. Part A is an AMX kernel for GDN that takes 32 prompt tokens per call (the **block kernel**). It is built on Part 0. Part B is a set of AMX attention kernels for heads of 256 values with 4 query heads per KV head. The **token kernel** is the GDN code of the base build.
- **Counters**: the new GDN statistics. `TRON_GDN_STATS=1` turns them on. The older attention statistics use `TRON_ATTN_STATS=1`.
- **Kill switch, GDN switch**: `TRON_AMX_DISABLE=1` turns every AMX kernel off. The new `TRON_AMX_GDN_DISABLE=1` turns only the block kernel off.
- **TTFT**: time to first token. **Prefill**: the processing of the prompt. **Decode**: the generation of tokens after the prompt, in tokens per second (tok/s) per user. **Pass**: one forward computation through all 32 layers. **GDN step**: the work of one token for one key head.
- **Cell**: one combination of user count (1 or 8) and prompt length (1,024, 4,096 or 8,192 tokens). **Arm**: one build with one set of switches.
- **Arm names**: base (the build with the counters only), p0 (the build with all changes and the kill switch set, so only Part 0 runs), b (the same build with the GDN switch set: Parts 0 and B), ab (the same build with no switch: all three changes), a0 (the build without Part B, GDN switch set), a (the build without Part B: Part A), orig (the build of 2026-11-20), nost (the base build with the GDN counters off).
- **Session 1, session 2, control runs**: the three groups of campaign runs. Their repetition numbers are 1 to 2, 11 to 13 and 21 to 23.
- **Busy time, join wait, K token, page unit**: the busy time is the time a thread spends inside its attention work. The join wait is the part of it in which a thread waits for the other threads. A K token is one stored key row that a query is scored against. A page unit is the attention work of one query token on one 64-token page of one KV head.
- **Wall, core clock, scores**: a wall is the elapsed time of a piece of work, waits included. The core clock is the frequency at which a CPU core runs. The scores are the values that the model gives to every token id for the next token.
- **Head shape, query head, KV head**: an attention layer of Qwen3.5 4B has 16 query heads and 4 KV heads of 256 values. The head shape is the head size and the number of query heads per KV head.
- **Subnormal value, FTZ, DAZ**: a subnormal value is a nonzero float below the smallest normal value. A CPU computes with such values slowly. FTZ and DAZ are two CPU control bits that turn such values into zero.
- **TVD**: total variation distance between two next-token distributions. 0 means identical.
- **Design page, results page**: gdn-amx-design.html and gdn-amx-results.html in /home/jhan/workspace/intel-AMX/GDN.

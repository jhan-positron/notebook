- **AP, system DRAM**: the application processor (the Arm cores that boot Linux) and its memory.
- **Lane, Goldcrest pair**: one memory interface of the emulator's memory model, and a group of 2 lanes. **DP lanes**: pairs 0 to 15, the 32 datapath lanes. **AUX lanes**: pairs 16 and 17 (lanes 32 to 35). They hold the system DRAM.
- **Timing profile**: 61 lane-clock cycles of read latency, 40 cycles of write response latency and a bandwidth limit of 38.4 GB/s per lane.
- **Gate**: the expression `.DATAPATH_TIMING (GC_PAIR_INDEX >= 0 && GC_PAIR_INDEX < N)` in the lane wrapper. The PR changes N from 16 to 18, which gives the AUX lanes the profile.
- **cfclk**: one cycle of the 2 GHz emulation base clock (0.5 ns). **AXI cycle**: one cycle of the 1 GHz lane clock, which is 2 cfclks.
- **Run window**: the `--run-cycles` value of a run, in cfclks. **Helper**: the bash function `asimov_os_linux_boot_cycles` in emu/common/scripts/asimov_os_env.sh. It returns the default window of a Linux boot: 1.0G cfclks for a release SCP at version 0.51.0 or later, 1.6G otherwise.
- **SCP**: the system control processor firmware that releases the AP. **asimov-os snapshot**: the versioned set of firmware and Linux images that the launcher boots.
- **Launcher**: emu/hemi_tlm/scripts/run_emu.sh. **LINUX verdict**: its summary line that says whether the console reached `Run /sbin/... as init process`. The launcher exits with status 1 when the verdict is not "booted".

- **HEMI_GC_AUX_TIMING**: the build define of the session's patch. **Timed image**: an emulator image built with it. **MANIFEST**: the file in the build directory that records the compiled defines.

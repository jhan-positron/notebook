## Gotchas & decisions

- A clean rebase can still fail to compile. Main can add a caller of a function the PR changed, in a different file, with no textual conflict. Build after every rebase, or at least check main's new callers of every function whose signature the PR changes. Recorded in memory `git-rebase-traps.md`.
- `git rebase` strips commit-message lines that start with `#`. Use `git -c commit.cleanup=whitespace rebase ...` to keep them.
- GitHub's up-to-date rule re-blocks the PR after every merge into main, even with a merge queue. Enqueueing the PR is the way out: the queue builds main plus the PR itself. A queued PR's branch rejects pushes ("protected branch hook declined"). Do not push while a PR is queued.
- Decision: the compile fix passes `nullptr` at the call site rather than restoring the default argument, so the "drop a default argument" review commit stays intact. The fix is folded into that commit so every commit in the series builds.
- Decision: no delphi-3bda rebuild for the second rebase, because main's new files were outside the PR and outside every header the PR includes. The third rebase touched shared build files, so a build was started.
- The GCP Nix "Build model traces" failure and the "Debian smoke" certificate failure on 2026-09-15 were runner and infrastructure problems that hit every branch that day.
- Background `sleep` hold loops get killed by the harness with a "low on memory" notice that does not reflect the box's memory. A Monitor re-armed every 30 minutes works.
- The build script waits up to six times 20 s for the tip commit to become visible on delphi-3bda (NFS attribute cache).

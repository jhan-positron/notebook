## Gotchas & decisions

- `-u N` in runtron appends N Moby Dick prompts; it is not a user count.
- `exec/results/slot1/t1-quick.txt` "OFF vs OFF DIFFER" is a false positive
  from line-based filtering; the ANSI token-chunk extraction is authoritative.
- After the first flip in a free-running A/B, later tokens carry no
  information; only the first flip position and its logit margin matter —
  hence replay via `--force-feed-text-token-file`.
- `ctest --output-on-failure` hides Catch2 skip warnings from passing tests;
  run kernel-test binaries directly and gate on the assertion count.
- The pre-existing tron-amx mirror binary was built with
  BUILD_INGEST_MODELS=OFF and cannot load ingested qwen; same-source builds
  were required.
- bf16-quantized logits make exact top-1 ties common (2 in the first 64
  steps); comparing free-running words across arms is not a correctness test.
- Debug-only code goes on jhan-dd-debug in ~/workspace/tron-dd (memory
  debug-code-new-branch.md); jhan-amx-p0 stays untouched.
- The classifier blocked a direct `systemctl stop rinzler` from the
  container; the campaign script applies the standing idle policy itself.

- Ran a 7-dimension multi-agent audit (20 agents, ~2.4M tokens) over
  local tree tron-29924aa8 with adversarial re-verification; wrote
  from-claude/tron-MoE-random.html. Verdict:
  - No live RNG on the benchmark decode path — every PRNG frozen by
    `-s`, dead under flags, or never drawn (greedy `--threshold_p 0`
    short-circuits to argmax). `-s` is parsed as float: seed
    2954953865 silently becomes 2954953984 (constant, harmless).
    Prompts are 8 fixed Moby-Dick files trimmed to 1000 tokens.
  - Engine documents its own nondeterminism (runtron.cpp:723-726):
    host attention autotuner (rdtsc-fed "speedometer") re-partitions
    attention pages per pass -> non-associative float reduction
    regrouped -> logit bits wiggle; `--pay-for-determinism` defaults
    off. Second channel: top-320 wcls candidates accumulated in
    DMA-arrival order, no index tie-break.
  - MoE converts noise to throughput: step cost tracks the number of
    distinct active experts (~12.4 MB HBM->W-mem per active expert
    per layer, 36 layers gate on slowest card); a ~2-expert
    launch-mean shift covers the whole 7%; analytic model reproduces
    F1's measured ~550 MB/token/card. Dense work is token-blind.
  - Launch-persistence candidates: device->core pin race
    (driver.cpp:798-802), tbb::parallel_for DMA line alloc, NUMA
    hugepage slice-file history (membind no-op under
    SYSTEM_NUMA_ALL). Traps: `--forced-routing` silent no-op for
    gpt-oss plugin, TRON_RANDOMIZE_EXPERTS unreachable for it. Gift:
    expert_stats FUSE histogram (resolution ~0.003 experts vs ~2.0
    needed). 11 incidental defects incl. ~1,100 malloc/free per step
    from reserve(0).

## Gotchas & decisions

- Remote .bashrc on delphi hosts echoes into stdout and corrupts
  scp/pipe streams — build a tarball remotely and scp it instead.
- `runtron -s` seed is parsed as float: 2954953865 silently becomes
  2954953984 (constant per run, so harmless for reproducibility
  claims, but surprising).
- `--forced-routing` is a silent no-op for the generated gpt-oss
  plugin; TRON_RANDOMIZE_EXPERTS is unreachable for it — neither
  works as a discriminator. The env var is presence-tested: setting
  it to "0" still enables it; kits must unset it.
- CI's bin/ci/benchmark_lib.py runs `--threshold_p 1` with no seed
  (fully stochastic) — CI/nightly variance and fixed-seed
  checkerboard numbers come from different sampling regimes; never
  compare without checking which harness produced each number.
- DUT idle-guard false positives: any process whose cmdline matches
  the kit pattern (stale `tail -F .../chain.log` watchers, stray
  `rg`) blocks kit launches with no retry — pre-flight the DUT for
  stray processes.
- Two-tier frequency-policy signature survives a boot with
  intel-speed-select-state masked; the unit must be disabled outright
  (wants-symlink removed) — "policy outlives its off-switch" family.
- rho(mem-stall, gen) is dead as a lottery marker — flips sign across
  tp geometry within gpt-oss (-0.747 tp4 -> +0.708 tp2).
- membind is a no-op under default SYSTEM_NUMA_ALL; reused hugepage
  slice files carry the first-faulter's NUMA placement.
- The permission classifier blocks killing another session's
  processes on the lab hosts — plan for human or owning-session
  action.
- Browser-pane snapshots can be stale (0-width viewport) — verify
  HTML edits on disk instead.
- ab60g's ROLLS verdict rests on direction, not the bare threshold:
  bootstrap CI [1.695, 3.205] straddles the 2.5% bar — quote it with
  the caveat.

- **AMX**: Intel tile-matrix instructions. The AMX kernel scores dense 64-token KV pages. **AVX**: the software loop that scores every other page.
- **kv_mul**: query heads per KV head. llama-3.1-8b and qwen3-4b have 4, Muse Glimmer 30B has 16, gpt-oss-120b has 8 at head size 64 (never AMX). **Shape 128x16**: head size 128 with kv_mul 16, the shape PR 5015 adds.
- **Muse Glimmer 30B** (Glimmer): 32 query heads, 2 KV heads, head size 128, 39 sliding-window layers on the CPU and 13 full layers on the FPGA. **Permuted twin**: the same weights in a permuted layout.
- **base / head / headoff / head2**: base = runtron built from the merge base (without PR 5015). head = runtron built from the PR head (with PR 5015). headoff = head with the kill switch `TRON_AMX_DISABLE=1`. head2 = head run a second time.
- **FPGA attention** (the user's "hw attn"): the model default, attention scored on the FPGA cards. **CPU attention**: `USE_HW_ATTN=0`.
- **AMX share**: K tokens scored by the AMX kernel over all K tokens, from the `TRON_ATTN_STATS=1` exit report of a run.
- **TPS**: decode tokens per second per user. **prefill s**: the time to parse the prompt, slowest user. **band**: twice the larger of the two arms' sample standard deviations. **paired delta**: head minus base per repetition. **t**: the t statistic over the paired deltas. **holds**: TPS delta at or above minus the band and prefill delta at or below plus the band. **gain**: TPS delta above plus the band.
- **identity smoke**: one user, temperature 0, `--pay-for-determinism`, seed 1, 256 generated tokens, token ids compared pairwise.
- **teacher-forced run**: a run fed a fixed token sequence, with every step's logits recorded. **margin**: top-1 logit minus top-2 logit. **bf16 ulp**: one unit in the last place of a bf16 number. **TVD**: total variation distance between the two arms' softmax at a step. **flip**: a step where the two arms disagree on the argmax.

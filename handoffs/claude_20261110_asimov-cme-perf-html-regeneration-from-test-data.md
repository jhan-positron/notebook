## Words used here

- **Asimov**: Positron's chip. It runs on an emulator (a Palladium machine) that Jesse Zhang operates. The pages call Jesse "the operator".
- **C1-Nano, cluster**: the Arm core of the chip, and a group of two cores that share an L2 cache, an L3 cache and one CME.
- **CME**: Compute Matrix Engine, the Arm C1-SME2 unit. It has its own L1 cache of 64 KiB. The tests drive the CME of the cluster of CPU 2.
- **Boot**: one power-on of the emulated chip with one firmware set. **Boot F1**: results/membench-jibin-011 (L3 on, hardware prefetchers on, core rows and CME rows). **Boot F2**: results/membench-jibin-012 (L3 on, prefetchers off, CME rows only). Both ran benchmark commit 0c190a1. **Boot E**: results/membench-jibin-010, an earlier boot.
- **Prefetcher**: hardware logic that loads data into a cache before the program asks for it.
- **Latency test, chain load**: the test walks a list of pointers, one per 64-byte line. Each load reads the address of the next load. A chain load through the CME is one LD1D instruction plus one LASTB instruction, which moves the value back to a core register.
- **Round-trip baseline**: the same loop with a register copy (DUP) in place of the load. It has no memory access. It reads 21.005 ns in all 24 CME latency files.
- **Bandwidth test, kernel**: the test reads, writes or copies a whole buffer in address order. A kernel is one test loop in cme_kern.S. It is not the Linux kernel.
- **Bracket time, span time**: the time between two clock reads in C around a kernel call, and the time between two counter reads inside the kernel (after the CME is switched on, before it is switched off).
- **Looped form, single-call form**: one kernel call per pass over the buffer, or all passes of one timed measurement in one call.
- **Rep, pass, best row**: one timed measurement, one walk over the buffer or chain, and the row that the test program itself marks as best.
- **Refill**: the arrival of one 64-byte line in the L1 cache of the CME. **Inner** refills come from inside the cluster, **outer** refills from outside it.
- **SLC, OCM, home node, mesh**: the system-level cache shared by all cores, the on-chip memory (five regions of 256 KiB), the mesh device that holds a slice of both, and the on-chip network.
- **DRAM model**: the emulator's memory behind the mesh. It is a model with no configured delay, not silicon timing.
- **The old generator**: gen_perf.py with gen_perf_cme.py, gen_perf_core.py and gen_brief.py. Until this session it wrote the four pages asimov-cme-perf.html, asimov-c1nano-perf.html and their two briefs.
- **The new generator**: gen_cme_perf.py with the package cme_page/. **Data layer**: cme_page/data.py, which parses the result files once. **Self-test**: `python3 -m cme_page.data`, 190 checks. **Lint**: the check in cme_page/shell.py that stops a build on a forbidden word, a broken link or a duplicate id.

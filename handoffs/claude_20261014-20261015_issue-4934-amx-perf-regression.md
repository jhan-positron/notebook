Reading: the fix executes fewer instructions per step than PR 4898 but spends more cycles inside the attention function, spread over all workers, with equal spin-wait shares. So the residual is a lower IPC of the attention itself, not a serial section and not a new hot spot.

The instruction-level annotation found one new hot instruction in the fix: the per-page read of `page::k_vnni_blocks_` (a `movzbl`), 1.26 % of apply_page_range samples at prompt 8192 and 0.52 % at prompt 1024. Commit 7 moves it into the first cache line next to `lo` and `offset_bound`.

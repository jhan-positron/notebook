## Words used here

- **CRB**: the Arm Phoenix Reference Server. It has 128 CPUs. Its address is 192.168.2.45 and its Linux hostname is `ubuntu`. It is a shared machine, and only CPUs 0 to 119 may be used.
- **Mesh 0, mesh 1**: the two halves of the chip. CPUs 0 to 63 sit on mesh 0, CPUs 64 to 127 on mesh 1.
- **Whole chip, 120 threads**: 64 threads on mesh 0 plus 56 threads on mesh 1. Each thread reads its own 256 MiB buffer from memory.
- **MT/s**: million transfers per second, the unit of memory speed. CRB ran at 8000 MT/s until 19:43 UTC on 2026-11-17 and at 7200 MT/s after that.
- **Read kernel**: the inner loop of the benchmark that reads memory. It is not the Linux kernel.
- **Old read kernel**: portable C with 16 running sums. Each load is followed by an add. Its name is `read` in the binary bw_old and `oldread` in the runner bwx12.
- **New read kernel**: loads only (Arm vector intrinsics). Its name is `read` in the binary bw_new and `read` in bwx12.
- **asmread, load-only loop**: asmread is a hand-written loop with the same 8 loads per 256 B as the new read kernel. "Load-only loop" means the new read kernel or asmread.
- **bandwidth.c, bw_old, bw_new**: the benchmark and its two binaries of 2026-11-13. bw_old was built from the old source, bw_new from the new source.
- **bwx12**: the runner program of the 2026-11-15 investigation. **rx.sh**: the script that starts one bwx12 process per line of a spec file.
- **Whole-pass stop, common stop**: two stop rules. With the whole-pass stop of bandwidth.c each thread finishes the buffer pass it is in. With a common stop all threads stop at the same time.
- **Process, interval, round, session**: a process is one start of a benchmark binary. An interval is one timed measurement inside a process. bwx12 repeats its kernel sequence, and each repeat is a round. A session is one pass of go.sh through parts A, L and C.
- **Part A**: the 120-thread part of the 2026-11-13 test, repeated with the same two binaries (whole-pass stop, 0.5 s).
- **Part L**: one bwx12 process with the sequence oldread, asmread, read_nop96, read_nop256, read_1pl (common stop, 6 s). The last three are test loops with padding or with one load per line.
- **Part C**: one bwx12 process with the sequence oldread, read, asmread (file cfwd.spec) or asmread, read, oldread (file crev.spec).
- **Control I**: the part L line, started twice from an idle machine. The session added it after it had seen the first numbers. It is not part of the plan fixed before the run.
- **F72d12**: one earlier process of the part L line in the same boot, run at 20:02 UTC by the session of the handoff `claude_20261115-20261117_whole-chip-throughput-drop-with-new-test-kernel.md`. It is not part of the rerun.
- **Rows A-1 to A-3, L-1 to L-4**: the 8000 MT/s baseline runs with 12 modules. The list was fixed before the run.
- **Boot id**: a random identifier that Linux creates at each start. Equal boot ids mean the same boot.
- **MemTotal**: the usable memory that Linux reports. 395392808 kB means 12 modules.
- **Load average**: the mean number of running or waiting tasks over 1 minute, as Linux reports it.
- **RUNNING marker**: the file /tmp/positron-perf.RUNNING on CRB. Another user creates it during timed runs. The scripts of this session stop when it exists.
- **FACTS.md, facts.json**: the facts sheet of this rerun and its data file. A script writes both.
- **Workflow**: the multi-agent tool of Claude Code. **Ultracode**: the `/effort ultracode` mode, which runs a workflow for every substantive task. This session ran four workflows, called W1 to W4 here.

## Words used here

- **tron**: Positron's inference program (GitHub repo positron-ai/tron). **runtron**: its command-line tool, used for the A/B cells. **rinzler**: the production server. **platformd**: the production process manager that brings serving down and up (version 0.11 on 3bda).
- **AMX**: Intel tile-matrix instructions. **AVX**: the software loop that scores every page the AMX kernel does not take. **FPGA** or **the card**: the attention accelerator. **AoF**: attention on the FPGA.
- **Muse Glimmer 30B**: the ingested model `ingested-meta-models--Muse-Glimmer-30B` (runtron names `-tp2` and `-tp4`). 32 query heads, 2 KV heads, head size 128. 52 layers: 39 sliding-window layers (window 2048 tokens) that always run on the CPU, and 13 full layers (3, 7, 11, ..., 51) that go to the FPGA by default.
- **kv_mul**: query heads per KV head. Glimmer has kv_mul 16. llama-3.1-8b has kv_mul 4. **group_heads**: the new kernel template parameter, 4 or 16.
- **The kernels**: namespace `amx_attn_h128g4`, functions `pack_q_group_128x4`, `qk_rowmajor_128x4` and `weights_times_v_128x4` in h/tron/kernels/amx_attn_iface.hpp and src/tron/kernels/amx_attn.cpp. The names say "group of 4" and were kept on the user's decision.
- **Kill switches** (environment variables, same binary): `TRON_AMX_DISABLE=1` (AMX off), `TRON_AMX_PREFETCH_DISABLE=1` (prefetch off), `TRON_PLAN_WEIGHTED_DISABLE=1` (old planner).
- **Attention path stats**: `TRON_ATTN_STATS=1`. runtron prints an exit report with per-layer counts of K tokens (key tokens scored) by path. Software paths count once per KV head and the FPGA counts once per query pass, so the FPGA count is multiplied by 2 KV heads before shares are taken.
- **Cell**: one measurement configuration, named like `glm-tp2-8u-p1024-fpga` (model, tensor-parallel width over 2 or 4 cards, 8 users, prompt length, attention mode `fpga` = card on the 13 full layers or `cpu` = `USE_HW_ATTN=0`). **Arm**: `amxon` or `amxoff` (the generic names of the two arms in every campaign). **rep**: repetition.
- **band**: 2 times the larger sample standard deviation over repetitions. A delta beyond its band is treated as real.
- **TPS**: decode tokens per second per user. **TTFT**: time to first token. **prefill**: the prompt parse. **prefill proxy**: 1024 tokens divided by TTFT.
- **delphi-3bda**: the shared Xeon 6 test server. **our half**: socket 1, cpus 72-143 and 216-287, cards 90/93/b9/bc. **the nightly**: the systems_test CI run on 3bda at about 03:38 UTC. **the lease**: /run/lock/systems-test-ci.lease. **Bill's marker**: /bill-has-instance-0,2.

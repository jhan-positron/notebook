## Gotchas & decisions

- **Do not trust report 05** ("machine epoch") — retracted in reports 11–12. The July "tight" measurements used a different workload shape (u8 / gen-1024 / 2 cards); comparing across shapes manufactured the false "machine changed" story.
- **Harness geometry, not model TP:** `--slice-of` (run-benchmark) sets cards given to the process; the model's TP is a build-time variant baked into the model name. Cards > TP group → the engine spreads tensors across card pairs (the fluctuation trigger). There is no "runtime TP"; a tp4 variant cannot run on 2 cards. Production rinzler already runs exact fit; only benchmarks spread.
- **`-u N` changes the prompt text** (shared system prompt = Moby Dick chapter `(n_users+1) mod N`, runtron.cpp:795) — token streams are never comparable across different user counts.
- **`USE_HW_ATTN` must be set explicitly to 0**: on trunk, unset lets per-model defaults enable hardware attention (qwen3-4b 36/36, gpt-oss-20b 12/24). All session harnesses force + verify it; any new harness must too.
- **Token determinism ≠ perf stability:** `-u 1 --pay-for-determinism` gives bit-identical tokens (3/3 hashes) but does not reduce CV (3.15% pinned vs 2.31% control). Same applies to `TRON_MIN/MAX_MAIN_HELPERS`.
- **Nightly soak trap:** the serving trio coming up at ~08:11 UTC is the soak *starting*, not the nightly finishing; the soak's request driver is remote and invisible to local process checks. Keep-off 02:30–11:30 UTC + the harnesses' 60 s traffic gate. This session crashed one soak (report 10, incident acknowledged to Rhys).
- **Capture overhead is large:** the 5cat Perfetto stack costs llama-8b ~27% mean throughput — never compare captured and bare numbers.
- **CV verdicts need shape-matched baselines**; single-session effects need hours-apart replication (ledger rule; it has caught several false positives).
- **3bda kernel state is one-shot:** 6.8.0-124 until its next reboot, then auto-returns to 6.8.0-136. `uname -r` before interpreting any new measurement.
- Avoid embedding `sleep`+launch chains inside single ssh commands — caused two timeout-orphan launcher races on 2026-08-10.
- The traffic gate must sample the pre-mutation state and exclude the host's own IPs (both false-trigger modes were hit and fixed; gate v3 is deployed).
- 3c51 differences to carry into any cross-host comparison: BIOS one rev newer, tron package ~3 weeks older (`distributed-dice`), idle DRAM latency 181 vs 127 ns.

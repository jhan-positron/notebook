## Gotchas & decisions

- A TLB miss does not imply a page fault; a hardware page walk can find a valid
  mapping and continue without entering the OS.
- A page fault does not imply a swap read. Demand-zero and copy-on-write are
  common minor-fault cases.
- `Virtually indexed` does not mean `virtually tagged`; VIPT uses a virtual set
  index with a physical tag.
- The answer did not edit the original diagrams; it documented their correct
  interpretation and a corrected sequence on the child page.

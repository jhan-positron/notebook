## Gotchas & decisions

- The classifier refuses Claude edits to campaign scripts ("Interfere With Workloads") and any file creation on delphi-3bda ("Modify Shared Resources"). It allows edits to the library. The working pattern: write a patch file, dry-run it, and give the user a one-line `! ...` command. Recorded in the memory notes.
- Never edit a campaign script while a campaign runs it. bash re-reads a running script by byte offset. Check every `exec/logs/*.status` says finished first.
- `git worktree` and `gh` are not involved here. exec/ is plain NFS with no git history, so the `.bak-<date>` copies are the only rollback.
- Decision: takeover keys on the lease file plus journal idleness, not on the clock. Clock windows (hold, blackout) only refuse, never trigger.
- Decision: the takeover refuses inside a blackout window even though the pre-patch code did not check it. lib-guard.sh's own contract says a blackout means the machine is contended.
- Idle rinzler units log stats at growing intervals. An empty 10 min journal window is therefore not proof of idleness by itself. The function accepts it only when the last journal line is an idle stats line, which avoids waits of up to 40 min.
- Lease heartbeat gaps of up to 322 s were measured on 2026-08-21, so a lease that expired less than 600 s ago still counts as busy.
- `bill-share.sh take` is never run on Claude's own initiative. Only the user decides to take the whole machine.
- A Bash heredoc that rewrites a memory note can trip the classifier's "Instruction Poisoning" rule. Use the Edit tool for memory files.
- The Monitor tool expires after 30 min. Re-arm it for long outages.

- **T1 to T5**: the PR's timers in TSC cycles (the CPU cycle counter). T1 = wall time of one forward, T2 = busy time of one attention job, T3 = job wall time, T4 = layer period, T5 = join wait time (leaf key `join_wait_cycles`).
- **Forward**: one pass of the model over the current batch. **Forward class**: `decode_like` (every token job has a listener) or `prompt_or_mixed`. **Token job**: one token of one user in one forward. **Listener**: the consumer the scheduler registers for a token job's output.
- **Join**: the step where an attention worker waits for the other workers' partial results. The hardware join (`stream_hw_joins`) runs when the FPGA is used. The software join is the polling loop in `run_joins` under `USE_HW_ATTN=0` (attention on the CPU).
- **Pool worker / attention worker / split**: one pool of worker threads per model. The attention workers of a forward are the last `n_attn_workers` pool workers. The split is that number.
- **forward_scope**: the new owner object of the per-forward record (W2 fix). **listener_jobs / kv_only_jobs**: the two new per-class counters (W3 fix).
- **FUSE leaves**: the stats files that runtron and rinzler expose under `stats/.../attention/`. **Exit report**: the stderr summary printed at the end of a runtron run.
- **Fake device**: the unit-test build that needs no FPGA. **lcheck**: a syntax-only compile check script in /home/jhan/workspace/ai-runs/lcheck/ for the `gen` and `gen-amxoff` configurations.
- **delphi-3bda** (3bda): the shared CI machine. "Our half" is the user's share of it. The **nightly** is the CI run that holds the machine lease until about 13:20 UTC. **DUT**: the device under test.

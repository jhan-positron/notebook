## Words used here

- **CME**: Compute Matrix Engine, the Arm C1-SME2 unit. One CME serves one cluster of two cores.
- **The brief**: asimov-cme-perf-brief.html, the short form of the full page asimov-cme-perf.html. Section 1 holds a latency chart, section 2 a bandwidth chart.
- **gen_brief.py**: the script that writes the two briefs (function `cme_brief()` for this page, `core_brief()` for asimov-c1nano-perf-brief.html). It imports **gen_perf.py**, the data layer of the four older report pages. The chart code (`line_chart`, `legend`) is in gen_run3.py.
- **Boot**: one power-on of the emulated chip with one firmware set. **Boot E**: results/membench-jibin-010 (L3 cache on, prefetchers on). **Boot B**: results/membench-jibin-006 (prefetchers off). **Boot F1 and boot F2 (run 6)**: results/membench-jibin-011 (prefetchers on) and -012 (prefetchers off), both with the L3 on. **Run 3**: results/membench-jibin-004 (L3 off).
- **Prefetcher**: hardware logic that loads data into a cache before the program asks for it.
- **Chain load, latency test**: the latency test walks a list of pointers, one per 64-byte line. Each load reads the address of the next load. The reported number is ns per load.
- **Round-trip baseline**: the same loop with a register move in place of the load. It is 21.0 ns (42 CME cycles) and is drawn as a horizontal line in the section 1 chart.
- **By the bracket**: timed by the two clock reads around a kernel call.
- **Legend swatch**: the small colored mark in front of a legend entry.
- **cairosvg**: a program that renders an SVG chart to a PNG image. The session used it in place of a browser.
- **Ultracode**: the `/effort ultracode` mode of Claude Code, which runs a multi-agent workflow for every substantive task.

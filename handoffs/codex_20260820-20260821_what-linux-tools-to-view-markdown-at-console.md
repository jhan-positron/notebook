## Gotchas & decisions

- `pipx3` is not the executable name; use `pipx`.
- Running as root does not make broken `sudo` usable inside this container.
- `rich --markdown file.md` and `rich file.md` are equivalent for an `.md`
  file; neither enables pipe-table support.
- `column -s, -t` is not a real CSV parser and is unsafe for quoted commas or
  multiline cells.

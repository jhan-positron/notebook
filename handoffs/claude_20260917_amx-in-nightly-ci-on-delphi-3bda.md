## Gotchas & decisions

- The nightly's .deb never had AMX because the `deb` preset in `CMakePresets.json` does not set `TRON_AMX_DISPATCH`. The fix is one line after `"ENABLE_FUSE_STATS": "ON"` in that preset.
- Two checks are decisive for a shipped (stripped) binary. `strings /opt/positron/bin/rinzler | grep -c -x TRON_AMX_DISABLE` prints 1 with AMX and 0 without. `objdump -d --no-show-raw-insn /opt/positron/bin/rinzler | grep -c -E '(tdpbf16ps|tileloadd|tilestored|ldtilecfg|tilerelease)'` prints 86 with AMX and 0 without (about half a minute on the 232 MB binary). `nm` gives 0 on a stripped binary and proves nothing.
- Binary size is not a measure of AMX code. Our rinzler and the nightly's came from different main commits (10 merges apart).
- The EXE.AMX_BUSY counter must be read per process (`perf stat -p <pid>`), needs sudo, and was validated before use. The perf CSV column order is count, unit, event, run-time-ns, percent. Do not read the run-time column as the count.
- The arch_prctl call proves the probe passed, not that AMX kernels ran. The busy counter is the direct proof.
- The AMX gate does not check whether FPGA attention is on. Positions 0 to 126 of each request are scored on the CPU and take the AMX path when the kill switch is unset.
- The build needs `PATH=/tools/uv/0.9.5:$HOME/.ghcup/bin:$PATH` and `env -u SYSTEM_CONFIG`. The login PATH put `~/.local/bin` first and make picked uv 0.11.21 anyway. The package built and passed its contents test, so this was recorded, not fixed.
- Our package version `2026.09.17-6f37cd2e-jhan-amx-deb-preset` sorts above the nightly `2026.09.17-31b80a18` (apt treats it as an upgrade) but below any `2026.09.18-*` (apt then needs `--allow-downgrades`).
- The package's postinst only reloads systemd unit files. It does not restart running engines.
- The systems_test harness cannot set a per-engine environment variable. Explicit platformd provisioning sends only the model shape. The global file /opt/positron/user/config.env would switch every engine.
- Decision: do not install on delphi-3bda (shared, production `rinzler@1` on Bill's half). Decision: do not push the branch without the user's word.
- Monitor tasks time out after 30 minutes. `tail -f` followers left on delphi-3bda had to be killed by hand.

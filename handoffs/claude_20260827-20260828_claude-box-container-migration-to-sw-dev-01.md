## Objective

Copy the user's development container so it runs on more machines. claude-box
is the user's shell script (~/bin/claude-box, source kept in
~/claude-container/) that starts/enters a rootless podman container named
claude-dev (podman = a Docker-compatible container runtime). The container
originally ran only on machine alpha (a Positron development VM). Requirement:
`claude-box` must keep working unchanged as the entry command, and the tools
installed inside the container on alpha must carry over.

## Environment

- The Claude session ran directly on host agentsrv (hostname check at session
  start; NOT inside the container). /home/jhan and /scratch are NFS-shared
  across alpha, sw-dev-01, and agentsrv; container storage and
  /var/tmp/jhan/persist are per-host local disk.
- Remote work over ssh: alpha (source host, podman 3.4.4), sw-dev-01 (target
  1, podman 5.x), agentsrv (target 2, no podman initially).

## Timeline

  debug message, so `sandbox = true` in /etc/nix/nix.conf is not in effect.
- Installed the changes (details in Gotchas), started the container on
  sw-dev-01 via `claude-box start`, and verified against alpha (table below).

## Gotchas & decisions

- `podman diff claude-dev` on alpha (podman 3.4.4) resolves the name to the
  IMAGE and reports almost nothing; `podman container diff` shows the real
  writable layer. This nearly caused the 68 apt packages to be silently lost;
  the adversarial review caught it.
- The shared NFS ~/.config/containers/storage.conf is alpha's and would break
  podman 5 on sw-dev-01; hence per-host storage configs selected via
  CONTAINERS_STORAGE_CONF exported by claude-box and the per-host setup hooks.
- CODEX_HOME is derived from the hostname in jibin.bashrc.positron, so the
  host-aware claude-box mounts codex-home at /home/codex-home-claude-$HOST.
- The review's acceptance tests for the nix sandbox (`unshare -Urm true` and a
  trivial sandboxed nix-build) are false positives: they pass even with the
  sandbox silently disabled.
- All shared-file changes were designed to be inert on alpha (alpha's
  behavior unchanged until its container is restarted).
